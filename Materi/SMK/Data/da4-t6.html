TASK 6 • TUGAS PROYEK AKHIR

Projek: Pengklasifikasi Sederhana

Membangun sistem klasifikasi cerdas utuh dari dataset hingga pengujian akurasi akhir

1. Deskripsi Misi Proyek

Kamu diminta membangun aplikasi terminal Python mandiri bernama Sistem Pengklasifikasi Cerdas. Program ini harus mampu menerima dataset angka berlabel, membaginya menjadi data latih dan data uji, mencari prediksi menggunakan metode k-NN atau ambang batas otomatis, lalu mencetak persentase skor akurasi akhirnya.

Misi ini memadukan seluruh alur dasar Machine Learning: Persiapan Data → Train-Test Split → Training / Pencarian Jarak → Prediksi → Evaluasi Akurasi.

2. Kebutuhan Fitur Aplikasi

Fitur Program Persyaratan Teknis
1. Dataset Terpadu Menyediakan minimal 15 baris data contoh yang terdiri dari 1 fitur numerik dan 1 label target (misal: suhu air dan label 'Dingin' / 'Panas').
2. Train-Test Split Otomatis Membagi dataset secara terprogram menjadi 80% data latih dan 20% data uji menggunakan teknik list slicing.
3. Model Prediksi (k-NN / Jarak) Membuat fungsi prediksi yang menghitung jarak terdekat data uji terhadap data latih untuk menentukan labelnya.
4. Laporan Akurasi Akhir Membandingkan hasil prediksi dengan label asli data uji, lalu mencetak persentase akurasi di layar terminal.
5. Fitur Tebak Data Pengguna Meminta input nilai fitur baru dari pengguna terminal, lalu mencetak hasil tebakan kategorinya secara langsung.

3. Langkah Pengerjaan Bertahap

1

Susun dataset awal

Tentukan topik masalah dan buat list data berpasangan (nilai, label) sebanyak minimal 15 baris.

2

Bagi data menjadi latih dan uji

Potong list data dengan slicing: 80% pertama disimpan ke data_latih dan 20% sisanya ke data_uji.

3

Bangun fungsi klasifikasi jarak terdekat

Buat fungsi yang menerima satu nilai fitur baru, menghitung selisih abs() terhadap setiap elemen data_latih, lalu mengembalikan label dengan jarak terpendek.

4

Uji dan hitung akurasi pada data uji

Tebak seluruh elemen pada data_uji, hitung berapa tebakan yang cocok dengan kunci aslinya, lalu hitung persentase akurasi.

5

Buat antarmuka terminal interaktif

Tambahkan perintah input() agar pengguna bisa memasukkan angka baru dan melihat hasil tebakan kategorinya.

4. Kriteria Keberhasilan & Checklist

  • [ ] Dataset memiliki minimal 15 baris data berlabel.
  • [ ] Model dilatih dan mencari tetangga HANYA dari data_latih, tanpa mengintip data_uji.
  • [ ] Program berhasil menghitung dan menampilkan skor persentase akurasi di atas data uji.
  • [ ] Program memiliki fitur input interaktif untuk mengetes data baru dari ketikan pengguna.
  • [ ] Kode bersih, terbagi ke dalam fungsi-fungsi teratur, dan bebas dari error eksekusi.
Tantangan Tambahan (Bonus): Terapkan konsep k=3 (melihat 3 tetangga terdekat lalu mengambil suara terbanyak / voting) untuk membuat tebakan model semakin kokoh terhadap data pencilan!
