TASK 5 • PENGELOMPOKAN DATA

Kelompokkan Data

Mengelompokkan data kontinu ke dalam kategori rentang nilai (Binning / Distribusi Frekuensi)

1. Mengapa Perlu Mengelompokkan Data?

Jika kita memiliki ratusan nilai ujian acak (61, 62, 63, ...), mencatat frekuensi tiap angka satu per satu tidak akan informatif. Dengan Binning (Pengelompokan ke Rentang Nilai), kita mengubah data angka kontinu menjadi kelompok tingkatan mutu (Grade Predikat).

Rentang Nilai (Bin) Predikat / Kelompok Artinya
85 – 100 A (Sangat Baik) Kelompok penguasaan materi istimewa
70 – 84 B (Baik) Kelompok standar tuntas kompetensi
< 70 C (Perlu Remedial) Kelompok yang butuh bimbingan ulang
Pengelompokan data adalah dasar utama untuk membuat grafik histogram dan diagram lingkaran dalam analisis data bisnis.

2. Contoh Kode Distribusi Frekuensi

# Kumpulan nilai ujian satu kelas semua_nilai = [95, 82, 67, 73, 88, 91, 58, 79, 84, 62, 100] # Wadah kelompok kelompok = { "A (85-100)": 0, "B (70-84)" : 0, "C (< 70)" : 0 } # Logika pengelompokan (Binning) for n in semua_nilai: if n >= 85: kelompok["A (85-100)"] += 1 elif n >= 70: kelompok["B (70-84)"] += 1 else: kelompok["C (< 70)"] += 1 print("=== Distribusi Nilai Siswa ===") for predikat, jumlah in kelompok.items(): persen = (jumlah / len(semua_nilai)) * 100 print(f"{predikat:<12}: {jumlah} orang ({persen:.1f}%)")

3. Langkah Praktik

1

Tentukan batas interval rentang

Tetapkan kategori batas nilai (misal: usia anak-anak <13, remaja 13–18, dewasa >18).

2

Siapkan dictionary penghitung

Buat dictionary dengan nilai awal masing-masing kategori diatur ke angka 0.

3

Gunakan percabangan if-elif-else

Looping setiap angka pada data dan tambahkan + 1 ke kategori kunci dictionary yang tepat.

4

Hitung proporsi persentase

Bagi jumlah orang per kelompok dengan total seluruh responden untuk mencetak persentasenya.

4. Kesalahan yang Sering Terjadi

  • Batas interval tumpang-tindih (contoh: n > 70 dan n >= 70 tidak jelas memasukkan angka 70 ke mana).
  • Urutan kondisi if terbalik (misal mengecek n >= 70 sebelum n >= 85, sehingga nilai 90 masuk ke kategori 70).
  • Lupa menghitung total responden saat mencari nilai persentase.
Saat menggunakan struktur if-elif-else menurun, selalu uji batas angka dari yang paling tinggi ke yang paling rendah.
