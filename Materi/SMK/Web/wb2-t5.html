TASK 5 • NAVIGASI TANPA MOUSE

Navigasi Keyboard

Membuat seluruh menu, tombol, dan form dapat dijelajahi dengan nyaman menggunakan tombol Tab

1. Berselancar di Web Menggunakan Tombol Tab

Tidak semua orang memakai mouse saat menggunakan laptop. Sebagian pengguna mengandalkan tombol Tab untuk berpindah antar tautan dan tombol, serta tombol Enter untuk mengeklik.

Tombol Keyboard Aksi di Website
Tab Pindah ke tombol, tautan, atau input formulir berikutnya
Shift + Tab Mundur ke elemen interaktif sebelumnya
Enter / Spasi Mengaktifkan tombol atau membuka tautan
:focus-visible Aturan CSS untuk menampilkan kotak penanda posisi kursor keyboard
Jangan pernah menghilangkan garis fokus dengan outline: none; tanpa memberi tanda pengganti, karena pengguna keyboard akan tersesat dan tidak tahu posisi tombol yang sedang aktif.

2. Contoh Kode Fokus Aksesibel

/* Memberikan penanda fokus yang tegas saat ditekan Tab */ a:focus-visible, button:focus-visible, input:focus-visible { outline: 3px solid #4361ee; /* Garis biru tegas */ outline-offset: 3px; /* Beri jarak agar tidak menempel */ border-radius: 6px; } <!-- Tautan lewati navigasi untuk pengguna keyboard --> <a href="#konten-utama" class="skip-link">Lompat ke Konten Utama</a>

3. Langkah Praktik

1

Periksa tag tombol dan link

Pastikan semua hal yang bisa diklik dibuat memakai tag semantik seperti <a> atau <button>.

2

Beri gaya outline yang kontras

Tambahkan selector :focus-visible di CSS dengan warna outline yang jelas dan tidak bertabrakan dengan warna latar.

3

Cek urutan formulir

Pastikan setiap kolom input formulir tersusun runtut dari atas ke bawah sesuai urutan membaca.

4

Uji coba tanpa menyentuh mouse

Lepaskan mouse-mu, lalu tekan tombol Tab berkali-kali untuk memastikan kamu bisa membuka menu dan mengisi form pendaftaran.

4. Kesalahan yang Sering Terjadi

  • Menuliskan * { outline: none; } yang menghilangkan garis pembantu fokus untuk seluruh elemen web.
  • Membuat tombol interaktif dari tag <div> yang tidak bisa menerima fokus tombol Tab secara otomatis.
  • Mengatur tabindex dengan angka positif acak yang mengacaukan urutan lompatan tombol keyboard.
Gunakan pseudo-class :focus-visible daripada :focus biasa agar garis penanda hanya muncul saat pengguna menavigasi via keyboard, bukan saat mouse mengeklik.
