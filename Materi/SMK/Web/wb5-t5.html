Uji dan Perbaikan Bug

Menemukan error pada panel Console, menguji skenario tak terduga, dan memastikan aplikasi bebas masalah

1. Membaca Pesan Error di Tab Console

Bug adalah kesalahan dalam kode yang menyebabkan aplikasi macet atau tidak bekerja sebagaimana mestinya. Tab Console pada browser Developer Tools (F12) adalah alat utama untuk melihat pesan kesalahan tersebut.

Pesan Error Umum Penyebab Utama Cara Memperbaiki
Uncaught TypeError: Cannot read properties of null JavaScript mencoba mengakses elemen HTML yang tidak ditemukan id/class-nya Periksa kesamaan ejaan nama id atau class antara HTML dan JavaScript
Uncaught ReferenceError: ... is not defined Variabel atau fungsi dipanggil padahal belum pernah dibuat namanya Cek deklarasi variabel atau ejaan huruf besar/kecil fungsi
NaN (Not a Number) Operasi matematika dijalankan pada teks yang bukan angka Pastikan input dibungkus fungsi Number() dan tidak bernilai kosong
Developer profesional selalu menguji skenario di luar dugaan: apa yang terjadi jika tombol diklik berkali-kali dengan cepat, atau jika kolom isian dibiarkan kosong?

2. Menulis Kode Aman (Defensive Code)

// 1. Cek keberadaan elemen sebelum dipasangi listener const btnReset = document.querySelector("#btnReset"); if (btnReset) { btnReset.addEventListener("click", () => { totalSkor = 0; perbaruiTampilanSkor(totalSkor); }); } else { console.warn("Tombol reset tidak ditemukan pada halaman ini."); }

3. Langkah Praktik

1

Buka Developer Tools Console

Tekan tombol F12 atau klik kanan lalu pilih Inspect, kemudian buka tab Console.

2

Uji coba tombol dan input

Gunakan aplikasi kuis, klik tombol opsi, dan periksa apakah ada teks merah error yang muncul di panel Console.

3

Uji skenario batas (Edge Cases)

Coba klik tombol beberapa kali berturut-turut untuk memastikan skor tidak terus bertambah secara curang.

4

Pastikan status 0 Error

Perbaiki baris kode yang memicu error sampai tab Console bersih dan aplikasi berjalan stabil.

4. Kesalahan yang Sering Terjadi

  • Mengabaikan pesan error merah di console selama tampilan website terlihat masih bisa diklik.
  • Hanya menguji skenario sukses (skenario yang berjalan normal) tanpa menguji saat pengguna salah input.
  • Memperbaiki satu baris kode tetapi secara tidak sengaja menghapus kurung kurawal tutup (}) yang memicu SyntaxError baru.
Jika menemukan error di Console, klik tautan nomor baris di sebelah kanan pesan error untuk langsung melompat ke baris kode yang bermasalah.
