TASK 1 • HTML SEMANTIK & KARTU

Galeri Kartu

Menyusun galeri kartu konten mandiri menggunakan tag semantik <section> dan <article>

1. Memilih Tag yang Tepat untuk Kartu

Dalam pembuatan daftar kegiatan atau katalog, hindari menggunakan tag <div> secara berlebihan. HTML menyediakan tag semantik yang langsung menjelaskan fungsi dari masing-masing bagian.

Tag Semantik Peran dalam Galeri
<section> Membungkus seluruh area galeri sebagai satu bagian tema konten.
<article> Membungkus masing-masing kartu info lomba karena isinya mandiri dan utuh.
<header> Menampung judul dan kategori di bagian atas kartu.
<footer> Menampung tombol aksi atau info tanggal di bagian dasar kartu.
Gunakan <article> jika konten di dalam kartu tetap masuk akal dan bernilai informasi meskipun dicabut dan dibaca terpisah dari halaman tersebut.

2. Contoh Kode Galeri Kartu

<!-- Struktur Semantik Galeri --> <section class="galeri-event"> <h2>Kompetisi Mendatang</h2> <article class="kartu-event"> <header> <span class="kategori">Web Dev</span> <h3>Lomba Frontend Siswa</h3> </header> <p>Bangun landing page menarik dalam waktu 24 jam.</p> <footer> <button>Lihat Detail</button> </footer> </article> </section>

3. Langkah Praktik

1

Bungkus area dengan <section>

Buat tag <section> lengkap dengan heading judul bagian menggunakan <h2>.

2

Buat elemen kartu dengan <article>

Di dalam section, buat minimal 3 kartu kegiatan menggunakan tag <article>.

3

Terapkan tata letak fleksibel

Beri class pada section induk lalu atur menggunakan CSS display: flex; gap: 1.5rem; agar kartu berjejer horizontal.

4

Ratakan tombol kartu ke bawah

Atur kartu dengan display: flex; flex-direction: column; justify-content: space-between; agar letak tombol sejajar rapi.

4. Kesalahan yang Sering Terjadi

  • Menuliskan seluruh kartu menggunakan tag <div class="card"> tanpa ada tag semantik sama sekali.
  • Tidak memberi heading (<h2> atau <h3>) di dalam tag <section> atau <article>.
  • Membuat tinggi kartu berbeda-beda karena tidak mengunci distribusi ruang dengan flexbox.
Setiap elemen <section> idealnya memiliki minimal satu judul (heading) agar struktur outline dokumen terbaca jelas oleh mesin pencari.
