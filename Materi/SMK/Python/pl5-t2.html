TASK 2 • METHOD OVERRIDING

Hewan Bersuara

Menimpa method milik class induk untuk memberikan perilaku unik pada tiap class turunan

1. Konsep Pewarisan dan Overriding

Class turunan (child class) mewarisi seluruh method dari class induk (parent class). Namun, bila perilaku bawaan induk kurang cocok, class anak bisa menulis ulang method tersebut dengan nama yang persis sama. Konsep ini disebut Method Overriding.

Class Method Perilaku Khusus
Hewan (Induk) bersuara() Menghasilkan suara umum hewan
Kucing (Anak) bersuara() (Overridden) Menimpa method induk dan berbunyi: "Meong! Meong!"
Anjing (Anak) bersuara() (Overridden) Menimpa method induk dan berbunyi: "Guk! Guk!"
Method overriding memungkinkan class induk mendefinisikan aturan umum, sementara detail perilakunya diserahkan pada masing-masing class anak.

2. Contoh Kode

# Class Induk class Hewan: def __init__(self, nama): self.nama = nama def bersuara(self): return f"{self.nama} mengeluarkan suara misterius." # Class Anak 1 class Kucing(Hewan): def bersuara(self): return f"{self.nama} bersuara: Meong! Meong!" # Class Anak 2 class Anjing(Hewan): def bersuara(self): return f"{self.nama} bersuara: Guk! Guk!" hewan_peliharaan = [Kucing("Mimi"), Anjing("Blacky")] for h in hewan_peliharaan: print(h.bersuara())

3. Langkah Praktik

1

Rancang class induk Hewan

Buat class Hewan dengan atribut nama dan method dasar bersuara().

2

Buat class turunan Kucing dan Anjing

Hubungkan pewarisan dengan tanda kurung: class Kucing(Hewan):.

3

Tulis ulang method bersuara()

Beri nama method yang sama persis di dalam class anak tetapi ubah nilai kembaliannya menjadi suara spesifik.

4

Tambahkan class Sapi

Buat class turunan ketiga Sapi yang meng-override suara menjadi "Moooo!" lalu uji panggilannya.

4. Kesalahan yang Sering Terjadi

  • Salah mengeja nama method pada class anak (misal suara() bukan bersuara()), sehingga method baru terbentuk dan bukan menimpa method induk.
  • Lupa menyertakan parameter self pada definisi method di class turunan.
  • Tidak mencantumkan nama class induk di dalam tanda kurung saat membuat class turunan.
Agar method overriding bekerja, nama method dan jumlah parameternya pada class anak harus serasi dengan method pada class induk.
