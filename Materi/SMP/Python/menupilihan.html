Membuat Menu Pilihan

Logika percabangan komputer untuk memilih menu menggunakan if, elif, dan else

1. Logika di Balik Menu Pilihan

Menu pilihan dibuat dengan menggabungkan tampilan daftar (print), input pilihan user, dan percabangan logika.

Peran Kata Kunci Logika:
  • if : "Jika memilih nomor ini..."
  • elif (else if) : "Atau jika memilih nomor yang ini..."
  • else : "Jika nomor yang diketik tidak ada di daftar menu..."
Catatan Indentasi (Spasi Tab):
Baris kode aksi di bawah if, elif, dan else wajib menjorok ke dalam (tekan 1 kali tombol Tab pada keyboard) agar Python tahu baris tersebut milik kondisi tersebut!

2. Instruksi 3 Langkah Praktik

1

Langkah 1: Tampilkan Daftar Pilihan

Gunakan print() untuk mencetak daftar menu nomor yang tersedia.

print("=== MENU KANTIN ===") print("1. Nasi Goreng (Rp 10.000)") print("2. Mie Ayam (Rp 8.000)") print("3. Es Teh (Rp 3.000)")
2

Langkah 2: Ambil Pilihan Pengguna

Minta pengguna mengetik nomor pilihannya.

pilihan = input("Pilih menu (1/2/3): ")
3

Langkah 3: Tentukan Respons dengan if-elif-else

Cek nomor yang diketikkan dan cetak pesanan yang sesuai.

if pilihan == "1": print("Kamu memesan Nasi Goreng!") elif pilihan == "2": print("Kamu memesan Mie Ayam!") elif pilihan == "3": print("Kamu memesan Es Teh!") else: print("Menu tidak valid, silakan pilih 1, 2, atau 3.")

Simulasi Langsung: Kantin Python

Pilih menu: 1. Nasi Goreng | 2. Mie Ayam | 3. Es Teh
