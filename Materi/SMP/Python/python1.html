Dasar Python: Variabel, Tipe Data & I/O

Memahami alur kerja program, penyimpanan memori, dan interaksi pengguna

1. Cara Python Membaca Kode

Python membaca kode baris demi baris secara berurutan dari baris paling atas hingga paling bawah (disebut proses sekuensial).

Komputer menjalankan instruksi langkah per langkah. Komputer tidak akan melompat ke baris 2 sebelum tugas di baris 1 benar-benar tuntas dikerjakan.

2. Variabel & Fungsi print()

Variabel adalah kotak bernama yang disimpan di dalam memori komputer untuk menyimpan suatu nilai atau informasi.

Fungsi print() bertugas menampilkan teks atau isi kotak variabel ke layar konsol/terminal.

# Kotak bernama 'nama' diisi teks nama = "Anindita" # Cetak teks dan variabel bersamaan print("Halo, namaku", nama)

3. Tipe Data Dasar Lengkap

Nilai di dalam variabel memiliki bentuk dan aturan yang berbeda-beda. Berikut tipe data utama di Python:

Tipe Data Nama Lengkap Kegunaan Contoh
str String Teks berupa karakter atau huruf (wajib diapit kutip " " atau ' '). "Budi", "Semarang", "123"
int Integer Bilangan bulat tanpa koma (bisa positif atau negatif). 14, 2026, -5
float Floating Point Bilangan pecahan atau desimal (menggunakan titik .). 3.14, 95.5, -0.5
bool Boolean Nilai logika kebenaran, hanya bernilai benar atau salah. True, False
None NoneType Menunjukkan nilai kosong atau variabel yang belum terisi apa pun. None
[..] List Kumpulan data yang berurutan dan dapat diubah isinya (mutable), menggunakan tanda kurung siku [...] . ['apel', 'mangga', 10]
# Contoh penerapan berbagai tipe data judul_game = "Petualangan Coding" # str level = 5 # int kecepatan = 12.8 # float sudah_menang = False # bool senjata_rahasia = None # NoneType

4. Fungsi input() & Konversi Tipe Data

Fungsi input() digunakan untuk menerima data yang diketikkan pengguna melalui keyboard.

Catatan Sangat Penting:
Fungsi input() selalu menghasilkan teks (str), sekalipun angka yang dimasukkan pengguna!

Jika ingin menjumlahkan angka dari pengguna, kita harus mengubah (konversi) tipe datanya terlebih dahulu menggunakan int() atau float():

# Mengambil input (selalu berupa teks/str) umur_teks = input("Masukkan umurmu: ") # Mengubah teks menjadi angka bulat agar bisa dihitung umur_angka = int(umur_teks) umur_tahun_depan = umur_angka + 1 print("Tahun depan umurmu:", umur_tahun_depan)

5. Instruksi Praktik

1

Langkah 1: Simpan Namamu di Variabel

Buat variabel bernama nama lalu simpan nama panggilanmu di dalamnya.

nama = "Nama Kamu"
2

Langkah 2: Tampilkan dengan print()

Gunakan fungsi print() untuk menampilkan sapaan beserta isi variabel nama.

print("Halo!", nama)
3

Langkah 3: Tambahkan Umur lewat input()

Minta pengguna mengisi umur via keyboard, lalu cetak rangkuman datanya ke layar.

umur = input("Berapa umurmu? ") print(nama, "berusia", umur, "tahun!")
