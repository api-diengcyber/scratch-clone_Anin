Tag dasar HTML

Web HTML/CSS via AI • Level Pemula

1. Tujuan task

Di task ini kamu mengerjakan Tag dasar HTML, bagian dari modul Web HTML/CSS via AI (pertemuan 7–12).

Konsep yang dipakai: HTML, CSS, prompt kode, review kode.

2. Ringkasan konsep

AI bisa menulis kode web, tapi kamu yang harus memahami dan memeriksanya.

  • HTML menyusun isi halaman
  • CSS mengatur tampilan
  • Selalu uji kode dari AI

3. Instruksi praktik

1

Langkah 1

Buat halaman dengan h1, p, img, dan a

2

Langkah 2

Isi dengan perkenalan dirimu

3

Langkah 3

Buka hasilnya di tab pratinjau

4. Tips saat mengerjakan

  • Simpan tiap versi prompt dan catat apa yang berubah pada hasilnya.
  • Periksa fakta penting dari hasil AI di sumber lain sebelum dipakai.
  • Jangan menulis data pribadi di prompt, dan sebutkan bila karyamu dibantu AI.
