Siap Dibagikan

Menyiapkan proyek web agar bisa dibuka secara online oleh siapa saja lewat tautan publik

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Siap Dibagikan, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Dari Komputer Lokal ke Internet

Selama file web hanya dibuka lewat folder komputermu (file:///C:/...), orang lain tidak bisa melihat karyamu. Untuk membagikannya, file harus diunggah ke penyedia hosting web statis.

Status File Alamat URL Dapat Dibuka Siapa?
Lokal Komputer file:///Users/nama/project/index.html Hanya di komputermu sendiri
Online (Hosting) https://username.github.io/kuis-mini/ Semua orang lewat HP, tablet, atau laptop
Server hosting mencari file bernama index.html di folder utama sebagai pintu gerbang pertama pembuka websitemu.

2. Jalur File (Relative Path) yang Aman

<!-- SALAH: Menggunakan jalur folder di komputermu --> <link rel="stylesheet" href="C:/Users/Budi/Documents/css/style.css"> <img src="D:/Foto/logo.png"> <!-- BENAR: Menggunakan jalur relatif dalam proyek --> <link rel="stylesheet" href="./css/style.css"> <script src="./js/app.js" defer></script> <img src="./assets/logo.png" alt="Logo EduEvent">

3. Eksplorasi Praktik

1

Pastikan nama file utama adalah index.html

File HTML pembuka wajib dinamai index.html (huruf kecil semua) dan berada di folder terluar.

2

Periksa jalur semua aset (gambar, CSS, JS)

Pastikan tautan link CSS dan script JS menggunakan relative path (./folder/file) dan tidak mengarah ke drive lokal komputermu.

3

Unggah ke platform hosting statis

Gunakan layanan hosting gratis seperti GitHub Pages, Vercel, atau Netlify Drag-and-Drop.

4

Uji coba buka tautan di ponsel

Buka tautan web yang kamu peroleh dari browser ponsel untuk memastikan semua gambar dan fungsi tombol bekerja sempurna.

4. Kesalahan yang Sering Terjadi

  • Menamai file utama dengan home.html atau kuis.html sehingga saat tautan dibuka muncul pesan 404 Not Found.
  • Terdapat perbedaan huruf besar dan kecil pada nama file (misal: di kode tertulis Logo.PNG, nama file aslinya logo.png).
  • Gambar rusak saat dibuka orang lain karena masih mengarah ke lokasi drive lokal komputermu.
Server online membedakan huruf besar dan huruf kecil (case-sensitive). Selalu biasakan menamai file dengan huruf kecil tanpa spasi.
