Menata website agar otomatis menyesuaikan tampilan di HP, tablet, dan laptop

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Satu Halaman, Tiga Layar, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Mengapa Desain Responsif Diperlukan?

Pengunjung membuka websitemu lewat perangkat yang berbeda-beda. Desain responsif memastikan susunan halaman tetap rapi dan nyaman dibaca tanpa harus digeser-geser ke samping.

Perangkat Lebar Layar Susunan Layout Ideal
Smartphone (HP) < 768px 1 kolom bertumpuk ke bawah
Tablet 768px – 1024px 2 kolom berdampingan
Laptop / Desktop > 1024px 3 atau 4 kolom horizontal
Kunci utama web responsif ada pada tag meta viewport di HTML dan aturan @media query di CSS.

2. Contoh Kode Viewport dan Media Query

<!-- 1. Wajib ada di dalam tag <head> --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> /* 2. Gaya Dasar: Layar HP (1 Kolom) */ .kartu-container { display: flex; flex-direction: column; gap: 1rem; } /* 3. Layar Tablet ke atas (>= 768px): 2 Kolom */ @media (min-width: 768px) { .kartu-container { display: grid; grid-template-columns: repeat(2, 1fr); } } /* 4. Layar Laptop ke atas (>= 1024px): 3 Kolom */ @media (min-width: 1024px) { .kartu-container { grid-template-columns: repeat(3, 1fr); } }

3. Eksplorasi Praktik

1

Pasang meta viewport

Pastikan tag <meta name="viewport" ...> terpasang di dalam tag <head> file HTML-mu.

2

Tulis gaya CSS untuk HP terlebih dahulu (Mobile-First)

Atur kontainer pembungkus elemen agar mengalir lurus ke bawah dalam 1 kolom sebagai gaya default.

3

Tambahkan media query untuk tablet

Tulis aturan @media (min-width: 768px) dan ubah tata letak menjadi 2 kolom.

4

Tambahkan media query untuk layar lebar

Tulis aturan @media (min-width: 1024px) agar tampilan membagi ruang menjadi 3 kolom secara seimbang.

4. Kesalahan yang Sering Terjadi

  • Lupa memasang tag meta viewport, sehingga tampilan di layar HP mengecil seperti prangko.
  • Memberikan lebar statis pada kotak konten (seperti width: 900px;) yang memicu garis geser (scroll) horizontal di HP.
  • Menulis urutan media query terbalik saat memakai min-width, sehingga aturan layar kecil menimpa layar besar.
Gunakan fitur Toggle Device Toolbar (Ctrl + Shift + M di browser) untuk menguji responsivitas halamanmu secara langsung di berbagai ukuran layar.
