Kuis Mini

Menyatukan struktur HTML, gaya CSS, dan logika JavaScript dalam satu aplikasi kuis interaktif

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Kuis Mini, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Memadukan Tiga Pilar Web

Aplikasi web yang utuh membagi tugas secara seimbang tanpa mencampuradukkan peran masing-masing bahasa pemrograman.

Teknologi Peran dalam Kuis Mini Contoh Elemen
HTML Wadah pertanyaan, opsi jawaban, dan area skor <article>, <button>, <h3>
CSS Tata letak kartu kuis, efek hover tombol, warna status jawaban display: flex, .benar, .salah
JavaScript Menyimpan soal, memeriksa kunci jawaban, dan menghitung skor addEventListener, array objek soal, skor total
Pemisahan tugas (Separation of Concerns) membuat kuis mudah diperbarui—misalnya menambah soal baru di JavaScript tanpa perlu merombak file HTML.

2. Contoh Kode Kuis Sederhana

<!-- 1. HTML: Wadah Pertanyaan --> <section class="kuis-box"> <h3 id="soalTeks">Ibu kota Indonesia saat ini adalah?</h3> <div class="opsi-list"> <button class="btn-opsi" data-jawaban="salah">Surabaya</button> <button class="btn-opsi" data-jawaban="benar">Jakarta</button> </div> <p id="statusHasil"></p> </section> // 2. JavaScript: Logika Pengecekan const opsiButtons = document.querySelectorAll(".btn-opsi"); const statusHasil = document.querySelector("#statusHasil"); opsiButtons.forEach((tombol) => { tombol.addEventListener("click", () => { if (tombol.dataset.jawaban === "benar") { statusHasil.textContent = "Jawabanmu Benar! 🎉"; statusHasil.style.color = "#4ade80"; } else { statusHasil.textContent = "Kurang tepat, coba lagi ya! ❌"; statusHasil.style.color = "#f72585"; } }); });

3. Eksplorasi Praktik

1

Susun kerangka semantik kuis

Buat tag <section> yang memuat judul pertanyaan dan wadah deretan tombol pilihan jawaban.

2

Beri styling tata letak tombol

Gunakan CSS Flexbox untuk menata tombol opsi vertikal atau horizontal dengan jarak gap yang nyaman ditekan.

3

Beri atribut penanda jawaban

Gunakan data-jawaban="benar" pada tombol jawaban tepat dan data-jawaban="salah" pada tombol pengecoh.

4

Hubungkan event listener di JavaScript

Dengarkan klik pada tombol pilihan dan cetak pesan status hasil langsung ke layar.

4. Kesalahan yang Sering Terjadi

  • Menulis kode JavaScript langsung di atribut HTML seperti onclick="alert('Benar')" alih-alih di file script terpisah.
  • Lupa menyertakan elemen penampung umpan balik sehingga hasil kuis tidak terlihat oleh pengguna.
  • Tidak menonaktifkan tombol setelah diklik sehingga pengguna bisa terus menekan pilihan berkali-kali.
Pastikan struktur file terpisah rapi: index.html untuk tag, style.css untuk gaya, dan app.js untuk aksi kuis.
