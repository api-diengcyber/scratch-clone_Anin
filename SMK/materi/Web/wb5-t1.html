Kuis Mini

Menyatukan struktur HTML, gaya CSS, dan logika JavaScript dalam satu aplikasi kuis interaktif

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Memadukan Tiga Pilar Web

Aplikasi web yang utuh membagi tugas secara seimbang tanpa mencampuradukkan peran masing-masing bahasa pemrograman.

Teknologi Peran dalam Kuis Mini Contoh Elemen
HTML Wadah pertanyaan, opsi jawaban, dan area skor <article>, <button>, <h3>
CSS Tata letak kartu kuis, efek hover tombol, warna status jawaban display: flex, .benar, .salah
JavaScript Menyimpan soal, memeriksa kunci jawaban, dan menghitung skor addEventListener, array objek soal, skor total
Pemisahan tugas (Separation of Concerns) membuat kuis mudah diperbarui—misalnya menambah soal baru di JavaScript tanpa perlu merombak file HTML.

2. Contoh Kode Kuis Sederhana

<!-- 1. HTML: Wadah Pertanyaan --> <section class="kuis-box"> <h3 id="soalTeks">Ibu kota Indonesia saat ini adalah?</h3> <div class="opsi-list"> <button class="btn-opsi" data-jawaban="salah">Surabaya</button> <button class="btn-opsi" data-jawaban="benar">Jakarta</button> </div> <p id="statusHasil"></p> </section> // 2. JavaScript: Logika Pengecekan const opsiButtons = document.querySelectorAll(".btn-opsi"); const statusHasil = document.querySelector("#statusHasil"); opsiButtons.forEach((tombol) => { tombol.addEventListener("click", () => { if (tombol.dataset.jawaban === "benar") { statusHasil.textContent = "Jawabanmu Benar! 🎉"; statusHasil.style.color = "#4ade80"; } else { statusHasil.textContent = "Kurang tepat, coba lagi ya! ❌"; statusHasil.style.color = "#f72585"; } }); });

3. Eksplorasi Praktik

1

Susun kerangka semantik kuis

Buat tag <section> yang memuat judul pertanyaan dan wadah deretan tombol pilihan jawaban.

2

Beri styling tata letak tombol

Gunakan CSS Flexbox untuk menata tombol opsi vertikal atau horizontal dengan jarak gap yang nyaman ditekan.

3

Beri atribut penanda jawaban

Gunakan data-jawaban="benar" pada tombol jawaban tepat dan data-jawaban="salah" pada tombol pengecoh.

4

Hubungkan event listener di JavaScript

Dengarkan klik pada tombol pilihan dan cetak pesan status hasil langsung ke layar.

4. Kesalahan yang Sering Terjadi

  • Menulis kode JavaScript langsung di atribut HTML seperti onclick="alert('Benar')" alih-alih di file script terpisah.
  • Lupa menyertakan elemen penampung umpan balik sehingga hasil kuis tidak terlihat oleh pengguna.
  • Tidak menonaktifkan tombol setelah diklik sehingga pengguna bisa terus menekan pilihan berkali-kali.
Pastikan struktur file terpisah rapi: index.html untuk tag, style.css untuk gaya, dan app.js untuk aksi kuis.
