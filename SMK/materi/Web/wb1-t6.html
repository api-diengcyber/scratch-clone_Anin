Proyek: Landing Page Komunitas

HTML Semantik & Layout CSS • Level Menengah

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Proyek: Landing Page Komunitas, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Tujuan task

Di task ini kamu mengerjakan Proyek: Landing Page Komunitas, bagian dari modul HTML Semantik & Layout CSS (pertemuan 1–6).

Konsep yang dipakai: semantik, flexbox, grid, box model.
Ini proyek. Kerjakan bertahap, simpan karyamu di tiap langkah, dan uji sebelum dikumpulkan.

2. Ringkasan konsep

HTML semantik memberi arti pada tiap bagian halaman. Flexbox dan grid mengatur tata letak tanpa trik yang rumit.

  • Tag semantik: header, nav, main, section, footer
  • Flexbox mengatur satu baris atau satu kolom
  • Grid mengatur baris dan kolom sekaligus

3. Eksplorasi Praktik

1

Langkah 1

Rancang halaman untuk sebuah komunitas atau klub sekolah

2

Langkah 2

Buat navbar, bagian utama, daftar kegiatan, dan form bergabung

3

Langkah 3

Pakai tag semantik seperti header, main, section, dan footer

4

Langkah 4

Rapikan tampilannya dengan Flexbox dan Grid

4. Tips saat mengerjakan

  • Muat ulang Preview dan buka di lebar layar yang berbeda setelah mengubah tata letak.
  • Gunakan tag semantik dan beri nama class yang menjelaskan fungsinya.
  • Pakai konsol browser untuk melihat error JavaScript.
