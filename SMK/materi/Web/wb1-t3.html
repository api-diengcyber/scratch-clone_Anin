TASK 2 • FORMULIR SEMANTIK

Formulir Pendaftaran

Menyusun form pendaftaran yang aksesibel dan terstruktur dengan label serta input yang terhubung

Materi Lengkap: Formulir Dan Validasi

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Formulir Pendaftaran, fokus utama kita adalah formulir dan validasi. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Form mengumpulkan input pengguna. Validasi memeriksa apakah data sesuai aturan sebelum diproses, baik di browser maupun server.

Contoh Sederhana

Email harus memiliki format yang masuk akal dan nama tidak boleh kosong sebelum data diterima.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

form, input, label, validation, required, submit, event

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan saat menerima data pengguna seperti pendaftaran, login, pencarian, atau transaksi.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Struktur Semantik Formulir

Formulir yang baik tidak hanya tampil rapi, tetapi juga harus menghubungkan setiap label instruksi ke kolom inputnya agar mudah diisi oleh pengguna keyboard maupun pembaca layar.

Tag / Atribut Fungsi
<form> Wadah utama tempat seluruh kolom isian dan tombol submit berada.
<label for="id-input"> Teks keterangan yang wajib ditautkan dengan atribut id milik input.
<input type="..."> Bidang tempat pengguna mengetikkan teks, email, atau angka.
<button type="submit"> Tombol untuk memicu pengiriman data formulir.
Saat tag <label> diklik dengan mouse, kursor akan otomatis aktif di dalam kolom <input> pasangannya jika atribut for dan id cocok.

2. Contoh Kode Form Semantik

<section id="pendaftaran"> <h2>Formulir Pendaftaran Siswa</h2> <form class="form-grup"> <div class="input-item"> <label for="nama-lengkap">Nama Lengkap:</label> <input type="text" id="nama-lengkap" name="nama" required> </div> <div class="input-item"> <label for="email-siswa">Email Sekolah:</label> <input type="email" id="email-siswa" name="email" required> </div> <button type="submit">Daftar Sekarang</button> </form> </section>

3. Eksplorasi Praktik

1

Bungkus area formulir ke dalam tag <section>

Buat <section id="pendaftaran"> dan beri judul form menggunakan heading semantik <h2>.

2

Buat elemen <form> dan pasangkan label

Sediakan input Nama, Email, dan Pilihan Kategori. Pastikan setiap <label for="..."> memiliki nilai yang persis sama dengan <input id="...">.

3

Terapkan tata letak flexbox pada kolom input

Atur .input-item dengan display: flex; flex-direction: column; gap: 0.5rem; agar teks label berada rapi di atas kotak input.

4

Gunakan tombol submit semantik

Tambahkan <button type="submit"> di akhir form untuk mengirim data.

4. Kesalahan yang Sering Terjadi

  • Menulis teks label biasa menggunakan tag <span> atau <p> tanpa tag <label>.
  • Nilai atribut for pada label tidak sama dengan atribut id pada input.
  • Hanya mengandalkan atribut placeholder sebagai pengganti label (placeholder akan hilang saat mulai mengetik sehingga membingungkan).
Placeholder bukan pengganti label. Label wajib selalu terlihat agar pengguna tidak lupa kolom apa yang sedang mereka isi.
