Layout dengan Grid

Mengatur struktur halaman makro (konten dan sidebar) secara bersamaan menggunakan CSS Grid

Materi Lengkap: Layout Css

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Layout dengan Grid, fokus utama kita adalah layout CSS. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. CSS layout menentukan posisi dan ukuran elemen. Flexbox cocok untuk mengatur elemen pada satu dimensi, sedangkan Grid cocok untuk baris dan kolom dua dimensi.

Contoh Sederhana

Flexbox dapat menyusun kartu secara horizontal dan membungkusnya ketika ruang sempit; Grid dapat membuat area kartu dalam beberapa kolom.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

display, flex, grid, container, item, gap, alignment, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan Flexbox untuk toolbar/nav/kumpulan item satu arah dan Grid untuk layout dua dimensi.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Prinsip Dua Dimensi pada CSS Grid

Jika Flexbox fokus pada satu arah, CSS Grid mengatur baris dan kolom secara bersamaan (dua dimensi). Ini sangat tepat untuk membagi halaman utama antara kolom konten dan kolom sidebar pendukung.

Properti CSS Grid Kegunaan
display: grid Mengaktifkan pembagian grid dua dimensi pada kontainer.
grid-template-columns Menentukan jumlah dan proporsi lebar setiap kolom.
Satuan Fraksi fr Membagi sisa ruang secara fleksibel (misal: 3fr 1fr).
gap Jarak renggang antara baris dan kolom grid.
Dengan rasio grid-template-columns: 3fr 1fr;, area konten utama otomatis mendapat 75% ruang dan sidebar mendapat 25% ruang.

2. Contoh Kode Layout Grid

<!-- Struktur Halaman Makro --> <div class="layout-utama"> <main> <h2>Konten Utama EduEvent</h2> <p>Daftar perlombaan dan kegiatan siswa sekolah.</p> </main> <aside> <h3>Pengumuman Penting</h3> <p>Batas akhir pengumpulan berkas: 25 Oktober 2026.</p> </aside> </div> /* CSS Tata Letak Dua Dimensi */ .layout-utama { display: grid; grid-template-columns: 3fr 1fr; gap: 2rem; max-width: 1100px; margin: 0 auto; }

3. Eksplorasi Praktik

1

Bungkus <main> dan <aside>

Satukan elemen semantik <main> dan <aside> ke dalam sebuah kontainer pembungkus layout.

2

Aktifkan display: grid

Beri properti display: grid; pada elemen pembungkus tersebut.

3

Bagi kolom asimetris dengan fr

Gunakan grid-template-columns: 3fr 1fr; dan beri jarak antar kolom dengan gap: 2rem;.

4

Batasi lebar maksimum halaman

Tambahkan max-width: 1100px; margin: 0 auto; agar halaman tetap rapi di tengah monitor berlayar besar.

4. Kesalahan yang Sering Terjadi

  • Menuliskan persentase kaku (seperti 75% 25%) tanpa memperhitungkan gap, sehingga kolom meluap keluar layar. Gunakan fr.
  • Menaruh tag <aside> di luar pembungkus grid sehingga sidebar jatuh ke bawah halaman.
  • Membuat grid bertingkat yang tidak perlu untuk bagian yang sebenarnya hanya membutuhkan satu baris sederhana.
Gunakan Grid untuk kerangka besar halaman (seperti membagi Konten dan Sidebar), lalu gunakan Flexbox untuk bagian kecil di dalamnya (seperti tombol dan menu).
