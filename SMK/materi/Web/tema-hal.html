1. Memahami classList dan Toggle

Daripada mengubah warna elemen satu per satu lewat kode JavaScript, cara terbaik untuk mengganti tema adalah dengan menambah atau menghapus class CSS pada elemen induk seperti <body>.

Metode classList Fungsi
classList.add("nama-class") Menambahkan class baru ke elemen.
classList.remove("nama-class") Menghapus class tertentu dari elemen.
classList.toggle("nama-class") Menambah class jika belum ada, atau menghapusnya jika sudah ada.
classList.contains("nama-class") Mengecek apakah elemen sedang memiliki class tersebut (menghasilkan true/false).
Method toggle() bertindak seperti sakelar lampu: satu klik menyalakan class mode gelap, klik berikutnya mematikan class tersebut.

2. Contoh Kode Pengubah Tema

/* 1. Aturan CSS untuk Tema Gelap */ body.dark-mode { background-color: #0f172a; color: #f8fafc; } <!-- 2. Tombol HTML --> <button id="btnTema">🌙 Mode Gelap</button> // 3. Logika JavaScript const btnTema = document.querySelector("#btnTema"); btnTema.addEventListener("click", function() { document.body.classList.toggle("dark-mode"); if (document.body.classList.contains("dark-mode")) { btnTema.textContent = "☀️ Mode Terang"; } else { btnTema.textContent = "🌙 Mode Gelap"; } });

3. Eksplorasi Praktik

1

Tentukan gaya tema gelap di file CSS

Buat class .dark-mode yang mengatur warna latar belakang (background) menjadi gelap dan warna teks menjadi terang.

2

Tambahkan tombol pengubah tema

Buat sebuah elemen <button id="btnTema"> di bagian atas halaman web.

3

Terapkan classList.toggle() saat tombol diklik

Panggil document.body.classList.toggle("dark-mode") di dalam event listener klik tombol.

4

Sesuaikan teks dan ikon tombol

Gunakan pengkondisian classList.contains("dark-mode") untuk mengganti ikon tombol antara bulan (🌙) dan matahari (☀️).

4. Kesalahan yang Sering Terjadi

  • Menuliskan tanda titik pada nama class di dalam method JS, contoh keliru: classList.toggle(".dark-mode"). Seharusnya tanpa titik: classList.toggle("dark-mode").
  • Mengubah style warna satu per satu lewat document.body.style.background yang membuat kode berantakan dan sulit dikelola.
  • Lupa mengubah warna teks saat latar belakang menjadi gelap, sehingga tulisan tidak terlihat (hitam di atas hitam).
Saat menggunakan properti classList, tuliskan langsung nama class-nya tanpa tanda titik (.), karena JavaScript sudah tahu bahwa nilai tersebut adalah nama class.
