Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Mengambil Nilai Input dan Mengubah Tipe Data

Nilai yang diambil dari elemen <input> selalu bertipe string (teks). Agar bisa dihitung secara matematis, teks tersebut perlu diubah menjadi angka menggunakan fungsi Number() atau parseFloat().

Perintah Hasil Keterangan
input.value "50000" (String) Teks mentah dari input pengguna.
Number(input.value) 50000 (Number) Diubah menjadi angka agar bisa dijumlahkan atau dikalikan.
Jika tidak diubah menjadi angka, operasi "10000" + "5000" akan menghasilkan "100005000", bukan 15000.

2. Contoh Kode Perhitungan Tip

const inputTagihan = document.querySelector("#tagihan"); const inputPersen = document.querySelector("#persenTip"); const teksHasil = document.querySelector("#total"); const btnHitung = document.querySelector("#btnHitung"); btnHitung.addEventListener("click", function() { const tagihan = Number(inputTagihan.value); const persen = Number(inputPersen.value); const jumlahTip = tagihan * (persen / 100); const totalBayar = tagihan + jumlahTip; teksHasil.textContent = "Rp " + totalBayar.toLocaleString("id-ID"); });

3. Eksplorasi Praktik

1

Buat input form tagihan dan persentase

Sediakan dua elemen <input type="number"> untuk total harga dan persen tip, serta sebuah tombol hitung.

2

Ambil data menggunakan .value

Di dalam event klik tombol, akses nilai input lalu bungkus dengan Number() agar menjadi bilangan bulat atau desimal.

3

Terapkan rumus perhitungan

Hitung nominal tip terlebih dahulu: tagihan * (persen / 100), lalu tambahkan ke nominal tagihan awal.

4

Tampilkan hasil ke layar

Perbarui elemen penampil hasil dengan total biaya yang sudah dihitung secara akurat.

4. Kesalahan yang Sering Terjadi

  • Menghitung langsung dari input.value tanpa konversi tipe data angka.
  • Kolom input dibiarkan kosong saat diklik sehingga muncul hasil NaN (Not a Number).
  • Mengambil nilai input.value di luar fungsi klik, sehingga nilainya tidak pernah ter-update.
Selalu ambil properti .value di dalam fungsi event listener agar membaca nilai terbaru saat tombol ditekan.
