1. Operasi Pengolahan Array Modern

Data yang tersimpan di web sering kali perlu diolah kembali—misalnya diurutkan berdasarkan abjad/kuota, atau dijumlahkan seluruh total pesertanya untuk laporan statistik.

Method Array Operasi yang Dilakukan Hasil
map() Mengubah format setiap elemen array menjadi format baru Array baru dengan format yang telah diubah
reduce() Mengakumulasi/menjumlahkan seluruh nilai angka dalam array Satu nilai total (misal total kuota)
sort() Mengurutkan urutan elemen (berdasarkan angka atau huruf) Array yang tersusun urut dari kecil ke besar/sebaliknya
Method map() dan filter() menghasilkan array baru tanpa merusak data asli, sedangkan sort() mengubah susunan urutan langsung pada array aslinya.

2. Contoh Kode Mengolah Data Array

const dataEvent = [ { nama: "Lomba Robotik", kuota: 20 }, { nama: "Web Desain", kuota: 35 }, { nama: "Desain Poster", kuota: 15 } ]; // 1. Menghitung Total Kuota menggunakan reduce() const totalKuota = dataEvent.reduce((total, item) => total + item.kuota, 0); console.log("Total Kursi:", totalKuota); // Hasil: 70 // 2. Mengurutkan berdasarkan kuota terbanyak (sort) const urutKuota = [...dataEvent].sort((a, b) => b.kuota - a.kuota); // 3. Mengambil daftar nama saja menggunakan map() const daftarNama = dataEvent.map((item) => item.nama); console.log(daftarNama); // ["Lomba Robotik", "Web Desain", "Desain Poster"]

3. Eksplorasi Praktik

1

Hitung total ringkasan data

Gunakan reduce() untuk menghitung total kuota peserta dari semua kegiatan dan tampilkan hasilnya di elemen statistik.

2

Buat tombol pengurutan (Sort)

Sediakan tombol "Urutkan Abjad (A-Z)" dan "Urutkan Kuota Terbanyak" di atas daftar kartu.

3

Gunakan fungsi sort()

Saat tombol ditekan, jalankan fungsi sort() pada salinan array data lalu render ulang kartumu.

4

Tampilkan ringkasan statistik

Gunakan map() atau properti length untuk mencetak jumlah kegiatan aktif yang tersedia.

4. Kesalahan yang Sering Terjadi

  • Menggunakan sort() angka tanpa fungsi pembanding (misal: hanya array.sort()), yang menghasilkan urutan keliru seperti [10, 100, 25] karena diurutkan layaknya teks.
  • Lupa memberikan nilai awal 0 pada parameter kedua method reduce() saat menjumlahkan nilai properti objek.
  • Mengira map() berfungsi sama persis dengan forEach(); gunakan map() bila ingin menghasilkan kumpulan data baru.
Untuk mengurutkan angka dari kecil ke besar gunakan (a, b) => a - b, dan untuk mengurutkan dari besar ke kecil gunakan (a, b) => b - a.
