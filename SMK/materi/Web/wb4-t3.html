1. Memadukan Event Input dan Method filter()

Fitur pencarian instan (live search) memantau kata yang diketikkan pengguna melalui event input, menyaring daftar data menggunakan method filter(), lalu mencetak ulang hasil yang cocok ke layar.

Operasi Contoh Kode Fungsi
filter() data.filter(item => ...) Menyaring array dan menghasilkan array baru yang lolos syarat.
includes() teks.includes(kataKunci) Mengecek apakah kata kunci terdapat di dalam teks (true/false).
toLowerCase() teks.toLowerCase() Mengubah teks ke huruf kecil agar pencarian tidak terpengaruh huruf kapital.
Selalu ubah kata kunci pencarian dan data asli ke huruf kecil dengan toLowerCase() agar pencarian kata "web" tetap menemukan data "Web Desain".

3. Eksplorasi Praktik

1

Tambahkan kolom pencarian di HTML

Buat elemen input dengan atribut type="search" dan beri id, misalnya: id="inputCari".

2

Tangkap ketikan dengan event input

Pasang event listener input pada kolom pencarian dan ambil nilainya secara berkala.

3

Gunakan filter() dan includes()

Saring array utama berdasarkan kesesuaian judul kegiatan dengan kata kunci yang diketik.

4

Render ulang daftar kartu

Panggil kembali fungsi render kartumu dengan mengirimkan array hasil saringan sebagai argumen.

4. Kesalahan yang Sering Terjadi

  • Lupa menyamakan teks ke huruf kecil dengan toLowerCase(), sehingga pencarian huruf kecil tidak menemukan teks berhuruf kapital.
  • Menimpa array data asli secara permanen saat memfilter, sehingga saat kolom pencarian dihapus, data lama tidak bisa kembali.
  • Menggunakan event change alih-alih event input, sehingga hasil pencarian tidak muncul secara instan saat mengetik.
Simpan data sumber pada variabel array asli, dan gunakan variabel terpisah untuk menampung hasil filter() agar data awal tetap utuh.
