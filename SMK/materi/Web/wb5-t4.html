Rapikan dan Dokumentasi

Merapikan indentasi baris kode dan menulis dokumen README yang menjelaskan karyamu

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Mengapa Dokumentasi Sangat Penting?

Developer hebat dinilai bukan hanya dari berjalannya aplikasi, melainkan seberapa bersih kodenya dan seberapa jelas panduannya agar orang lain bisa menggunakannya.

Bagian README Informasi yang Ditulis
Judul & Deskripsi Nama web app dan penjelasan singkat tentang apa fungsinya.
Fitur Utama Daftar kemampuan kuis (misal: skor instan, pilihan ganda, tombol reset).
Cara Menjalankan Petunjuk membuka website (cukup buka index.html di browser).
Pembuat Nama lengkap pembuat dan asal sekolah.
File README.md adalah buku panduan pertama yang dibaca saat orang lain membuka repositori kodinganmu.

2. Contoh File README.md Sederhana

# Kuis Cerdas Web Development Aplikasi web kuis interaktif seputar HTML, CSS, dan JavaScript untuk siswa SMA/SMK. ## Fitur: - Kuis interaktif dengan skor real-time - Tata letak responsif di layar ponsel dan desktop - Peringatan warna untuk jawaban benar dan salah ## Cara Menggunakan: 1. Buka file `index.html` menggunakan browser Google Chrome atau Firefox. 2. Pilih salah satu jawaban dari pertanyaan yang tampil di layar. 3. Nilai akhir akan muncul di bagian bawah kuis. ## Dibuat Oleh: - Nama: [Nama Siswa] - Kelas: [Kelas / Sekolah]

3. Eksplorasi Praktik

1

Rapikan indentasi file HTML, CSS, dan JS

Gunakan fitur format otomatis di code editor (Shift + Alt + F di VS Code) agar spasi dan tab tersusun lurus.

2

Hapus sisa kode uji coba

Bersihkan baris console.log() yang tidak lagi dibutuhkan dan buang potongan kode yang tidak terpakai.

3

Beri komentar penjelas

Tambahkan 1–2 baris komentar di atas fungsi penting untuk menjelaskan fungsinya secara singkat.

4

Buat file README.md

Tuliskan nama kuis, tujuan, fitur utama, dan namamu sebagai pembuat karya di folder proyek.

4. Kesalahan yang Sering Terjadi

  • Menulis kode zig-zag tanpa indentasi spasi yang konsisten, sehingga sulit dibaca saat ada baris penutup yang kurang.
  • Menyimpan puluhan komentar dari kode gagal lama yang membuat file menjadi penuh dan membingungkan.
  • Tidak mencantumkan identitas dan penjelasan fitur pada file proyek.
Kode yang bersih (Clean Code) mencerminkan ketelitian dan profesionalisme seorang programmer.
