TASK 3 • SATU DIMENSI DENGAN FLEXBOX

Navbar dengan Flexbox

Menata bilah menu navigasi yang fleksibel dan seimbang menggunakan CSS Flexbox

1. Prinsip Satu Dimensi pada Flexbox

Flexbox adalah sistem tata letak satu dimensi (hanya fokus mengatur satu baris atau satu kolom dalam satu waktu). Ini sangat ideal untuk bilah navigasi (navbar) di dalam tag <header>.

Properti Flexbox Pengaruh pada Navbar
display: flex Mengaktifkan mode flexbox sehingga elemen anak berjajar menyamping.
justify-content: space-between Mendorong logo ke sudut kiri dan menu tautan ke sudut kanan.
align-items: center Meratakan logo dan menu tepat di tengah garis vertikal.
gap: 1.5rem Memberi jarak antar tautan menu tanpa perlu memberi margin manual.
Gunakan tag semantik <header> untuk membungkus area kepala halaman dan tag <nav> khusus untuk blok tautan menu.

2. Contoh Kode Navbar Flexbox

<!-- Struktur HTML --> <header class="main-header"> <div class="logo">EduEvent Hub</div> <nav> <ul class="nav-links"> <li><a href="#beranda">Beranda</a></li> <li><a href="#lomba">Daftar Lomba</a></li> <li><a href="#kontak">Kontak</a></li> </ul> </nav> </header> /* Aturan CSS Flexbox */ .main-header { display: flex; justify-content: space-between; align-items: center; padding: 1rem 2rem; background-color: #0f172a; } .nav-links { display: flex; list-style: none; gap: 1.5rem; }

3. Langkah Praktik

1

Buat elemen <header> dan <nav>

Susun logo dan daftar tautan menggunakan tag <header>, <nav>, dan list <ul>.

2

Jadikan header sebagai flex container

Tambahkan display: flex; justify-content: space-between; align-items: center; pada class header.

3

Bentuk menu tautan secara horizontal

Beri properti display: flex; gap: 1.5rem; list-style: none; pada elemen <ul> menu navigasi.

4

Hilangkan garis bawah tautan

Beri warna kontras terang pada tag <a> dan tambahkan text-decoration: none; agar rapi.

4. Kesalahan yang Sering Terjadi

  • Menuliskan justify-content: space-between pada tag <ul>, bukan pada tag <header>.
  • Lupa menghapus padding dan margin bawaan pada tag <ul> sehingga menu sedikit bergeser ke kanan.
  • Menggunakan trik lawas seperti float: left; yang membuat alur halaman rusak dan sulit dikelola.
Ingat: Flexbox bekerja pada elemen anak langsung (direct child). Properti flex container mengatur tata letak anak-anaknya.
