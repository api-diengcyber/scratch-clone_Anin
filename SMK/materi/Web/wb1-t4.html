MODUL SMK • SATU DIMENSI DENGAN FLEXBOX

Navbar dengan Flexbox

Menata bilah menu navigasi yang fleksibel dan seimbang menggunakan CSS Flexbox

Materi Lengkap: Layout Css

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Navbar dengan Flexbox, fokus utama kita adalah layout CSS. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. CSS layout menentukan posisi dan ukuran elemen. Flexbox cocok untuk mengatur elemen pada satu dimensi, sedangkan Grid cocok untuk baris dan kolom dua dimensi.

Contoh Sederhana

Flexbox dapat menyusun kartu secara horizontal dan membungkusnya ketika ruang sempit; Grid dapat membuat area kartu dalam beberapa kolom.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

display, flex, grid, container, item, gap, alignment, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan Flexbox untuk toolbar/nav/kumpulan item satu arah dan Grid untuk layout dua dimensi.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Prinsip Satu Dimensi pada Flexbox

Flexbox adalah sistem tata letak satu dimensi (hanya fokus mengatur satu baris atau satu kolom dalam satu waktu). Ini sangat ideal untuk bilah navigasi (navbar) di dalam tag <header>.

Properti Flexbox Pengaruh pada Navbar
display: flex Mengaktifkan mode flexbox sehingga elemen anak berjajar menyamping.
justify-content: space-between Mendorong logo ke sudut kiri dan menu tautan ke sudut kanan.
align-items: center Meratakan logo dan menu tepat di tengah garis vertikal.
gap: 1.5rem Memberi jarak antar tautan menu tanpa perlu memberi margin manual.
Gunakan tag semantik <header> untuk membungkus area kepala halaman dan tag <nav> khusus untuk blok tautan menu.

2. Contoh Kode Navbar Flexbox

<!-- Struktur HTML --> <header class="main-header"> <div class="logo">EduEvent Hub</div> <nav> <ul class="nav-links"> <li><a href="#beranda">Beranda</a></li> <li><a href="#lomba">Daftar Lomba</a></li> <li><a href="#kontak">Kontak</a></li> </ul> </nav> </header> /* Aturan CSS Flexbox */ .main-header { display: flex; justify-content: space-between; align-items: center; padding: 1rem 2rem; background-color: #0f172a; } .nav-links { display: flex; list-style: none; gap: 1.5rem; }

3. Eksplorasi Praktik

1

Buat elemen <header> dan <nav>

Susun logo dan daftar tautan menggunakan tag <header>, <nav>, dan list <ul>.

2

Jadikan header sebagai flex container

Tambahkan display: flex; justify-content: space-between; align-items: center; pada class header.

3

Bentuk menu tautan secara horizontal

Beri properti display: flex; gap: 1.5rem; list-style: none; pada elemen <ul> menu navigasi.

4

Hilangkan garis bawah tautan

Beri warna kontras terang pada tag <a> dan tambahkan text-decoration: none; agar rapi.

4. Kesalahan yang Sering Terjadi

  • Menuliskan justify-content: space-between pada tag <ul>, bukan pada tag <header>.
  • Lupa menghapus padding dan margin bawaan pada tag <ul> sehingga menu sedikit bergeser ke kanan.
  • Menggunakan trik lawas seperti float: left; yang membuat alur halaman rusak dan sulit dikelola.
Ingat: Flexbox bekerja pada elemen anak langsung (direct child). Properti flex container mengatur tata letak anak-anaknya.
