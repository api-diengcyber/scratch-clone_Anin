MODUL SMK • PENYIMPANAN BROWSER

Simpan di localStorage

Menyimpan data secara permanen di browser agar tidak hilang saat halaman di-refresh atau ditutup

Materi Lengkap: Penyimpanan Browser

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Simpan di localStorage, fokus utama kita adalah penyimpanan browser. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. localStorage menyimpan data berbentuk string di browser dan dapat dibaca kembali pada kunjungan berikutnya. Object/array biasanya perlu JSON.stringify dan JSON.parse.

Contoh Sederhana

localStorage.setItem("tema","gelap") menyimpan preferensi tema.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

localStorage, key, value, string, JSON.stringify, JSON.parse

1. Memahami localStorage dan Format JSON

Variabel biasa di JavaScript akan terhapus saat halaman di-refresh. localStorage bertindak sebagai media penyimpanan internal di browser pengguna yang hanya dapat menerima data berbentuk string (teks).

Perintah Kegunaan
JSON.stringify(data) Mengubah objek atau array JavaScript menjadi teks JSON agar bisa disimpan.
localStorage.setItem("kunci", teksJSON) Menyimpan data teks ke dalam penyimpanan browser.
localStorage.getItem("kunci") Mengambil kembali data teks yang tersimpan berdasarkan nama kuncinya.
JSON.parse(teksJSON) Mengubah kembali teks JSON menjadi objek atau array JavaScript yang bisa diolah.
Jembatan penyimpanan: Array/Objek → JSON.stringify() → localStorage → JSON.parse() → Array/Objek.

2. Contoh Kode Simpan dan Muat Data

// 1. Mengambil data yang tersimpan (atau array kosong jika belum ada) let daftarTugas = JSON.parse(localStorage.getItem("tugas_saya")) || []; // 2. Fungsi Menyimpan ke localStorage function simpanData() { localStorage.setItem("tugas_saya", JSON.stringify(daftarTugas)); } // 3. Menambah item baru lalu simpan function tambahTugas(namaTugas) { daftarTugas.push({ nama: namaTugas, status: "aktif" }); simpanData(); // Data permanen tersimpan di browser }

3. Eksplorasi Praktik

1

Muat data awal dari localStorage

Gunakan JSON.parse(localStorage.getItem(...)) || [] di awal file script agar data lama langsung terbaca saat halaman dibuka.

2

Simpan data setiap ada perubahan

Panggil localStorage.setItem("kunci", JSON.stringify(array)) setiap kali pengguna menambah atau menghapus tugas.

3

Render data yang tersimpan

Jalankan fungsi render daftar tugas menggunakan data yang berhasil dimuat dari storage tersebut.

4

Buktikan dengan me-refresh browser

Tambahkan 2 data baru, refresh halaman browser, dan pastikan data tidak hilang.

4. Kesalahan yang Sering Terjadi

  • Menyimpan array atau objek langsung tanpa JSON.stringify(), sehingga nilainya berubah menjadi teks rusak "[object Object]".
  • Lupa memberikan fallback || [] saat membaca data pertama kali, sehingga memicu error ketika storage masih bernilai null.
  • Mengubah data array tetapi lupa memanggil fungsi penyimpanan localStorage.setItem() kembali.
Kamu bisa memeriksa langsung isi data yang tersimpan dengan menekan F12 lalu membuka tab Application > Local Storage di browsermu.
