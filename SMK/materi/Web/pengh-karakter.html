Penghitung Karakter

Menghitung jumlah karakter dan mendeteksi sisa kuota teks secara langsung saat mengetik

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Memantau Perubahan Teks dengan Event "input"

Untuk mendeteksi setiap huruf atau spasi yang diketik pengguna secara instan, kita menggunakan event input. Panjang karakter teks diperoleh dari properti .length pada string.

Properti / Event Fungsi
event "input" Memicu fungsi setiap kali ada ketikan baru, penghapusan, atau paste teks.
teks.length Menghitung total karakter (huruf, angka, spasi, simbol).
element.classList Menambah atau menghapus class CSS saat batas karakter terlampaui.
Event input berjalan seketika saat tombol keyboard ditekan, berbeda dengan event change yang baru berjalan ketika pengguna keluar dari kotak input.

2. Contoh Kode Penghitung Teks

const pesan = document.querySelector("#pesan"); const infoKarakter = document.querySelector("#infoKarakter"); const batasMaksimal = 100; pesan.addEventListener("input", function() { const jumlahSaatIni = pesan.value.length; const sisa = batasMaksimal - jumlahSaatIni; infoKarakter.textContent = jumlahSaatIni + " / " + batasMaksimal + " karakter"; if (sisa < 10) { infoKarakter.style.color = "#f72585"; // Tanda peringatan merah } else { infoKarakter.style.color = "#0f172a"; } });

3. Eksplorasi Praktik

1

Buat elemen textarea dan penanda jumlah

Tambahkan elemen <textarea id="pesan"></textarea> dan sebuah tag <span id="infoKarakter"> di bawahnya.

2

Pasang event listener "input"

Dengarkan perubahan teks pada textarea secara langsung menggunakan event input.

3

Hitung panjang karakter

Ambil panjang teks dengan membaca properti pesan.value.length di dalam fungsi listener.

4

Perbarui tampilan dan tambahkan peringatan batas

Tampilkan rasio karakter terpakai dan ubah warna teks indikator jika kuota karakter hampir penuh.

4. Kesalahan yang Sering Terjadi

  • Menggunakan event change sehingga jumlah karakter tidak ter-update langsung saat mengetik.
  • Menghitung pesan.length alih-alih membaca nilai isinya: pesan.value.length.
  • Tidak memberi batas maksimal sehingga sisa kuota menghasilkan angka negatif.
Ingat: pesan adalah elemen HTML-nya, sedangkan teks di dalamnya disimpan pada properti pesan.value.
