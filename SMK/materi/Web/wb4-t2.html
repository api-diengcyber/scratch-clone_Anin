1. Memisahkan Data dari Tampilan

Daripada menuliskan belasan kartu statis secara manual di HTML, data disimpan di JavaScript dalam bentuk Array of Objects. Program kemudian membaca array ini dan mencetak kartu secara teratur.

Struktur Contoh Penulisan Kegunaan
Objek { nama: "Lomba Web", kuota: 20 } Menyimpan informasi lengkap dari satu item data.
Array Objek [ { ... }, { ... }, { ... } ] Menampung kumpulan data dalam satu daftar terurut.
forEach() data.forEach(item => { ... }) Menjalankan fungsi cetak HTML untuk setiap item dalam daftar.
Gunakan Template Literals (tanda backtick ` ` dan ${variabel}) untuk menyisipkan data objek langsung ke dalam struktur tag HTML kartu.

2. Contoh Kode Render Kartu

// 1. Daftar Data (Array of Objects) const dataEvent = [ { judul: "Desain Web 2026", kategori: "Frontend", kuota: 25 }, { judul: "Kuis Logika Dasar", kategori: "Algoritma", kuota: 40 }, { judul: "Keamanan Jaringan", kategori: "Cyber", kuota: 15 } ]; // 2. Fungsi Cetak ke Halaman const wadahKartu = document.querySelector("#wadahKartu"); function tampilkanKartu(daftar) { wadahKartu.innerHTML = ""; // Bersihkan wadah terlebih dahulu daftar.forEach((item) => { wadahKartu.innerHTML += \` <div class="kartu"> <span class="badge">\${item.kategori}</span> <h3>\${item.judul}</h3> <p>Tersedia \${item.kuota} kursi peserta</p> </div> \`; }); } tampilkanKartu(dataEvent);

3. Eksplorasi Praktik

1

Siapkan wadah penampung di HTML

Buat elemen pembungkus kosong di file HTML, misalnya: <div id="wadahKartu"></div>.

2

Buat array of objects di JavaScript

Susun array bernama dataEvent yang memuat minimal 3 objek dengan properti yang seragam (misal: judul, kategori, kuota).

3

Looping data dengan forEach()

Buat fungsi render yang membaca setiap objek di dalam array dan merangkai tag HTML kartu menggunakan template literals.

4

Panggil fungsi saat halaman terbuka

Jalankan fungsi render tersebut agar semua kartu muncul rapi secara otomatis saat web pertama kali dimuat.

4. Kesalahan yang Sering Terjadi

  • Lupa mengosongkan wadahKartu.innerHTML = "" sebelum loop, sehingga kartu bertambah ganda saat fungsi dipanggil ulang.
  • Salah menuliskan nama properti objek (misal di array tertulis judul, tetapi saat dicetak memanggil ${item.Judul}).
  • Menggunakan tanda petik biasa (' atau ") bukan tanda backtick (`), sehingga sintaks ${...} terbaca sebagai teks biasa.
Perhatikan penulisan huruf besar dan kecil (case-sensitive) pada properti objek JavaScript.
