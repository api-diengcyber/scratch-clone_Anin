Memastikan website ramah bagi penyandang disabilitas dan nyaman dibaca siapa pun

Materi Lengkap: Aksesibilitas Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Cek Aksesibilitas, fokus utama kita adalah aksesibilitas web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Aksesibilitas memastikan halaman dapat digunakan oleh sebanyak mungkin orang, termasuk pengguna keyboard atau pembaca layar. Struktur semantik, label, fokus, kontras, dan teks alternatif berperan penting.

Contoh Sederhana

Label yang terhubung dengan input membantu pembaca layar mengetahui fungsi kolom.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

accessibility, keyboard, focus, label, alt text, contrast, semantic HTML

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan selalu, bukan hanya ketika ada permintaan khusus.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Mengenal Aksesibilitas Web (A11y)

Aksesibilitas web memastikan teman-teman tunanetra yang memakai aplikasi pembaca layar (screen reader) serta pengguna yang memiliki keterbatasan penglihatan warna tetap bisa menikmati websitemu tanpa kesulitan.

Pilar Aksesibilitas Penerapan Manfaat
Teks Alternatif (Alt) Atribut alt="..." pada tag <img> Screen reader dapat membacakan maksud gambar kepada tunanetra
Kontras Warna Rasio warna teks dan background minimal 4.5:1 Teks tetap terbaca jelas di bawah terik matahari atau bagi yang rabun
Tag Semantik Pakai <button> bukan <div> Perangkat lunak memahami jenis tombol dan perintahnya
Standar internasional WCAG AA menetapkan rasio kontras teks biasa terhadap warna dasarnya minimal bernilai 4.5 : 1.

2. Contoh Kode Aksesibel

<!-- TIDAK AKSESIBEL --> <img src="lomba.jpg"> <div class="btn" style="color:#ccc; background:#fff;">Klik</div> <!-- AKSESIBEL --> <img src="lomba.jpg" alt="Siswa SMA sedang mempresentasikan proyek coding di atas panggung"> <button class="btn-daftar">Daftar Sekarang</button> /* CSS dengan kontras tinggi */ .btn-daftar { background-color: #0f172a; /* Latar sangat gelap */ color: #ffffff; /* Teks putih terang (Rasio > 10:1) */ }

3. Eksplorasi Praktik

1

Beri alt text deskriptif pada setiap gambar

Jelaskan secara singkat apa isi gambar tersebut, bukan sekadar menulis kata "gambar" atau "foto".

2

Periksa kontras warna teks

Pastikan tidak menggunakan warna teks abu-abu muda di atas warna putih atau warna biru muda di atas warna biru tua.

3

Gunakan elemen interaktif bawaan

Gunakan tag <button> untuk tombol aksi dan tag <a> untuk tautan pindah halaman.

4

Audit dengan Lighthouse

Buka tab Inspect > Lighthouse di browser Google Chrome, pilih kategori 'Accessibility', lalu jalankan pengujian.

4. Kesalahan yang Sering Terjadi

  • Menulis atribut kosong alt="" atau menamai gambar dengan nama filenya seperti alt="IMG_0192.jpg".
  • Warna teks terlalu pudar sehingga tidak terbaca oleh pengguna dengan keterbatasan penglihatan.
  • Menggunakan gambar yang berisi tulisan tanpa menuliskan ulang teks tersebut ke dalam atribut alt.
Jika sebuah gambar murni hanya hiasan latar belakang tanpa informasi penting, lebih baik pasang melalui CSS background-image.
