Mode Gelap (Dark Mode)

Menyesuaikan tampilan web secara otomatis dengan mode tema yang dipilih pengguna di HP/laptop

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Mendeteksi Tema dengan prefers-color-scheme

Banyak pengguna lebih nyaman membaca web dengan latar belakang gelap di malam hari agar mata tidak silau. CSS memiliki fitur untuk mendeteksi setelan tema bawaan perangkat pengguna secara langsung.

Fitur CSS Fungsi
prefers-color-scheme: dark Mendeteksi apakah sistem HP/laptop pengguna sedang mengaktifkan mode gelap
CSS Custom Properties (Variables) Menyimpan warna dalam variabel (misal: --bg-utama) agar mudah diganti sekaligus
Alih-alih menulis ulang seluruh kode CSS, cukup ganti nilai variabel warna di dalam blok media query mode gelap.

2. Contoh Kode CSS Mode Gelap Otomatis

/* 1. Warna Default: Mode Terang */ :root { --bg-halaman: #f8fafc; --bg-kartu: #ffffff; --teks-utama: #0f172a; --border-warna: #e2e8f0; } /* 2. Warna Otomatis saat HP/Laptop Mode Gelap */ @media (prefers-color-scheme: dark) { :root { --bg-halaman: #0b0f19; --bg-kartu: #1e293b; --teks-utama: #f8fafc; --border-warna: #334155; } } /* 3. Terapkan Variabel ke Elemen */ body { background-color: var(--bg-halaman); color: var(--teks-utama); } .kartu { background-color: var(--bg-kartu); border: 1px solid var(--border-warna); }

3. Eksplorasi Praktik

1

Tentukan variabel warna di :root

Deklarasikan nama variabel untuk latar belakang dan warna teks pada bagian atas file CSS.

2

Gunakan variabel pada elemen halaman

Ganti kode warna kaku pada body dan kartu menggunakan var(--nama-variabel).

3

Tambahkan media query prefers-color-scheme

Tulis aturan @media (prefers-color-scheme: dark) lalu ubah nilai variabel menjadi warna gelap.

4

Uji coba di browser

Ganti pengaturan tema laptopmu ke Dark Mode, dan perhatikan websitemu akan langsung berubah warna tanpa refresh.

4. Kesalahan yang Sering Terjadi

  • Memakai warna hitam pekat (#000000) murni yang kontrasnya terlalu tajam di mata; gunakan warna abu gelap seperti #0f172a.
  • Lupa mengubah warna teks sehingga tulisan hitam tidak terlihat di atas latar belakang yang berubah menjadi gelap.
  • Warna garis tepi (border) dibiarkan terang sehingga terlihat menyala aneh saat di mode gelap.
Pastikan kontras teks di mode gelap tetap memenuhi standar aksesibilitas agar teks tetap terbaca dengan jelas.
