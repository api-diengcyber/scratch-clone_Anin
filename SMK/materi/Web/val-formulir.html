Validasi Formulir

Mencegah pengiriman data kosong dan menampilkan pesan peringatan interaktif

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Mencegah Pengiriman Default dengan preventDefault()

Secara default, saat form dikirimkan browser akan me-refresh halaman. Kita harus menghentikan perilaku bawaan ini menggunakan event.preventDefault() agar JavaScript bisa memeriksa kelengkapan data terlebih dahulu.

Metode Validasi Fungsi
event.preventDefault() Membatalkan reload halaman saat form disubmit.
input.value.trim() Menghapus spasi kosong di awal dan akhir teks input.
Pengkondisian if (...) Memeriksa apakah isian kosong atau kurang dari syarat minimal.
Validasi form di sisi browser (client-side) memberikan respons cepat kepada pengguna sebelum data dikirim ke server.

2. Contoh Kode Validasi Form

const form = document.querySelector("#formDaftar"); const inputNama = document.querySelector("#nama"); const pesanError = document.querySelector("#error"); form.addEventListener("submit", function(event) { // 1. Cegah reload halaman event.preventDefault(); // 2. Ambil nilai input tanpa spasi kosong const nama = inputNama.value.trim(); // 3. Cek kondisi validasi if (nama === "") { pesanError.textContent = "Nama tidak boleh kosong!"; pesanError.style.color = "#f72585"; } else if (nama.length < 3) { pesanError.textContent = "Nama minimal terdiri dari 3 karakter!"; pesanError.style.color = "#f72585"; } else { pesanError.textContent = "Pendaftaran berhasil! Halo, " + nama; pesanError.style.color = "#4361ee"; form.reset(); // Kosongkan form kembali } });

3. Eksplorasi Praktik

1

Buat elemen <form> dan tempat pesan error

Sediakan elemen <form id="formDaftar">, input teks, tombol submit, serta tag <p id="error">.

2

Pasang listener submit dan preventDefault()

Dengarkan event submit pada form dan hentikan reload otomatis dengan event.preventDefault().

3

Periksa teks menggunakan if-else

Gunakan .trim() untuk memeriksa apakah input kosong atau panjang karakternya belum memenuhi syarat.

4

Tampilkan notifikasi hasil ke pengguna

Isi teks pesan error jika data salah, atau tampilkan pesan sukses jika semua kolom terisi dengan benar.

4. Kesalahan yang Sering Terjadi

  • Lupa menulis event.preventDefault() sehingga halaman ter-refresh dan pesan error langsung hilang.
  • Memasang event listener pada tombol dengan event click alih-alih event submit pada elemen <form>.
  • Tidak menggunakan .trim(), sehingga input yang hanya berisi spasi dianggap sah.
Selalu pasang listener pada elemen <form> dengan event submit agar validasi tetap berjalan saat pengguna menekan tombol Enter di keyboard.
