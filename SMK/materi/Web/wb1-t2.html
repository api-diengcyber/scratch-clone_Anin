Galeri Kartu

Menyusun galeri kartu konten mandiri menggunakan tag semantik <section> dan <article>

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Galeri Kartu, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Memilih Tag yang Tepat untuk Kartu

Dalam pembuatan daftar kegiatan atau katalog, hindari menggunakan tag <div> secara berlebihan. HTML menyediakan tag semantik yang langsung menjelaskan fungsi dari masing-masing bagian.

Tag Semantik Peran dalam Galeri
<section> Membungkus seluruh area galeri sebagai satu bagian tema konten.
<article> Membungkus masing-masing kartu info lomba karena isinya mandiri dan utuh.
<header> Menampung judul dan kategori di bagian atas kartu.
<footer> Menampung tombol aksi atau info tanggal di bagian dasar kartu.
Gunakan <article> jika konten di dalam kartu tetap masuk akal dan bernilai informasi meskipun dicabut dan dibaca terpisah dari halaman tersebut.

2. Contoh Kode Galeri Kartu

<!-- Struktur Semantik Galeri --> <section class="galeri-event"> <h2>Kompetisi Mendatang</h2> <article class="kartu-event"> <header> <span class="kategori">Web Dev</span> <h3>Lomba Frontend Siswa</h3> </header> <p>Bangun landing page menarik dalam waktu 24 jam.</p> <footer> <button>Lihat Detail</button> </footer> </article> </section>

3. Eksplorasi Praktik

1

Bungkus area dengan <section>

Buat tag <section> lengkap dengan heading judul bagian menggunakan <h2>.

2

Buat elemen kartu dengan <article>

Di dalam section, buat minimal 3 kartu kegiatan menggunakan tag <article>.

3

Terapkan tata letak fleksibel

Beri class pada section induk lalu atur menggunakan CSS display: flex; gap: 1.5rem; agar kartu berjejer horizontal.

4

Ratakan tombol kartu ke bawah

Atur kartu dengan display: flex; flex-direction: column; justify-content: space-between; agar letak tombol sejajar rapi.

4. Kesalahan yang Sering Terjadi

  • Menuliskan seluruh kartu menggunakan tag <div class="card"> tanpa ada tag semantik sama sekali.
  • Tidak memberi heading (<h2> atau <h3>) di dalam tag <section> atau <article>.
  • Membuat tinggi kartu berbeda-beda karena tidak mengunci distribusi ruang dengan flexbox.
Setiap elemen <section> idealnya memiliki minimal satu judul (heading) agar struktur outline dokumen terbaca jelas oleh mesin pencari.
