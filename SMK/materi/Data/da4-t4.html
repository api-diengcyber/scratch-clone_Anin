TASK 4 • EVALUASI MODEL

Hitung Akurasi

Mengukur seberapa pintar model kita dengan menghitung persentase tebakan yang benar pada data uji

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Rumus Evaluasi Akurasi

Akurasi (Accuracy) adalah metrik evaluasi paling umum dalam masalah klasifikasi untuk melihat seberapa sering tebakan model cocok dengan kenyataan aslinya.

Rumus:
Akurasi = (Jumlah Tebakan Benar / Total Data Uji) * 100%
Data Ke- Label Asli (Kunci) Prediksi Model Status
1 1 (Lulus) 1 (Lulus) Benar ✔
2 0 (Remedial) 1 (Lulus) Salah ❌
3 1 (Lulus) 1 (Lulus) Benar ✔
4 0 (Remedial) 0 (Remedial) Benar ✔

Dari 4 data uji di atas, terdapat 3 tebakan benar. Maka akurasinya adalah: (3 / 4) * 100% = 75%.

2. Contoh Kode Menghitung Akurasi

# Fungsi evaluasi akurasi def hitung_akurasi(label_asli, label_prediksi): if len(label_asli) == 0: return 0.0 benar = 0 for asli, tebakan in zip(label_asli, label_prediksi): if asli == tebakan: benar += 1 persentase = (benar / len(label_asli)) * 100 return persentase # Pengujian hasil model kunci_jawaban = [1, 0, 1, 1, 0] hasil_prediksi = [1, 0, 0, 1, 0] skor_akurasi = hitung_akurasi(kunci_jawaban, hasil_prediksi) print(f"Akurasi Model pada Data Uji: {skor_akurasi:.1f}%")

3. Eksplorasi Praktik

1

Jalankan model pada data uji

Masukkan fitur dari data uji ke dalam modelmu untuk mendapatkan list hasil tebakan (prediksi).

2

Bandingkan dengan fungsi zip()

Gunakan zip(label_asli, label_prediksi) untuk membandingkan pasangan data baris demi baris secara otomatis.

3

Hitung persentase keberhasilan

Bagi jumlah kecocokan benar dengan total panjang data uji lalu kalikan 100.

4

Analisis kesalahan

Cetak data mana saja yang salah tebak dan cari tahu penyebab kegagalannya.

4. Kesalahan yang Sering Terjadi

  • Menghitung akurasi hanya dari data latih dan langsung berpuas diri saat melihat angka 100%.
  • Jumlah elemen di list label asli dan list prediksi tidak sama (mengakibatkan pemotongan perbandingan).
  • Lupa mengalikan 100 sehingga nilai akurasi masih berupa desimal (0.8 bukan 80%).
Nilai akurasi data uji yang realistis biasanya berada di kisaran 75% – 95%. Akurasi sempurna 100% pada data nyata yang banyak justru patut dicurigai ada kebocoran data (*data leakage*).
