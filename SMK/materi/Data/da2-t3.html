Median dan Rentang

Menentukan nilai tengah tahan pencilan dan mengukur sebaran rentang data

Materi Lengkap: Statistik Deskriptif

Konsep dasar. Data adalah kumpulan fakta atau pengukuran yang dapat digunakan untuk menjawab pertanyaan. Analisis data dimulai dari pertanyaan yang jelas, kualitas data, pengolahan, lalu interpretasi hasil. Pada materi Median dan Rentang, fokus utama kita adalah statistik deskriptif. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Statistik deskriptif merangkum data. Mean adalah rata-rata, median nilai tengah setelah diurutkan, modus nilai yang paling sering muncul, dan rentang adalah selisih maksimum-minimum.

Contoh Sederhana

Data [60,70,70,80,100] memiliki median 70 dan modus 70; rata-rata 76.

1. Mengapa Median Lebih Tahan Outlier?

Jika satu siswa mendapat uang saku Rp1.000.000 sementara empat temannya hanya Rp10.000, rata-rata (mean) akan melonjak drastis dan tidak realistis. Median (nilai tengah) membagi data menjadi dua bagian yang sama besar setelah data diurutkan terlebih dahulu.

Kondisi Jumlah Data (n) Posisi Nilai Tengah Cara Menghitung
Ganjil (misal n = 5) Tepat satu angka di tengah Ambil indeks n // 2
Genap (misal n = 6) Dua angka berada di tengah Rata-rata dari dua nilai tengah tersebut
Rentang (Range) Ukuran sebaran data nilai_maksimum - nilai_minimum
Syarat mutlak Median: List wajib diurutkan terlebih dahulu dengan sorted(data) atau data.sort() sebelum mengambil indeks tengah.

2. Contoh Kode

def hitung_median(data): urut = sorted(data) # 1. Wajib urutkan data n = len(urut) tengah = n // 2 if n % 2 != 0: # Data Ganjil: ambil langsung angka tengah return urut[tengah] else: # Data Genap: jumlahkan dua angka tengah lalu bagi 2 return (urut[tengah - 1] + urut[tengah]) / 2 uang_saku = [10000, 15000, 12000, 1000000, 10000] med = hitung_median(uang_saku) rentang = max(uang_saku) - min(uang_saku) print("Data setelah diurutkan:", sorted(uang_saku)) print(f"Median Uang Saku : Rp{med:,.0f}") print(f"Rentang (Range) : Rp{rentang:,.0f}")

3. Eksplorasi Praktik

1

Kumpulkan data dengan pencilan

Buat list angka yang sengaja memuat satu nilai yang jauh lebih besar dari yang lain.

2

Urutkan data dengan sorted()

Simpan hasil pengurutan ke variabel list baru.

3

Terapkan logika ganjil/genap

Gunakan operator modulo n % 2 untuk menentukan cara pengambilan titik tengah.

4

Hitung sebaran rentang

Kurangkan nilai maksimum dengan nilai minimum untuk melihat lebar sebaran data.

4. Kesalahan yang Sering Terjadi

  • Mengambil nilai tengah tanpa mengurutkan list terlebih dahulu (menghasilkan angka sembarangan).
  • Pada data genap, lupa mengurangi indeks tengah pertama: indeks dua angka tengah adalah tengah - 1 dan tengah.
  • Mengira Rentang (Range) adalah fungsi bawaan Python range(); rentang statistik dihitung dengan max() - min().
Ingat: Python menggunakan zero-indexing (dimulai dari 0). Pada 4 data (indeks 0, 1, 2, 3), dua posisi tengahnya berada di indeks 1 dan 2.
