MODUL SMK • ALGORITMA K-NN

Jarak Terdekat (k-NN)

Menebak label data baru berdasarkan kesamaan sifat dengan tetangga terdekat di data latih

Materi Lengkap: Klasifikasi Dan Evaluasi Model

Konsep dasar. Data adalah kumpulan fakta atau pengukuran yang dapat digunakan untuk menjawab pertanyaan. Analisis data dimulai dari pertanyaan yang jelas, kualitas data, pengolahan, lalu interpretasi hasil. Pada materi Jarak Terdekat (k-NN), fokus utama kita adalah klasifikasi dan evaluasi model. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Klasifikasi memberikan label pada data berdasarkan pola. Data latih digunakan untuk belajar aturan/pola, data uji untuk mengukur performa pada data yang belum digunakan saat belajar. k-NN membandingkan kedekatan data baru dengan contoh yang sudah berlabel.

Contoh Sederhana

Jika tiga tetangga terdekat sebuah titik adalah dua “A” dan satu “B”, k-NN dengan k=3 cenderung memilih A.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

feature, label, training, testing, k-NN, distance, accuracy

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk masalah yang hasilnya berupa kategori dan memiliki contoh data berlabel.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan sumber, missing value, satuan, skala grafik, ukuran sampel, outlier, dan perbedaan antara korelasi dan sebab-akibat.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: langsung menghitung tanpa pertanyaan, grafik menyesatkan, mengabaikan data kosong, menyimpulkan terlalu jauh, dan memperlakukan data kecil sebagai gambaran seluruh populasi.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Filosofi k-Nearest Neighbors (k-NN)

Pernahkah kamu mendengar pepatah "Karakter seseorang mirip dengan teman-teman terdekatnya"? Begitulah cara kerja algoritma k-Nearest Neighbors (k-NN). Untuk menebak kategori data baru, komputer mencari titik data latih yang jarak fiturnya paling dekat, lalu meniru label tetangga tersebut.

Langkah Kerja k-NN Operasi Matematika Keterangan
1. Hitung Jarak Selisih Nilai: abs(x1 - x2) Menghitung seberapa mirip data baru dengan tiap contoh data latih
2. Urutkan Jarak Cari jarak terkecil (minimum) Menemukan tetangga yang karakteristiknya paling mirip
3. Ambil Keputusan Tiru label tetangga terdekat Prediksi data baru disamakan dengan label tetangga itu
Jika ada 1 tetangga terdekat (k=1), kita langsung menyalin labelnya. Jika k=3, kita mengambil suara terbanyak (voting) dari 3 tetangga terdekat.

2. Contoh Kode Klasifikasi Jarak Terdekat (1-NN)

# Data latih: (berat_gram, label) data_latih = [ (120, "Jeruk"), (130, "Jeruk"), (180, "Apel"), (195, "Apel") ] def prediksi_knn_sederhana(berat_baru, basis_data): tetangga_terdekat = None jarak_terpendek = float("inf") for berat_latih, label in basis_data: # Hitung selisih jarak absolut jarak = abs(berat_baru - berat_latih) if jarak < jarak_terpendek: jarak_terpendek = jarak tetangga_terdekat = label return tetangga_terdekat # Uji data buah misterius dengan berat 175 gram buah_misterius = 175 hasil = prediksi_knn_sederhana(buah_misterius, data_latih) print(f"Buah dengan berat {buah_misterius}g diprediksi adalah: {hasil}") # Hasil: Apel (karena 175 paling dekat ke 180)

3. Eksplorasi Praktik

1

Siapkan kumpulan titik data latih

Buat list berisi minimal 6 pasang angka fitur dan labelnya.

2

Gunakan fungsi abs() untuk jarak

Gunakan abs(nilai_baru - nilai_latih) untuk menghitung selisih jarak tanpa menghasilkan angka minus.

3

Temukan jarak minimum

Gunakan logika pembanding untuk menemukan data latih mana yang jaraknya paling kecil terhadap data baru.

4

Tebak labelnya

Ambil label dari tetangga terdekat tersebut sebagai hasil tebakan akhir modelmu.

4. Kesalahan yang Sering Terjadi

  • Lupa menggunakan fungsi abs() (nilai absolut), sehingga selisih negatif dianggap lebih kecil dari jarak positif nol.
  • Inisialisasi jarak_terpendek = 0; seharusnya diatur dengan angka sangat besar (seperti float("inf") atau 999999).
  • Jika ada 2 fitur (misal: berat dalam gram [100-200] dan panjang dalam meter [0.1-0.2]), fitur yang angkanya besar akan mendominasi perhitungan jarak bila tidak dinormalisasi.
Algoritma k-NN sangat mudah dipahami dan kuat karena tidak memerlukan asumsi rumus yang rumit.
