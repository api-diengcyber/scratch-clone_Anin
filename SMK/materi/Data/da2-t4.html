1. Library Bawaan Python: statistics

Setelah memahami rumus manualnya, kita dapat menggunakan modul bawaan Python yaitu statistics. Modul ini sudah teruji menangani kasus-kasus rumit seperti multimodus atau data bernilai genap secara otomatis.

Fungsi Operasi Statistik Contoh Panggilan
statistics.mean() Rata-rata aritmetika statistics.mean(data)
statistics.median() Titik nilai tengah statistics.median(data)
statistics.mode() Nilai frekuensi terbanyak (tunggal) statistics.mode(data)
statistics.stdev() Standar deviasi (penyimpangan data dari rata-rata) statistics.stdev(data)
Modul statistics adalah pustaka bawaan resmi (standard library). Kamu tidak perlu mengunduh atau menginstal apapun dengan pip, cukup tuliskan import statistics.

2. Contoh Kode

import statistics skor_peserta = [75, 80, 80, 85, 90, 95, 80, 70] # Menghitung seluruh metrik pemusatan data sekaligus rata = statistics.mean(skor_peserta) med = statistics.median(skor_peserta) mod = statistics.mode(skor_peserta) simpangan = statistics.stdev(skor_peserta) print("Hasil Modul Statistics:") print(f"- Mean : {rata:.2f}") print(f"- Median : {med}") print(f"- Modus : {mod}") print(f"- Standar Deviasi : {simpangan:.2f}")

3. Eksplorasi Praktik

1

Import modul statistics

Ketikkan import statistics di bagian paling atas skrip kodemu.

2

Siapkan kumpulan sampel data

Gunakan data berat badan atau data tinggi badan teman sekelasmu.

3

Eksekusi fungsi pemusatan data

Panggil statistics.mean(), statistics.median(), dan statistics.mode().

4

Hitung standar deviasi

Jalankan statistics.stdev() untuk mengetahui seberapa seragam skor yang diperoleh.

4. Kesalahan yang Sering Terjadi

  • Menamai file Python dengan nama statistics.py, yang menyebabkan Python bentrok dan mengimpor filemu sendiri alih-alih modul bawaan.
  • Menghitung standar deviasi pada data dengan sampel kurang dari 2 elemen (fungsi stdev() butuh minimal 2 data).
  • Salah mengeja nama modul, misal: import statistic (kurang huruf s di belakang).
Jangan pernah menamai file skripmu sama persis dengan nama modul bawaan Python agar tidak memicu AttributeError saat diimpor.
