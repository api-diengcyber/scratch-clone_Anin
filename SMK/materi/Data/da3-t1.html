Grafik Batang dari Div

Membangun diagram batang visual menggunakan elemen HTML murni dan persentase CSS

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Diagram Batang untuk Membandingkan Kategori

Diagram batang (bar chart) adalah visualisasi paling efektif untuk membandingkan jumlah atau nilai antarkategori. Panjang batang mewakili besaran angka, sehingga mata manusia bisa membedakan perbandingan nilai dalam hitungan detik tanpa membaca tabel angka satu per satu.

Komponen Grafik Elemen Pembentuk Fungsi
Label Kategori <span> / <p> Menyebutkan nama kelompok data yang dibandingkan (misal: nama jurusan)
Wadah Batang (Track) <div class="bar-bg"> Latar belakang abu-abu yang melambangkan kapasitas maksimal (100%)
Batang Isi (Fill) <div class="bar-fill"> Kotak berwarna dengan width: X% yang panjangnya sebanding dengan angka data
Label Nilai Teks angka di ujung batang Memastikan pembaca tahu nilai pasti di balik visualisasi
Gunakan properti CSS width: X% untuk grafik batang horizontal. Persentase dihitung dari: (nilai_saat_ini / nilai_maksimal) * 100%.

2. Contoh Kode Diagram Batang CSS

<!-- Struktur HTML --> <div class="chart-row"> <span class="label">RPL</span> <div class="bar-track"> <div class="bar-fill" style="width: 85%;">85 Siswa</div> </div> </div> <div class="chart-row"> <span class="label">TKJ</span> <div class="bar-track"> <div class="bar-fill" style="width: 60%;">60 Siswa</div> </div> </div> /* Aturan CSS */ .chart-row { display: flex; align-items: center; gap: 12px; margin-bottom: 10px; } .label { width: 60px; font-weight: 700; } .bar-track { flex-grow: 1; background-color: #e2e8f0; border-radius: 8px; overflow: hidden; } .bar-fill { background-color: #4361ee; color: #ffffff; padding: 6px 12px; font-size: 0.85rem; border-radius: 8px; transition: width 0.4s ease; }

3. Eksplorasi Praktik

1

Tentukan data kategori pembanding

Pilih data yang ingin dibandingkan (misal: jumlah peminat ekstrakurikuler Pramuka: 40, PMR: 25, Futsal: 80, Coding: 95).

2

Tentukan angka patokan maksimum

Ambil angka terbesar (95) sebagai batas acuan 100% untuk menghitung persentase lebar batang kategori lainnya.

3

Susun struktur flexbox horizontal

Buat div baris berisi label nama di kiri dan track batang di kanan menggunakan display: flex.

4

Terapkan inline style persentase

Isi properti style="width: X%;" pada elemen .bar-fill sesuai perhitungan masing-masing data.

4. Kesalahan yang Sering Terjadi

  • Menentukan panjang batang dengan piksel statis (width: 300px;), sehingga batang meluap keluar layar ponsel.
  • Skala perbandingan tidak proporsional (misal data 50 dan data 100 diberi panjang yang hampir mirip).
  • Lupa menyertakan label kategori atau teks angka, sehingga diagram hanya menjadi kotak warna tanpa makna.
Diagram batang wajib selalu dimulai dari angka dasar 0 pada sumbunya agar perbedaan panjang batang merefleksikan perbandingan asli tanpa manipulasi persepsi visual.
