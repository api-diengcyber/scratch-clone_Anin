Linear Search vs Binary Search

Menemukan data dengan cara mengecek satu per satu versus membelah dua data terurut

Materi Lengkap: Pencarian Data

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Linear Search vs Binary Search, fokus utama kita adalah pencarian data. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Linear Search memeriksa elemen dari awal sampai ditemukan, sedangkan Binary Search membagi ruang pencarian menjadi dua dan membutuhkan data yang sudah terurut.

Contoh Sederhana

Pada data [3, 7, 12, 18, 25], mencari 18 dengan pencarian linear mengecek 3, 7, 12, lalu 18. Binary Search dapat melihat nilai tengah, membandingkan, lalu membuang separuh bagian yang tidak mungkin.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

linear search, binary search, data terurut, indeks, kompleksitas

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan linear search untuk data kecil atau belum terurut; gunakan binary search saat data terurut dan jumlah pencarian cukup banyak.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Membandingkan Cara Mencari Data

Algoritma adalah rangkaian instruksi terstruktur untuk menyelesaikan masalah. Kinerja algoritma pencarian diukur dari seberapa banyak langkah pengecekan yang harus dilakukan sampai data ditemukan.

Metode Cara Kerja Syarat Data Efisiensi (1.000 Data)
Linear Search Mengecek elemen dari indeks pertama hingga terakhir secara berurutan. Bebas (acak atau urut) Bisa butuh hingga 1.000 langkah
Binary Search Membelah dua data terurut dan memeriksa nilai tengah secara berulang. Wajib sudah berurutan Maksimal sekitar 10 langkah saja
Binary search jauh lebih kencang dibanding linear search, namun hanya bisa bekerja jika data sudah terurut dari kecil ke besar.

2. Contoh Kode

# 1. Linear Search (Cek satu per satu) def linear_search(data, target): for i in range(len(data)): if data[i] == target: return i # Ketemu di indeks ke-i return -1 # Tidak ditemukan # 2. Binary Search (Belah dua data terurut) def binary_search(data_urut, target): kiri = 0 kanan = len(data_urut) - 1 while kiri <= kanan: tengah = (kiri + kanan) // 2 if data_urut[tengah] == target: return tengah elif data_urut[tengah] < target: kiri = tengah + 1 # Geser cari ke paruh kanan else: kanan = tengah - 1 # Geser cari ke paruh kiri return -1 angka = [12, 24, 35, 47, 59, 70, 88] print("Hasil Binary Search:", binary_search(angka, 47)) # Indeks 3

3. Eksplorasi Praktik

1

Tulis fungsi linear_search

Buat fungsi dengan perulangan for yang membandingkan setiap item dengan angka target.

2

Tulis fungsi binary_search

Gunakan pointer kiri, kanan, dan titik tengah dalam perulangan while.

3

Uji kedua fungsi pada list angka terurut

Jalankan kedua fungsi untuk mencari angka yang ada di tengah list dan angka yang tidak terdaftar sama sekali.

4

Hitung jumlah perbandingannya

Tambahkan variabel penghitung langkah (counter) di dalam loop untuk membuktikan efisiensi Binary Search.

4. Kesalahan yang Sering Terjadi

  • Menjalankan Binary Search pada data yang masih acak/belum diurutkan, sehingga menghasilkan jawaban tidak ditemukan meski angkanya ada.
  • Lupa memperbarui nilai kiri = tengah + 1 atau kanan = tengah - 1 sehingga memicu perulangan abadi (infinite loop).
  • Menggunakan pembagian biasa / alih-alih pembagian bulat // untuk menghitung indeks tengah.
Indeks list selalu berupa bilangan bulat. Gunakan tanda // agar hasil pembagian indeks tidak menghasilkan bilangan berkoma (float).
