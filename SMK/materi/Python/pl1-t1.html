Struktur Data: List, Tuple, Dict & Set

Memilih wadah data yang tepat untuk masalah yang tepat

Materi Lengkap: Struktur Data

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Struktur Data: List, Tuple, Dict & Set, fokus utama kita adalah struktur data. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Struktur data menentukan bagaimana banyak nilai disimpan dan diakses. List bersifat berurutan dan dapat diubah, tuple berurutan tetapi umumnya tidak diubah, set menyimpan anggota unik, dan dict memetakan key ke value.

Contoh Sederhana

Nilai siswa dapat disimpan sebagai list, koordinat tetap sebagai tuple, daftar kategori unik sebagai set, dan data siswa berdasarkan NIS sebagai dict.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

list, tuple, set, dictionary, key, value, indeks, mutable

1. Mengapa struktur data penting?

Program nyata mengelola banyak data: daftar siswa, stok barang, riwayat transaksi. Struktur data menentukan seberapa mudah dan cepat data itu disimpan, dicari, dan diubah.

Pertanyaan pemilihan: apakah data berurutan? bisa diubah? perlu dicari lewat nama (kunci)? boleh ada duplikat?

3. List dan dict: operasi utama

nilai = [80, 75, 90] nilai.append(85) # tambah di akhir nilai.remove(75) # hapus nilai 75 print(len(nilai), nilai[0], nilai[-1]) siswa = {"nama": "Rani", "kelas": "X-RPL"} siswa["umur"] = 16 # tambah/ubah kunci print(siswa.get("alamat", "-")) # aman bila kunci tidak ada for k, v in siswa.items(): print(k, "=", v)
KeyError: siswa["alamat"] error jika kunci tidak ada. Pakai .get() atau cek dengan in dulu.

4. Set dan tuple: kegunaan nyata

hadir = ["Ani", "Budi", "Ani", "Citra"] unik = set(hadir) print(len(unik)) # 3 a = {1, 2, 3}; b = {2, 3, 4} print(a & b, a | b, a - b) # irisan, gabungan, selisih titik = (3, 5) # tidak bisa diubah
  • Pengecekan x in set jauh lebih cepat daripada pada list besar.
  • Tuple aman dipakai sebagai kunci dict, list tidak bisa.

5. Pola penting

# daftar dict: bentuk umum data tabel barang = [{"nama": "Pensil", "stok": 20}, {"nama": "Buku", "stok": 5}] habis = [b["nama"] for b in barang if b["stok"] < 10] print(habis) # ['Buku']
Jangan menambah atau menghapus isi list saat sedang di-loop. Buat list baru atau loop pada salinannya.
