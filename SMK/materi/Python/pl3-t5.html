1. Menerima Argumen Dinamis

Terkadang kita tidak tahu persis berapa banyak data yang akan dikirim ke dalam fungsi. Python memiliki dua sintaks sakti: *args untuk argumen posisi beruntun, dan **kwargs untuk argumen bernama (kata kunci).

Sintaks Bentuk Data di Fungsi Kapan Digunakan?
*args (1 bintang) Tuple Saat ingin menerima banyak nilai tanpa nama (misal menjumlahkan 2, 5, atau 20 angka).
**kwargs (2 bintang) Dictionary Saat ingin menerima banyak data berlabel pasangan kunci-nilai (misal biodata profil).
Nama args dan kwargs adalah kesepakatan konvensi standar. Yang terpenting adalah tanda satu bintang (*) dan dua bintang (**) di depan nama parameternya.

2. Contoh Kode

# 1. Menggunakan *args (Menerima banyak angka) def hitung_total(*angka): total = sum(angka) return total print("Total 3 angka:", hitung_total(10, 20, 30)) # Output: 60 print("Total 5 angka:", hitung_total(5, 5, 10, 20, 50)) # Output: 90 # 2. Menggabungkan *args dan **kwargs def profil_lengkap(nama, *hobi, **informasi): print(f"Nama: {nama}") print(f"Hobi ({len(hobi)}): {', '.join(hobi)}") for kunci, nilai in informasi.items(): print(f"- {kunci}: {nilai}") profil_lengkap("Sarah", "Membaca", "Koding", kelas="X-RPL", kota="Semarang")

3. Eksplorasi Praktik

1

Buat fungsi penjumlah serbaguna dengan *args

Tulis fungsi jumlahkan(*bilangan) lalu lakukan iterasi loop atau gunakan fungsi sum().

2

Buat fungsi pencetak biodata dengan **kwargs

Tulis fungsi cetak_info(**data) dan telusuri datanya dengan data.items().

3

Padukan keduanya dalam satu fungsi

Buat fungsi yang memiliki parameter wajib di awal, lalu *args, kemudian **kwargs di akhir.

4

Uji coba dengan argumen beragam

Panggil fungsi tersebut dengan 1 argumen, 3 argumen biasa, dan beberapa argumen bernama (keyword argument).

4. Kesalahan yang Sering Terjadi

  • Menukar urutan penulisan parameter: **kwargs ditaruh sebelum *args (ini akan memicu SyntaxError!).
  • Lupa menulis tanda bintang saat deklarasi (menulis def f(args): biasa, yang berarti hanya menerima 1 variabel tunggal).
  • Mencoba mengubah nilai args di dalam fungsi (ingat: *args dikemas menjadi Tuple yang bersifat immutable).
Urutan wajib saat menyusun parameter lengkap: (1) Parameter Biasa, (2) *args, (3) Parameter Default, (4) **kwargs.
