1. Cara Kerja Bubble Sort

Dinamakan Bubble Sort (pengurutan gelembung) karena nilai terbesar perlahan-lahan "mengapung" ke ujung kanan list lewat serangkaian pertukaran pasangan data yang bersebelahan.

Langkah Pemeriksaan Pasangan yang Dibandingkan Aksi
1 [5, 2], 8, 1 5 > 2? Ya, tukar posisi menjadi [2, 5, 8, 1]
2 2, [5, 8], 1 5 > 8? Tidak, posisi tetap [2, 5, 8, 1]
3 2, 5, [8, 1] 8 > 1? Ya, tukar posisi menjadi [2, 5, 1, 8] (8 selesai di ujung)
Di Python, menukar posisi dua variabel sangat mudah dilakukan tanpa variabel penampung sementara: a, b = b, a.

2. Contoh Kode Bubble Sort

def bubble_sort(data): n = len(data) # Perulangan luar: jumlah putaran penuh for i in range(n): # Perulangan dalam: membandingkan pasangan bersebelahan for j in range(0, n - i - 1): if data[j] > data[j + 1]: # Tukar posisi data[j], data[j + 1] = data[j + 1], data[j] return data angka_acak = [64, 34, 25, 12, 22, 11, 90] print("Sebelum urut:", angka_acak) bubble_sort(angka_acak) print("Sesudah urut:", angka_acak)

3. Eksplorasi Praktik

1

Siapkan list angka yang acak

Buat variabel list dengan minimal 5 angka acak yang belum berurutan.

2

Gunakan perulangan bersarang (Nested Loop)

Gunakan loop luar untuk mengulang putaran dan loop dalam untuk menelusuri pasangan indeks j dan j+1.

3

Beri kondisi pertukaran nilai

Gunakan kondisi if data[j] > data[j+1] dan lakukan pertukaran posisi variabel.

4

Amati hasil cetak list

Cetak list hasil pengurutan ke konsol untuk memastikan data sudah berjejer rapi dari nilai terendah.

4. Kesalahan yang Sering Terjadi

  • Batas loop dalam ditulis range(n) sehingga memicu IndexError saat memanggil data[j+1] di indeks paling ujung.
  • Kondisi penukaran terbalik (misal menggunakan tanda < yang malah membuat urutan terbalik dari besar ke kecil).
  • Menukar nilai tanpa sintaks Python yang benar sehingga nilai salah satu variabel hilang tertimpa.
Gunakan batas range(0, n - i - 1) agar loop dalam tidak memeriksa elemen ujung kanan yang posisinya sudah pasti benar.
