Bandingkan Kecepatan

Mengukur jumlah langkah dan durasi waktu eksekusi pada kumpulan data skala besar

1. Mengapa Kecepatan Algoritma Diukur?

Pada data kecil (5–10 angka), semua algoritma terasa instan. Namun, ketika data mencapai ribuan atau jutaan item, perbedaan algoritma yang efisien dan tidak efisien akan terlihat nyata.

Ukuran Data Langkah Linear Search Langkah Binary Search
10 Data Maksimal 10 langkah Maksimal 4 langkah
1.000 Data Maksimal 1.000 langkah Maksimal 10 langkah
1.000.000 Data Maksimal 1.000.000 langkah Maksimal 20 langkah
Gunakan modul bawaan Python time untuk mengukur waktu eksekusi program dalam satuan detik secara presisi.

2. Contoh Kode Uji Kecepatan

import time # Siapkan 100.000 data angka terurut banyak_data = 100000 data_tes = list(range(banyak_data)) target = banyak_data - 1 # Angka paling terakhir # Uji 1: Linear Search mulai = time.time() linear_search(data_tes, target) selesai = time.time() durasi_linear = selesai - mulai print(f"Linear Search: {durasi_linear:.6f} detik") # Uji 2: Binary Search mulai = time.time() binary_search(data_tes, target) selesai = time.time() durasi_binary = selesai - mulai print(f"Binary Search: {durasi_binary:.6f} detik")

3. Langkah Praktik

1

Import module time

Tulis import time pada baris paling atas skrip kodemu.

2

Buat list data berukuran besar

Gunakan fungsi list(range(50000)) untuk menghasilkan list berisi puluhan ribu angka secara cepat.

3

Catat durasi sebelum dan sesudah

Simpan waktu awal dengan time.time(), jalankan fungsi pencarian, lalu kurangkan dengan waktu selesai.

4

Catat perbandingan pada tabel

Cetak hasil waktu kedua algoritma dan bandingkan selisih kecepatannya.

4. Kesalahan yang Sering Terjadi

  • Menguji kecepatan hanya pada 5 sampai 10 data sehingga waktu yang tercatat 0.000000 detik di kedua metode.
  • Menyertakan perintah print() di dalam loop saat tes kecepatan (fungsi print sangat lambat dan membuat pengukuran tidak akurat).
  • Menjalankan Binary Search pada list yang belum terurut selama proses uji coba benchmark.
Hapus atau nonaktifkan semua perintah print() di dalam fungsi pencarian saat kamu melakukan uji kecepatan waktu eksekusi.
