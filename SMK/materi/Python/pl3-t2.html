Rekursi Pertama

Memahami konsep fungsi yang memanggil dirinya sendiri dan pentingnya kasus dasar (base case)

Materi Lengkap: Rekursi

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Rekursi Pertama, fokus utama kita adalah rekursi. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Fungsi rekursif memanggil dirinya sendiri dengan masalah yang lebih kecil. Rekursi harus memiliki base case agar pemanggilan berhenti.

Contoh Sederhana

Fibonacci dapat didefinisikan F(0)=0, F(1)=1, dan F(n)=F(n-1)+F(n-2).

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

rekursi, base case, recursive case, call stack

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan saat masalah secara alami dapat dipecah menjadi submasalah sejenis; untuk masalah besar pertimbangkan efisiensi dan batas stack.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Apa itu Fungsi Rekursif?

Rekursi terjadi ketika suatu fungsi memanggil dirinya sendiri untuk menyelesaikan bagian masalah yang lebih kecil. Agar pemanggilan tidak berlangsung selamanya, fungsi rekursif wajib memiliki kasus dasar (base case) sebagai syarat berhenti.

Komponen Rekursi Peran Contoh pada Faktorial (5!)
Kasus Dasar (Base Case) Kondisi penghenti agar fungsi tidak memanggil dirinya lagi Jika n == 1, kembalikan 1
Langkah Rekursif (Recursive Step) Memanggil fungsi itu sendiri dengan argumen yang nilainya mengecil Kembalikan n * faktorial(n - 1)
Tanpa kasus dasar (base case), fungsi rekursif akan memanggil dirinya tanpa henti hingga memori komputer penuh dan memicu error RecursionError.

2. Contoh Kode

# Menghitung Faktorial: n! = n * (n-1) * ... * 1 def faktorial(n): # 1. KASUS DASAR (Titik Berhenti) if n <= 1: return 1 # 2. LANGKAH REKURSIF (Memanggil diri sendiri dengan masalah lebih kecil) return n * faktorial(n - 1) print("Faktorial 5:", faktorial(5)) # 5 * 4 * 3 * 2 * 1 = 120 print("Faktorial 3:", faktorial(3)) # 3 * 2 * 1 = 6

3. Eksplorasi Praktik

1

Tentukan kasus dasar (base case)

Tulis kondisi if n <= 1: return 1 di baris pertama badan fungsi.

2

Tulis pemanggilan rekursif

Kalikan parameter n dengan hasil pemanggilan fungsi terhadap nilai (n - 1).

3

Lakukan simulasi hitung mundur

Buat fungsi kedua hitung_mundur(n) yang mencetak angka n lalu memanggil hitung_mundur(n - 1) hingga mencapai 0.

4

Uji coba eksekusi

Jalankan fungsi dengan angka kecil (misal: 4 atau 5) dan amati urutan pemanggilannya.

4. Kesalahan yang Sering Terjadi

  • Lupa menulis kasus dasar (base case) sehingga terjadi RecursionError: maximum recursion depth exceeded.
  • Parameter pemanggilan rekursif tidak mengecil (misal memanggil faktorial(n) bukan faktorial(n - 1)).
  • Lupa kata kunci return saat memanggil fungsi rekursif, sehingga menghasilkan nilai None.
Pastikan setiap pemanggilan rekursif membawa argumen yang bergerak mendekati kondisi kasus dasar (base case).
