TASK 5 • MANIPULASI DATA JSON

Muat dan Ubah JSON

Membaca file data JSON yang ada, memodifikasinya di memori, dan menyimpannya kembali secara permanen

1. Siklus Lengkap: Muat, Ubah, Simpan

Aplikasi seperti game atau pencatat inventaris bekerja dengan siklus: (1) Muat data lama dari file ke memori, (2) Modifikasi nilai sesuai aksi pengguna, dan (3) Tulis ulang data baru ke file agar perubahan tersimpan permanen.

Tahap Alur Fungsi Python Aksi yang Terjadi
1. Baca Data json.load(file) Membaca file .json dan mengubahnya langsung menjadi dict/list Python.
2. Modifikasi Manipulasi Dict / List biasa Menambah kunci baru, memperbarui skor, atau menambahkan item list.
3. Tulis Ulang json.dump(data, file) Menimpa file dengan versi data yang sudah diperbarui.
Kombinasikan dengan blok try/except agar program otomatis membuat file JSON baru dengan data kosong jika filenya belum pernah dibuat sebelumnya.

2. Contoh Kode Update Data JSON

import json nama_file = "inventaris.json" # TAHAP 1: Muat data lama (dengan penanganan jika file belum ada) try: with open(nama_file, "r", encoding="utf-8") as f: data_game = json.load(f) except (FileNotFoundError, json.JSONDecodeError): # Data default jika file belum dibuat atau kosong data_game = {"koin": 100, "item": []} # TAHAP 2: Ubah data di memori Python data_game["koin"] += 50 # Tambah koin data_game["item"].append("Tameng Besi") # Tambah item baru # TAHAP 3: Tulis ulang data yang sudah diupdate ke file with open(nama_file, "w", encoding="utf-8") as f: json.dump(data_game, f, indent=4) print("Inventaris berhasil diperbarui!") print(f"Koin sekarang: {data_game['koin']}, Total item: {len(data_game['item'])}")

3. Langkah Praktik

1

Buat fungsi muat_data() yang aman

Gunakan try: json.load() dengan penanganan FileNotFoundError untuk mengembalikan dictionary awal jika file belum ada.

2

Tambahkan data baru lewat program

Tanyakan input nama barang baru dari pengguna dengan input() lalu tambahkan ke list inventaris.

3

Simpan kembali ke file JSON

Buka kembali file dalam mode "w" dan jalankan json.dump(data, f, indent=4).

4

Jalankan program berulang kali

Jalankan skrip 2 sampai 3 kali, dan amati bahwa data lama tidak hilang melainkan terus bertambah di dalam file inventaris.json.

4. Kesalahan yang Sering Terjadi

  • Membuka file dengan mode "w" saat berniat membaca, yang langsung mengosongkan file sebelum sempat dibaca dengan json.load().
  • File JSON kosong (0 bytes) dibuka dengan json.load() yang memicu error json.decoder.JSONDecodeError.
  • Mengubah dictionary di memori tetapi lupa menuliskan blok json.dump() untuk menyimpannya kembali ke file fisik.
Ingat urutan langkah: buka baca ("r") terlebih dahulu → ubah variabel di memori → baru kemudian buka tulis ("w") untuk menyimpan pembaruan.
