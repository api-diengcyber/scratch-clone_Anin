Dict Bertingkat

Menyusun basis data profil siswa lengkap dengan dictionary di dalam dictionary

Materi Lengkap: Struktur Data

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Dict Bertingkat, fokus utama kita adalah struktur data. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Struktur data menentukan bagaimana banyak nilai disimpan dan diakses. List bersifat berurutan dan dapat diubah, tuple berurutan tetapi umumnya tidak diubah, set menyimpan anggota unik, dan dict memetakan key ke value.

Contoh Sederhana

Nilai siswa dapat disimpan sebagai list, koordinat tetap sebagai tuple, daftar kategori unik sebagai set, dan data siswa berdasarkan NIS sebagai dict.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

list, tuple, set, dictionary, key, value, indeks, mutable

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Pilih struktur berdasarkan kebutuhan akses, perubahan data, dan keunikan nilai.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Menyusun Data Bertingkat (Hierarkis)

Dalam aplikasi nyata, sebuah data sering kali memiliki cabang rincian. Nested Dictionary (dictionary bertingkat) memungkinkan kita menyimpan dictionary atau list lain di dalam satu nilai kunci.

Struktur Contoh Akses Artinya
Tingkat 1 (Kunci Utama) data["SISWA01"] Mengambil seluruh data milik siswa dengan ID SISWA01.
Tingkat 2 (Kunci Rincian) data["SISWA01"]["nama"] Mengambil nama lengkap siswa tersebut.
Tingkat 3 (Nilai List) data["SISWA01"]["nilai"][0] Mengambil nilai ujian pertama milik siswa tersebut.
Akses data bertingkat dilakukan dengan menyambungkan kurung siku: kamus[kunci_luar][kunci_dalam].

2. Contoh Kode

# Database Mini Siswa database_siswa = { "101": { "nama": "Rian Hidayat", "kelas": "X-RPL 1", "nilai": [85, 90, 88] }, "102": { "nama": "Sarah Amelia", "kelas": "X-RPL 2", "nilai": [92, 95, 90] } } # 1. Mengakses nama siswa 101 print("Nama:", database_siswa["101"]["nama"]) # 2. Menghitung rata-rata nilai siswa 102 daftar_nilai = database_siswa["102"]["nilai"] rata_rata = sum(daftar_nilai) / len(daftar_nilai) print(f"Rata-rata Sarah: {rata_rata:.1f}") # 3. Menambahkan data siswa baru ke database database_siswa["103"] = { "nama": "Bayu Aji", "kelas": "X-TKJ", "nilai": [78, 82, 80] }

3. Eksplorasi Praktik

1

Rancang database bertingkat

Buat dictionary bernama database_siswa dengan kunci berupa nomor induk/ID siswa.

2

Isi rincian tiap siswa

Di dalam setiap ID, buat dictionary baru yang memuat informasi nama, kelas, dan list nilai.

3

Panggil data bersarang secara presisi

Cetak nama dan kelas siswa tertentu menggunakan dua kurung siku berturut-turut.

4

Hitung data nilai dari list bersarang

Ambil list nilai milik siswa pertama dan hitung nilai rata-ratanya menggunakan sum() dan len().

4. Kesalahan yang Sering Terjadi

  • Menuliskan koma di dalam satu kurung siku seperti data["101", "nama"]; penulisan yang benar adalah memisahkannya: data["101"]["nama"].
  • Salah eja pada kunci bersarang (misal menulis "Nama" dengan huruf kapital padahal kuncinya adalah "nama").
  • Lupa menutup kurung kurawal pembungkus luar saat menuliskan banyak data siswa.
Susun kode dengan indentasi (tab) yang rapi ke bawah agar kamu tidak bingung membedakan antara dictionary luar dan dictionary bagian dalam.
