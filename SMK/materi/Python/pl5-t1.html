Materi Lengkap: Pemrograman Berorientasi Objek

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi OOP Lanjutan, fokus utama kita adalah pemrograman berorientasi objek. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. OOP mengelompokkan data dan perilaku ke dalam object. Class menjadi cetak biru, object adalah instance, inheritance mewariskan perilaku, polymorphism memungkinkan antarmuka yang sama memiliki perilaku berbeda, encapsulation membatasi cara data diakses, dan composition menyusun object dari object lain.

Contoh Sederhana

Class Hewan dapat memiliki method suara(). Kucing dan Anjing dapat memberikan implementasi suara() yang berbeda.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

class, object, attribute, method, constructor, inheritance, polymorphism, encapsulation, composition

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

1. Enkapsulasi: menjaga data tetap aman

Enkapsulasi berarti data object tidak diubah sembarangan dari luar; perubahan lewat method yang bisa memeriksa aturan.

class Rekening: def __init__(self, pemilik, saldo=0): self.pemilik = pemilik self._saldo = saldo # awalan _ : jangan diubah langsung @property def saldo(self): return self._saldo def setor(self, jumlah): if jumlah <= 0: raise ValueError("Jumlah harus positif") self._saldo += jumlah def tarik(self, jumlah): if jumlah > self._saldo: print("Saldo tidak cukup") return False self._saldo -= jumlah return True def __str__(self): return f"{self.pemilik}: Rp{self._saldo:,}" r = Rekening("Rani", 100000) r.setor(50000) print(r) # Rani: Rp150,000 print(r.saldo) # 150000 lewat property
Python tidak benar-benar mencegah akses ke _saldo. Awalan garis bawah adalah kesepakatan antar programmer. Aturan seperti saldo tidak boleh negatif ditaruh di method.

2. Polimorfisme

Polimorfisme: nama method sama, perilaku berbeda tergantung class-nya. Pemanggil tidak perlu mengecek jenis object.

class Bentuk: def luas(self): raise NotImplementedError("Class turunan harus menimpa luas()") class Persegi(Bentuk): def __init__(self, sisi): self.sisi = sisi def luas(self): return self.sisi ** 2 class Lingkaran(Bentuk): def __init__(self, r): self.r = r def luas(self): return 3.14159 * self.r ** 2 bentuk = [Persegi(4), Lingkaran(3), Persegi(2)] print(sum(b.luas() for b in bentuk)) # satu perulangan untuk semua jenis
Tambah class Segitiga baru nanti, perulangan di atas tidak perlu diubah. Itulah manfaat polimorfisme.
