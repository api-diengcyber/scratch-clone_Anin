TASK 2 • SERIALISASI DATA JSON

Simpan Data JSON

Menyimpan data dictionary dan list kompleks ke format standar pertukaran data JSON

1. Mengapa Menggunakan Format JSON?

Jika kita menyimpan dictionary langsung dengan file.write(str(data)), teks tersebut akan sulit dibaca ulang sebagai struktur data. JSON (JavaScript Object Notation) adalah format teks standar universal yang digunakan untuk menyimpan dan bertukar data antar bahasa pemrograman.

Fungsi Modul json Operasi Keluaran / Hasil
json.dump(data, file) Menyimpan struktur data Python langsung ke dalam file. File berformat .json tersimpan di disk
json.dumps(data) Mengubah struktur data Python menjadi string teks di memori. Variabel bertipe string (teks JSON)
Gunakan parameter indent=4 pada fungsi json.dump() agar file teks JSON yang dihasilkan memiliki spasi indentasi rapi dan mudah dibaca oleh manusia.

2. Contoh Kode Menyimpan JSON

import json # Data kompleks: dictionary berisi list dan nested dict data_profil = { "username": "cyber_ninja", "level": 15, "status_aktif": True, "item_inventaris": ["Pedang Kayu", "Ramuan HP", "Kunci Emas"], "statistik": { "menang": 42, "kalah": 3 } } # Menyimpan data langsung ke file 'pemain.json' with open("pemain.json", "w", encoding="utf-8") as file_json: json.dump(data_profil, file_json, indent=4) print("Data pemain berhasil disimpan ke format pemain.json!")

3. Langkah Praktik

1

Import modul json

Tuliskan import json di baris paling atas skrip kodemu.

2

Rancang struktur data dictionary

Buat dictionary berisi identitas siswa lengkap dengan list hobi dan nilai pelajaran.

3

Tulis ke file dengan json.dump()

Buka file siswa.json dalam mode "w", lalu simpan datamu menggunakan json.dump(data, file, indent=4).

4

Periksa file hasil di folder

Buka file siswa.json menggunakan text editor dan perhatikan bahwa formatnya tersusun rapi dengan kurung kurawal dan kurung siku.

4. Kesalahan yang Sering Terjadi

  • Tertukar antara json.dump() (untuk file fisik) dan json.dumps() (untuk string di memori).
  • Mencoba menyimpan tipe data yang tidak didukung JSON murni, seperti objek set (ubah set menjadi list terlebih dahulu sebelum disimpan).
  • Nilai boolean Python True / False diubah manual jadi string, padahal json.dump() otomatis mengubahnya ke standar JSON true / false.
JSON hanya mendukung tipe data standar: string, number, boolean, list (array), dict (object), dan None (null).
