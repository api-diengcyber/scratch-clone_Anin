Metode List

Menyisipkan, menghapus elemen, membalik urutan, dan mengurutkan data list secara efisien

Materi Lengkap: Struktur Data

1. Beragam Method Bawaan List

Python menyediakan fungsi bawaan (method) yang mempermudah manipulasi antrean dan urutan data di dalam list tanpa perlu perulangan manual.

Method Contoh Perintah Hasil / Efek
insert() data.insert(1, "Budi") Menyisipkan item ke posisi indeks tertentu tanpa menimpa data lama.
pop() data.pop() / data.pop(0) Mengambil sekaligus menghapus elemen terakhir atau elemen pada indeks tertentu.
remove() data.remove("Budi") Menghapus elemen berdasarkan kesamaan nilainya.
sort() data.sort() Mengurutkan item dari terkecil ke terbesar (A-Z atau 0-9).
reverse() data.reverse() Membalikkan urutan isi list dari belakang ke depan.
Method pop() sangat bermanfaat untuk simulasi antrean, karena ia menghapus item sekaligus mengembalikan nilai yang dihapus ke dalam variabel.

2. Contoh Kode

# Simulasi Antrean Pasien antrean = ["Rina", "Dedi", "Fajar"] # 1. Pasien darurat masuk di urutan kedua (indeks 1) antrean.insert(1, "Maya") print("Setelah disisipkan:", antrean) # ['Rina', 'Maya', 'Dedi', 'Fajar'] # 2. Pasien pertama dipanggil ke ruangan (dihapus dari antrean) pasien_masuk = antrean.pop(0) print(f"Sedang dilayani: {pasien_masuk}") # 3. Mengurutkan nama pasien sisa sesuai abjad antrean.sort() print("Antrean urut abjad:", antrean)

3. Eksplorasi Praktik

1

Buat list data acak

Buat list angka atau nama yang urutannya sengaja dibuat tidak beraturan.

2

Sisipkan item dengan .insert()

Tambahkan sebuah elemen baru tepat di posisi indeks tertentu.

3

Keluarkan data dengan .pop()

Ambil elemen pertama dengan .pop(0) dan simpan ke variabel tersendiri.

4

Urutkan dengan .sort()

Panggil .sort() untuk merapikan seluruh isi list secara otomatis.

4. Kesalahan yang Sering Terjadi

  • Menuliskan hasil = data.sort(); method sort() langsung mengubah list asli di tempat dan menghasilkan nilai None. Cukup tulis data.sort().
  • Muncul ValueError saat menggunakan .remove("nama") pada item yang ternyata tidak ada di dalam list.
  • Tertukar urutan argumen pada insert(indeks, nilai); letakkan indeks terlebih dahulu sebelum nilainya.
Jika ingin mengurutkan dari besar ke kecil (kebalikan), gunakan parameter data.sort(reverse=True).
