1. Konsep Pasangan Key-Value pada Dictionary

Jika list menggunakan indeks nomor (0, 1, 2), Dictionary (dict) menggunakan nama pengenal berupa Key untuk mengakses datanya (Value). Dictionary ditandai dengan kurung kurawal {}.

Operasi Dict Contoh Kode Penjelasan
Membuat Dict kontak = {"Budi": "08123"} "Budi" adalah key, "08123" adalah value.
Akses Data kontak["Budi"] Mengambil nomor telepon milik Budi.
Tambah / Ubah kontak["Andi"] = "08567" Jika belum ada akan dibuat, jika sudah ada akan ditimpa.
Akses Aman kontak.get("Siti", "Kosong") Mencegah error saat nama kontak tidak ditemukan.
Gunakan Dictionary jika data yang kamu miliki membutuhkan label identitas (seperti nama orang, kode barang, atau username).

2. Contoh Kode

# 1. Membuat dictionary buku telepon buku_telepon = { "Andi": "08123456789", "Budi": "08567890123", "Citra": "08789012345" } # 2. Menambah kontak baru buku_telepon["Dewi"] = "08991122334" # 3. Mencari kontak dengan method get() nama_cari = "Budi" nomor = buku_telepon.get(nama_cari, "Nomor tidak ditemukan") print(f"Kontak {nama_cari}: {nomor}") # 4. Menampilkan seluruh kontak dengan loop for nama, no_hp in buku_telepon.items(): print(f"- {nama}: {no_hp}")

3. Eksplorasi Praktik

1

Inisialisasi dictionary kontak

Buat variabel buku_telepon berisi minimal 3 pasang nama teman dan nomor HP.

2

Tambahkan kontak baru

Masukkan satu nama dan nomor baru dengan cara mengisi kunci baru: buku_telepon["Nama"] = "Nomor".

3

Cari kontak dengan .get()

Cari salah satu nomor menggunakan .get() agar program tetap aman dan tidak error saat nama tidak ada.

4

Cetak seluruh buku telepon

Gunakan perulangan for nama, no in buku_telepon.items(): untuk mencetak semua kontak ke terminal.

4. Kesalahan yang Sering Terjadi

  • Muncul KeyError saat memanggil kunci yang belum pernah dibuat dengan kurung siku buku_telepon["X"].
  • Kunci (Key) ganda: jika kamu menulis nama yang sama dua kali, data sebelumnya akan tertimpa karena Key harus unik.
  • Lupa menuliskan method .items() saat melakukan perulangan untuk mengambil pasangan key dan value sekaligus.
Gunakan selalu dict.get(key, nilai_cadangan) jika kamu tidak yakin apakah kunci tersebut sudah terdaftar atau belum.
