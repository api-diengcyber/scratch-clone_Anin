Enkapsulasi

Melindungi atribut penting dari modifikasi langsung di luar class menggunakan akses privat

Materi Lengkap: Pemrograman Berorientasi Objek

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Enkapsulasi, fokus utama kita adalah pemrograman berorientasi objek. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. OOP mengelompokkan data dan perilaku ke dalam object. Class menjadi cetak biru, object adalah instance, inheritance mewariskan perilaku, polymorphism memungkinkan antarmuka yang sama memiliki perilaku berbeda, encapsulation membatasi cara data diakses, dan composition menyusun object dari object lain.

1. Mengapa Perlu Enkapsulasi?

Jika saldo bank dibiarkan terbuka (publik), kode lain bisa mengubahnya secara sengaja atau tidak sengaja menjadi angka negatif. Enkapsulasi membungkus dan mengunci data di dalam objek menggunakan awalan dua garis bawah __, sehingga hanya bisa dibaca atau diubah melalui method resmi yang memiliki validasi.

Jenis Akses Contoh Penulisan Akses dari Luar Class
Publik (Biasa) self.nama = "Andi" Bisa dibaca dan diubah secara bebas langsung
Privat (Enkapsulasi) self.__saldo = 50000 Terkunci, hanya bisa diakses via method Getter dan Setter
Getter adalah method untuk membaca nilai atribut privat, sedangkan Setter adalah method untuk mengubah nilainya setelah lolos pengecekan logika.

2. Contoh Kode

class DompetDigital: def __init__(self, pemilik, saldo_awal): self.pemilik = pemilik self.__saldo = saldo_awal # Atribut privat (__saldo) # Getter: membaca saldo dengan aman def get_saldo(self): return self.__saldo # Setter: menambah saldo dengan validasi def top_up(self, jumlah): if jumlah > 0: self.__saldo += jumlah print(f"Berhasil isi saldo: Rp{jumlah:,}") else: print("Gagal: Nominal isi saldo harus lebih dari 0!") dompet = DompetDigital("Rian", 50000) dompet.top_up(25000) print("Saldo akhir:", dompet.get_saldo()) # Mencoba merusak saldo langsung dari luar akan gagal / memicu AttributeError # print(dompet.__saldo) -> Error!

3. Eksplorasi Praktik

1

Buat atribut privat

Deklarasikan atribut dengan dua garis bawah self.__saldo di dalam constructor class.

2

Buat method Getter

Tulis method get_saldo(self) yang hanya bertugas mengembalikan nilai self.__saldo.

3

Buat method Setter dengan logika validasi

Tulis method tarik_tunai(self, nominal) yang memeriksa apakah saldo mencukupi sebelum memotong saldo.

4

Buktikan keamanan enkapsulasi

Coba akses objek.__saldo secara langsung di baris pemanggil dan perhatikan bahwa Python melindunginya.

4. Kesalahan yang Sering Terjadi

  • Hanya memakai satu garis bawah _saldo (ini hanya penanda konvensi sopan santun, bukan perlindungan enkapsulasi keras di Python).
  • Membuat setter tanpa validasi apapun, sehingga tujuan utama melindungi data menjadi sia-sia.
  • Mencoba mengubah nilai privat dengan menulis dompet.__saldo = 999; Python tidak akan mengubah atribut privat aslinya, melainkan hanya membuat variabel baru yang tidak terhubung.
Gunakan dua garis bawah (__nama_atribut) saat kamu benar-benar ingin mengunci data agar tidak disentuh langsung dari luar class.
