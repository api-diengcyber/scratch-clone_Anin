MODUL SMK • HUBUNGAN ANTAR OBJEK

Komposisi

Membangun sistem terstruktur dengan menggabungkan objek-objek kecil menjadi objek utuh yang fleksibel

Materi Lengkap: Pemrograman Berorientasi Objek

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Komposisi, fokus utama kita adalah pemrograman berorientasi objek. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. OOP mengelompokkan data dan perilaku ke dalam object. Class menjadi cetak biru, object adalah instance, inheritance mewariskan perilaku, polymorphism memungkinkan antarmuka yang sama memiliki perilaku berbeda, encapsulation membatasi cara data diakses, dan composition menyusun object dari object lain.

Contoh Sederhana

Class Hewan dapat memiliki method suara(). Kucing dan Anjing dapat memberikan implementasi suara() yang berbeda.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

class, object, attribute, method, constructor, inheritance, polymorphism, encapsulation, composition

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan saat program memiliki banyak entitas dengan data dan perilaku yang saling berkaitan.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Hubungan "Adalah" vs "Memiliki"

Tidak semua relasi class harus diselesaikan dengan pewarisan (inheritance). Terlalu banyak pewarisan bertingkat membuat kode kaku. Prinsip desain modern menganjurkan: utamakan komposisi di atas pewarisan.

Relasi Istilah Relasi Contoh Masalah Kapan Digunakan?
Pewarisan (Inheritance) "Adalah" (Is-A) Kucing adalah Hewan Saat class anak merupakan jenis khusus dari class induk.
Komposisi (Composition) "Memiliki" (Has-A) Komputer memiliki Mesin / CPU Saat objek kompleks dirakit dari bagian-bagian komponen independen.
Dalam komposisi, sebuah objek memegang objek lain sebagai atributnya. Jika komponen rusak atau diganti, class utama tidak ikut runtuh.

2. Contoh Kode Komposisi

# Komponen Independen 1 class Processor: def __init__(self, model, kecepatan_ghz): self.model = model self.kecepatan_ghz = kecepatan_ghz # Komponen Independen 2 class RAM: def __init__(self, kapasitas_gb): self.kapasitas_gb = kapasitas_gb # Class Utama yang MERAKIT (Memiliki) komponen di atas class Komputer: def __init__(self, merk, obj_processor, obj_ram): self.merk = merk self.processor = obj_processor # Komposisi: menyimpan objek self.ram = obj_ram # Komposisi: menyimpan objek def spesifikasi(self): return ( f"Komputer {self.merk} | " f"CPU: {self.processor.model} ({self.processor.kecepatan_ghz} GHz) | " f"RAM: {self.ram.kapasitas_gb} GB" ) # Merakit objek cpu = Processor("Intel Core i7", 3.6) memori = RAM(16) laptop_sekolah = Komputer("Asus ROG", cpu, memori) print(laptop_sekolah.spesifikasi())

3. Eksplorasi Praktik

1

Buat class komponen kecil

Buat class Baterai dengan atribut daya_persen dan method isi_daya().

2

Rancang class utama

Buat class Smartphone yang menerima parameter objek baterai pada constructor __init__.

3

Delegasikan method ke komponen

Di dalam method Smartphone.charge(), panggil method milik objek baterai: self.baterai.isi_daya().

4

Buktikan modularitas

Ganti objek baterai dengan baterai lain tanpa perlu mengubah struktur kode class Smartphone.

4. Kesalahan yang Sering Terjadi

  • Memaksakan pewarisan, contohnya: membuat class Mobil(Mesin): (salah, karena mobil bukan jenis mesin, melainkan mobil memiliki mesin).
  • Lupa mengakses atribut objek bagian lewat titik bertingkat (misal memanggil self.kecepatan_ghz padahal seharusnya self.processor.kecepatan_ghz).
  • Menghapus class komponen sehingga class utama gagal berfungsi saat diinstansiasi.
