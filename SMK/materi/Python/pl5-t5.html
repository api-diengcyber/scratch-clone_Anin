TASK 5 • HUBUNGAN ANTAR OBJEK

Komposisi

Membangun sistem terstruktur dengan menggabungkan objek-objek kecil menjadi objek utuh yang fleksibel

1. Hubungan "Adalah" vs "Memiliki"

Tidak semua relasi class harus diselesaikan dengan pewarisan (inheritance). Terlalu banyak pewarisan bertingkat membuat kode kaku. Prinsip desain modern menganjurkan: utamakan komposisi di atas pewarisan.

Relasi Istilah Relasi Contoh Masalah Kapan Digunakan?
Pewarisan (Inheritance) "Adalah" (Is-A) Kucing adalah Hewan Saat class anak merupakan jenis khusus dari class induk.
Komposisi (Composition) "Memiliki" (Has-A) Komputer memiliki Mesin / CPU Saat objek kompleks dirakit dari bagian-bagian komponen independen.
Dalam komposisi, sebuah objek memegang objek lain sebagai atributnya. Jika komponen rusak atau diganti, class utama tidak ikut runtuh.

2. Contoh Kode Komposisi

# Komponen Independen 1 class Processor: def __init__(self, model, kecepatan_ghz): self.model = model self.kecepatan_ghz = kecepatan_ghz # Komponen Independen 2 class RAM: def __init__(self, kapasitas_gb): self.kapasitas_gb = kapasitas_gb # Class Utama yang MERAKIT (Memiliki) komponen di atas class Komputer: def __init__(self, merk, obj_processor, obj_ram): self.merk = merk self.processor = obj_processor # Komposisi: menyimpan objek self.ram = obj_ram # Komposisi: menyimpan objek def spesifikasi(self): return ( f"Komputer {self.merk} | " f"CPU: {self.processor.model} ({self.processor.kecepatan_ghz} GHz) | " f"RAM: {self.ram.kapasitas_gb} GB" ) # Merakit objek cpu = Processor("Intel Core i7", 3.6) memori = RAM(16) laptop_sekolah = Komputer("Asus ROG", cpu, memori) print(laptop_sekolah.spesifikasi())

3. Langkah Praktik

1

Buat class komponen kecil

Buat class Baterai dengan atribut daya_persen dan method isi_daya().

2

Rancang class utama

Buat class Smartphone yang menerima parameter objek baterai pada constructor __init__.

3

Delegasikan method ke komponen

Di dalam method Smartphone.charge(), panggil method milik objek baterai: self.baterai.isi_daya().

4

Buktikan modularitas

Ganti objek baterai dengan baterai lain tanpa perlu mengubah struktur kode class Smartphone.

4. Kesalahan yang Sering Terjadi

  • Memaksakan pewarisan, contohnya: membuat class Mobil(Mesin): (salah, karena mobil bukan jenis mesin, melainkan mobil memiliki mesin).
  • Lupa mengakses atribut objek bagian lewat titik bertingkat (misal memanggil self.kecepatan_ghz padahal seharusnya self.processor.kecepatan_ghz).
  • Menghapus class komponen sehingga class utama gagal berfungsi saat diinstansiasi.
