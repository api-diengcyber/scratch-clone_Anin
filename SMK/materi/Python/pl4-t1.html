File, JSON & Penanganan Error

Menyimpan data permanen dan membuat program yang tidak mudah mogok

Materi Lengkap: Penyimpanan Data Json

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi File, JSON & Penanganan Error, fokus utama kita adalah penyimpanan data JSON. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. JSON menyimpan data dalam pasangan key-value dan array sehingga data dapat ditulis ke file dan dibaca kembali oleh program.

Contoh Sederhana

{"nama":"Ari","nilai":90} menyimpan satu objek siswa; program dapat memuatnya kembali menjadi dictionary Python.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

JSON, object, array, key, value, serialisasi, deserialisasi

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk pertukaran atau penyimpanan data terstruktur sederhana.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

with open(...) menutup file otomatis walau terjadi error. Selalu pakai bentuk ini.

2. JSON: menyimpan dict dan list

import json data = {"nama": "Rani", "umur": 16, "hobi": ["coding", "musik"]} with open("data.json", "w", encoding="utf-8") as f: json.dump(data, f, indent=2, ensure_ascii=False) with open("data.json", encoding="utf-8") as f: baru = json.load(f) print(baru["hobi"][0]) # coding

JSON adalah teks dengan format yang sama dengan dict dan list Python. Cocok untuk menyimpan data program yang bisa dibaca manusia dan dipakai bahasa lain.

3. try / except

try: a = int(input("Angka 1: ")) b = int(input("Angka 2: ")) print("Hasil:", a / b) except ValueError: print("Masukkan angka yang benar.") except ZeroDivisionError: print("Pembagi tidak boleh nol.")
ErrorPenyebab umum
ValueErrorTeks diubah ke angka, misalnya int("abc")
ZeroDivisionErrorMembagi dengan nol
FileNotFoundErrorNama atau lokasi file salah
KeyErrorKunci dict tidak ada
json.JSONDecodeErrorFile JSON kosong atau rusak
Jangan menulis except: kosong. Itu menyembunyikan error yang tidak kamu duga. Tangkap error yang spesifik.

4. Membuat program tahan error

import json def muat(nama_file): try: with open(nama_file, encoding="utf-8") as f: return json.load(f) except FileNotFoundError: return [] # belum ada file: mulai dari kosong except json.JSONDecodeError: print("File rusak, memulai dari kosong.") return []

Pola ini membuat program pertama kali dijalankan tetap berjalan, walau file datanya belum ada.

5. Menghitung kata

from collections import Counter with open("teks.txt", encoding="utf-8") as f: isi = f.read().lower() kata = [k.strip(".,!?") for k in isi.split()] print(Counter(kata).most_common(5))

Counter menghitung kemunculan tiap kata, dan most_common(5) memberi lima yang tersering.

6. Membaca, mengubah, menyimpan

data = muat("data.json") data["umur"] = 17 with open("data.json", "w", encoding="utf-8") as f: json.dump(data, f, indent=2, ensure_ascii=False)
Baca file dulu sampai selesai, baru buka dengan mode w. Mode w mengosongkan file saat dibuka; kalau program mati sebelum menulis, datamu hilang.
