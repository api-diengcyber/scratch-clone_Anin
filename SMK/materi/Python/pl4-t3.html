Program Tahan Error

Mengantisipasi kegagalan program dan menangani error secara elegan dengan blok try dan except

1. Mengapa Program Butuh try / except?

Dalam dunia nyata, error pasti terjadi: pengguna salah mengetik huruf saat diminta angka, atau file yang dicari ternyata tidak ada di folder. Tanpa penanganan, program akan langsung berhenti mendadak (crash). Dengan try / except, kita menangkap error tersebut dan memberikan solusi cadangan dengan tenang.

Jenis Error (Exception) Penyebab Munculnya Contoh Masalah
FileNotFoundError Mencoba membuka file yang tidak ditemukan di disk. open("rahasia.txt", "r") padahal file belum dibuat
ValueError Tipe data benar tapi nilainya tidak sesuai. int("sepuluh") saat pengguna salah ketik
ZeroDivisionError Mencoba membagi angka dengan angka nol. total / 0 saat jumlah data kosong
Prinsip: Jalankan kode berisiko di dalam blok try. Jika terjadi error, Python langsung melompat ke blok except tanpa menghentikan jalannya program.

2. Contoh Kode Penanganan Error

# Membaca file dengan aman tanpa membuat program crash nama_file = "pengumuman.txt" try: with open(nama_file, "r", encoding="utf-8") as file: konten = file.read() print("Isi file:", konten) except FileNotFoundError: print(f"Pemberitahuan: File '{nama_file}' belum ditemukan. Sistem membuatkan file kosong baru...") with open(nama_file, "w", encoding="utf-8") as file: file.write("Belum ada pengumuman hari ini.\n") finally: print("Pemeriksaan file selesai dijalankan!")

3. Langkah Praktik

1

Bungkus pembacaan file dengan blok try

Masukkan perintah with open("skor.txt", "r") as f: ke dalam blok try:.

2

Tangkap FileNotFoundError

Tambahkan except FileNotFoundError: lalu beri pesan ramah bahwa file belum ada dan tentukan nilai default 0.

3

Tangkap ValueError pada input angka

Tambahkan pengecekan konversi input angka int(input(...)) dengan except ValueError: agar tidak crash saat diinput huruf.

4

Uji coba sengaja memicu error

Jalankan program saat file belum ada atau masukkan teks acak untuk membuktikan program tetap berjalan mulus sampai baris akhir.

4. Kesalahan yang Sering Terjadi

  • Menulis except: kosong tanpa menyebutkan jenis errornya (ini sangat berbahaya karena bisa menyembunyikan bug salah ketik variabel).
  • Menaruh terlalu banyak baris kode di dalam blok try sehingga sulit melacak baris mana yang memicu error sebenarnya.
  • Membiarkan blok except kosong dengan hanya menulis pass tanpa memberitahu pengguna apa yang sedang terjadi.
Selalu tangani error secara spesifik, contohnya: except FileNotFoundError: atau except ValueError:, bukan blok except umum.
