Fungsi Lanjut & Rekursi

Parameter fleksibel, lambda, comprehension, map/filter, dan rekursi

Materi Lengkap: Rekursi

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Fungsi Lanjut & Rekursi, fokus utama kita adalah rekursi. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Fungsi rekursif memanggil dirinya sendiri dengan masalah yang lebih kecil. Rekursi harus memiliki base case agar pemanggilan berhenti.

Contoh Sederhana

Fibonacci dapat didefinisikan F(0)=0, F(1)=1, dan F(n)=F(n-1)+F(n-2).

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

rekursi, base case, recursive case, call stack

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan saat masalah secara alami dapat dipecah menjadi submasalah sejenis; untuk masalah besar pertimbangkan efisiensi dan batas stack.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Fungsi yang baik

Fungsi yang baik kecil, bernama jelas, dan punya satu tugas. Docstring menjelaskan apa yang dilakukan, parameter, dan nilai kembaliannya.

def sapa(nama, sapaan="Halo"): """Mengembalikan kalimat sapaan untuk nama.""" return f"{sapaan}, {nama}!" print(sapa("Rani")) # Halo, Rani! print(sapa("Rani", sapaan="Selamat pagi"))
BentukArtiContoh
Parameter defaultArgumen jadi opsionaldef f(x, y=10)
*argsMenampung argumen posisi sebanyak apa pun (menjadi tuple)def jumlah(*angka)
**kwargsMenampung argumen bernama (menjadi dict)def profil(**data)
def jumlah(*angka): return sum(angka) def profil(**data): for kunci, nilai in data.items(): print(kunci, ":", nilai) print(jumlah(1, 2, 3, 4)) # 10 profil(nama="Rani", kelas="XI")
Jebakan klasik: def f(x, daftar=[]) memakai satu list yang sama di setiap panggilan. Pakai daftar=None lalu buat list baru di dalam fungsi.

2. Lambda, map, filter, dan sorted

kuadrat = lambda x: x * x print(kuadrat(5)) # 25 angka = list(range(1, 21)) print(list(map(lambda x: x * x, angka))) # semua dikuadratkan print(list(filter(lambda x: x % 2 == 0, angka))) # hanya genap siswa = [("Ani", 80), ("Budi", 95), ("Citra", 70)] print(sorted(siswa, key=lambda s: s[1], reverse=True))

Lambda adalah fungsi kecil tanpa nama untuk satu ekspresi. Jangan dipakai untuk logika panjang; buat fungsi biasa agar mudah dibaca.

3. List comprehension

kuadrat = [x * x for x in range(1, 11)] genap = [x for x in range(1, 21) if x % 2 == 0] # setara dengan: genap2 = [] for x in range(1, 21): if x % 2 == 0: genap2.append(x)
BentukArti
[ekspresi for x in data]Ubah setiap elemen

Comprehension biasanya lebih singkat dan setara dengan map atau filter. Jika sudah sulit dibaca, pecah jadi perulangan biasa.

4. Rekursi

Fungsi rekursif memanggil dirinya sendiri. Ia butuh kasus dasar (kapan berhenti) dan langkah rekursif (mengecilkan masalah).

def faktorial(n): if n <= 1: # kasus dasar return 1 return n * faktorial(n - 1) # langkah rekursif print(faktorial(5)) # 120 # faktorial(3) → 3 * faktorial(2) → 3 * 2 * faktorial(1) → 3 * 2 * 1 = 6
def fibonacci(n): if n <= 1: return n return fibonacci(n - 1) + fibonacci(n - 2) def fibonacci_loop(n): a, b = 0, 1 for _ in range(n): a, b = b, a + b return a print([fibonacci(i) for i in range(10)]) # 10 bilangan pertama
Fibonacci rekursif menghitung hal yang sama berkali-kali: fibonacci(30) memanggil dirinya sekitar 2,7 juta kali, sedangkan versi perulangan hanya 30 putaran. Rekursi lebih mudah dibaca, tetapi belum tentu lebih cepat.
  • Tanpa kasus dasar, Python berhenti dengan RecursionError (batas kedalaman sekitar 1000).
  • Gunakan rekursi untuk masalah yang berbentuk "masalah lebih kecil yang sama": faktorial, pohon, folder.

5. Peta ke task

  • Fungsi serbaguna: parameter default, comprehension, lambda.
