TASK 4 • ANALISIS FILE TEKS

Hitung Kata dalam File

Membaca dokumen teks, memproses string, dan menghitung statistik jumlah baris serta kata

1. Membedah Teks dari File

Pengolahan file teks sering melibatkan analisis statistik: menghitung berapa banyak paragraf, baris, total kata, hingga karakter yang ada dalam sebuah berkas.

Method String / List Cara Kerja Contoh Penggunaan
file.readlines() Membaca seluruh file dan mengembalikannya sebagai list baris. len(file.readlines()) menghitung total baris
teks.split() Memecah teks string menjadi potongan kata berdasarkan spasi. "halo dunia".split() menghasilkan ["halo", "dunia"]
teks.strip() Menghapus karakter spasi atau enter (\n) liar di ujung teks. Merapikan baris teks sebelum dihitung
Method .split() secara otomatis mengabaikan spasi berlebih, spasi ganda, dan karakter baris baru (\n), sehingga sangat cocok untuk menghitung total kata murni.

3. Langkah Praktik

1

Buat file teks cerita pendek

Buat file artikel.txt yang berisi 3–4 paragraf cerita pendek atau deskripsi proyekmu.

2

Buka file di blok try/except

Baca seluruh isi file menggunakan mode "r" dan simpan ke variabel string.

3

Pecah teks dengan .split()

Gunakan method konten.split() untuk memecah teks menjadi list kata, lalu hitung jumlahnya dengan len().

4

Hitung kemunculan kata tertentu

Gunakan method daftar_kata.count("python") untuk mencari berapa kali kata kunci tertentu muncul di dalam teks.

4. Kesalahan yang Sering Terjadi

  • Menghitung jumlah karakter langsung dengan len(konten) tanpa menyadari bahwa spasi dan enter (\n) ikut terhitung sebagai karakter.
  • Memanggil file.read() dua kali berturut-turut; pada pemanggilan kedua hasilnya akan kosong karena kursor baca sudah berada di ujung akhir file.
  • Lupa menyamakan teks ke huruf kecil dengan .lower() saat menghitung frekuensi kata tertentu.
