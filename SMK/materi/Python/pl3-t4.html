1. Memanfaatkan Lambda, Map, dan Filter

Lambda adalah fungsi anonim (tanpa nama) yang ditulis dalam satu baris ringkas: lambda argumen: ekspresi. Lambda sering dipadukan dengan map() dan filter() untuk memanipulasi koleksi data secara cepat.

Fungsi Format Peran
lambda lambda x: x * 2 Fungsi cepat satu baris tanpa perlu kata kunci def.
map() map(fungsi, koleksi) Menerapkan fungsi ke seluruh elemen koleksi data.
filter() filter(fungsi, koleksi) Menyaring elemen yang bernilai True saja berdasarkan kondisi.
Hasil dari map() dan filter() berbentuk objek generator/iterator. Bungkus dengan list() agar hasilnya dapat dilihat dan dicetak langsung.

2. Contoh Kode

nilai_siswa = [45, 78, 90, 62, 88, 55] # 1. FILTER: Ambil nilai yang tuntas (>= 70) nilai_tuntas = list(filter(lambda x: x >= 70, nilai_siswa)) print("Nilai Tuntas:", nilai_tuntas) # [78, 90, 88] # 2. MAP: Beri bonus poin 5 pada semua nilai nilai_bonus = list(map(lambda x: x + 5, nilai_siswa)) print("Nilai + Bonus:", nilai_bonus) # [50, 83, 95, 67, 93, 60]

3. Eksplorasi Praktik

1

Buat fungsi lambda sederhana

Deklarasikan lambda untuk mengalikan angka dengan dua: kali_dua = lambda x: x * 2.

2

Terapkan fungsi filter()

Saring list bilangan acak untuk membuang seluruh angka bernilai negatif menggunakan filter(lambda x: x >= 0, data).

3

Terapkan fungsi map()

Ubah sekumpulan nama siswa dalam list menjadi huruf besar semua menggunakan map(lambda nama: nama.upper(), daftar_nama).

4

Konversikan ke tipe list

Bungkus kedua hasil tersebut dengan list() lalu cetak ke layar konsol.

4. Kesalahan yang Sering Terjadi

  • Lupa membungkus hasil dengan list(), sehingga yang tercetak hanya berupa alamat memori seperti <map object at 0x...>.
  • Menuliskan pernyataan kompleks di dalam lambda (seperti if-elif-else rumit atau loop); lambda hanya boleh memuat satu ekspresi sederhana.
  • Kondisi pada filter() tidak menghasilkan nilai boolean (True/False).
Jika logikamu butuh percabangan bertingkat atau operasi beberapa baris, gunakan fungsi biasa dengan kata kunci def daripada memaksakan lambda.
