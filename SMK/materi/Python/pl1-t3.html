Tuple dan Set

Menjaga keaslian data permanen dengan tuple dan menyaring duplikasi otomatis dengan set

Materi Lengkap: Struktur Data

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Tuple dan Set, fokus utama kita adalah struktur data. 1. Mengenal Tuple dan Set

Selain list dan dictionary, Python menyediakan dua struktur data penting lainnya dengan sifat khusus: Tuple yang sifatnya terkunci permanen, dan Set yang menolak data duplikat.

Struktur Data Simbol Bisa Diubah? Bisa Duplikat? Kapan Memakainya?
Tuple ( ) Tidak (Immutable) Bisa Data paten yang tidak boleh dirusak (misal: koordinat GPS, hari seminggu).
Set { } Bisa Tidak (Nilai Unik) Menyaring duplikasi dan mengecek keanggotaan dengan sangat cepat.
Gunakan set() ketika kamu ingin tahu jumlah pengunjung unik tanpa menghitung orang yang sama dua kali.

2. Contoh Kode

# 1. Tuple: Data koordinat lokasi (tidak boleh berubah) koordinat_sekolah = (-7.250445, 112.768845) print("Latitude:", koordinat_sekolah[0]) # 2. Set: Menghapus data duplikat dari list tamu daftar_hadir = ["Andi", "Budi", "Andi", "Citra", "Budi"] tamu_unik = set(daftar_hadir) # Menambah tamu baru ke dalam set tamu_unik.add("Doni") print("Daftar tamu unik:", tamu_unik) # Memeriksa keanggotaan print("Apakah Budi hadir?", "Budi" in tamu_unik)

3. Eksplorasi Praktik

1

Buat sebuah tuple

Deklarasikan tuple bernama resolusi_layar = (1920, 1080) dan cetak nilai lebarnya.

2

Siapkan list dengan data ganda

Buat list nama hobi yang sengaja memuat kata yang sama berkali-kali.

3

Konversikan list menjadi set

Gunakan fungsi set() untuk membersihkan seluruh data hobi yang terduplikasi.

4

Lakukan pengecekan dengan operator 'in'

Periksa apakah hobi tertentu ada di dalam set menggunakan perintah "membaca" in set_hobi.

4. Kesalahan yang Sering Terjadi

  • Mencoba mengubah nilai tuple (misal: koordinat[0] = 10) yang akan memicu TypeError: 'tuple' object does not support item assignment.
  • Mencoba mengakses item set dengan indeks angka (misal: tamu_unik[0]), yang akan menghasilkan error karena Set tidak memiliki urutan.
  • Membuat set kosong dengan {}; di Python, {} kosong akan dianggap Dictionary. Gunakan set() untuk membuat set kosong.
Set tidak menjamin urutan data saat dicetak. Jika urutan data sangat penting, gunakanlah List!
