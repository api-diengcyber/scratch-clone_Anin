1. Memadukan Sorting dan Searching

Dalam aplikasi nyata seperti pencarian kontak atau buku induk sekolah, data teks (string) harus diurutkan secara alfabetis (A-Z) terlebih dahulu sebelum bisa dicari secepat kilat dengan Binary Search.

Tahapan Proses Tujuan
Tahap 1: Normalisasi Ubah nama ke huruf kecil dengan .lower() Menghindari kesalahan akibat beda huruf besar dan kecil
Tahap 2: Pengurutan Gunakan algoritma sort (Bubble/Selection) Memastikan data tersusun rapi dari A sampai Z
Tahap 3: Pencarian Jalankan Binary Search Menemukan nomor urut kehadiran siswa hanya dalam beberapa langkah
Di Python, teks dapat dibandingkan secara alfabetis dengan operator matematika biasa: "Andi" < "Budi" bernilai True.

2. Contoh Kode Proyek Cari Nama

# Daftar nama siswa yang masih acak daftar_siswa = ["Rian", "Citra", "Budi", "Zahra", "Andi", "Fani"] # 1. Urutkan nama terlebih dahulu (A-Z) daftar_siswa.sort() print("Daftar Siswa Urut:", daftar_siswa) # 2. Fungsi cari nama berbasis Binary Search def cari_siswa(daftar_urut, nama_target): kiri = 0 kanan = len(daftar_urut) - 1 target_bersih = nama_target.lower() while kiri <= kanan: tengah = (kiri + kanan) // 2 nama_tengah = daftar_urut[tengah].lower() if nama_tengah == target_bersih: return tengah # Menemukan indeks urutan elif nama_tengah < target_bersih: kiri = tengah + 1 else: kanan = tengah - 1 return -1 nama = "Citra" posisi = cari_siswa(daftar_siswa, nama) if posisi != -1: print(f"Siswa bernama {nama} terdaftar di nomor urut {posisi + 1}.") else: print(f"{nama} tidak ditemukan dalam daftar kelas.")

3. Eksplorasi Praktik

1

Siapkan list nama acak

Buat list berisi minimal 8 nama teman sekelas yang belum berurutan abjad.

2

Urutkan daftar nama

Jalankan fungsi pengurutan (kamu bisa menggunakan algoritma buatanmu dari Task 2/3 atau fungsi .sort()).

3

Adaptasikan Binary Search untuk teks

Gunakan method .lower() pada nama target dan nama di indeks tengah sebelum membandingkannya.

4

Cetak nomor absen siswa

Tampilkan nomor urut absen yang ramah dibaca (indeks + 1) jika nama siswa berhasil ditemukan.

4. Kesalahan yang Sering Terjadi

  • Membandingkan teks tanpa .lower() sehingga huruf besar selalu dianggap lebih kecil dari huruf kecil dalam urutan ASCII (contoh: "Zahra" < "andi").
  • Langsung mencari dengan Binary Search pada list absensi tanpa mengurutkannya terlebih dahulu.
  • Menampilkan indeks 0 langsung ke pengguna alih-alih nomor urut posisi + 1.
Normalisasi huruf dengan .lower() adalah kunci agar pencarian nama bersifat fleksibel (tidak terpengaruh huruf besar/kecil yang diketik pengguna).
