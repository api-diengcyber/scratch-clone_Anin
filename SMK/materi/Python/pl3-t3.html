1. Logika Deret Fibonacci

Deret Fibonacci adalah barisan angka di mana setiap suku adalah hasil penjumlahan dari dua suku sebelumnya: 0, 1, 1, 2, 3, 5, 8, 13, 21, .... Ini adalah contoh klasik dari rekursi bercabang (tree recursion).

Suku ke-n Nilai Rumus Pembentuk
Suku ke-0 0 Kasus Dasar 1: return 0
Suku ke-1 1 Kasus Dasar 2: return 1
Suku ke-n (n >= 2) Fib(n-1) + Fib(n-2) Langkah Rekursif: penjumlahan 2 panggilan fungsi
Berbeda dengan faktorial yang hanya memanggil fungsi sekali per putaran, fungsi Fibonacci rekursif memanggil dirinya sendiri dua kali di setiap langkahnya.

2. Contoh Kode

# Fungsi Rekursif Mencari Suku ke-n Fibonacci def fibonacci(n): # Dua Kasus Dasar if n <= 0: return 0 elif n == 1: return 1 # Langkah Rekursif Berganda return fibonacci(n - 1) + fibonacci(n - 2) # Mencetak 8 suku pertama print("Suku ke-7:", fibonacci(7)) # Output: 13 deret = [fibonacci(i) for i in range(8)] print("Deret Fibonacci:", deret) # [0, 1, 1, 2, 3, 5, 8, 13]

3. Eksplorasi Praktik

1

Tulis dua kasus dasar (base cases)

Gunakan pengkondisian: kembalikan 0 jika n <= 0, dan kembalikan 1 jika n == 1.

2

Terapkan pemanggilan bercabang

Tulis baris rekursif: return fibonacci(n - 1) + fibonacci(n - 2).

3

Cetak nilai suku tertentu

Panggil fibonacci(6) untuk memastikan hasilnya bernilai 8.

4

Gabungkan dengan list comprehension

Gunakan loop comprehension untuk mencetak deret dari suku ke-0 sampai ke-9.

4. Kesalahan yang Sering Terjadi

  • Hanya membuat 1 kasus dasar (misal hanya n == 0), sehingga program salah hitung saat mencapai n == 1.
  • Menguji fungsi dengan nilai n yang terlalu besar (misal n = 50); karena pohon rekursinya bercabang ganda, program akan terasa membeku (*freeze*).
  • Lupa bahwa Fibonacci dimulai dari indeks 0, bukan 1.
Uji fungsi Fibonacci rekursif sederhana dengan angka di bawah 30 agar waktu pemrosesannya tetap instan di komputermu.
