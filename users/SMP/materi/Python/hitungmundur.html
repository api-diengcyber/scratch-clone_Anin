1. Konsep Hitung Mundur

Daripada menulis print(5), print(4), dan seterusnya secara manual, kita bisa meminta Python mengulanginya secara otomatis menggunakan looping (perulangan).

Peran Fungsi Khusus:
  • range(mulai, berhenti, langkah) : Membuat deret urutan angka. Jika ingin mundur, langkahnya bernilai minus (-1).
  • import time : Modul bawaan Python untuk mengatur waktu.
  • time.sleep(1) : Menghentikan program sejenak selama 1 detik agar hitungan mundur terlihat berdetak nyata.

2. Eksplorasi Praktik

1

Contoh 1: Siapkan Modul Waktu

Panggil modul waktu Python di baris paling atas program.

import time
2

Contoh 2: Buat Perulangan Mundur

Gunakan for dan range(5, 0, -1) untuk menghitung dari 5 turun ke 1 dengan jeda 1 detik tiap hitungan.

for i in range(5, 0, -1): print(f"Hitungan: {i}") time.sleep(1)
3

Contoh 3: Cetak Teks Penutup

Di luar perulangan (tanpa indentasi tab), cetak pesan setelah hitungan selesai.

print("ROKET MELUNCUR! 🚀")
