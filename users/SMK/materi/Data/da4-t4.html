MODUL SMK • EVALUASI MODEL

Hitung Akurasi

Mengukur seberapa pintar model kita dengan menghitung persentase tebakan yang benar pada data uji

Materi Lengkap: Klasifikasi Dan Evaluasi Model

Konsep dasar. Data adalah kumpulan fakta atau pengukuran yang dapat digunakan untuk menjawab pertanyaan. Analisis data dimulai dari pertanyaan yang jelas, kualitas data, pengolahan, lalu interpretasi hasil. Pada materi Hitung Akurasi, fokus utama kita adalah klasifikasi dan evaluasi model. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Klasifikasi memberikan label pada data berdasarkan pola. Data latih digunakan untuk belajar aturan/pola, data uji untuk mengukur performa pada data yang belum digunakan saat belajar. k-NN membandingkan kedekatan data baru dengan contoh yang sudah berlabel.

Contoh Sederhana

Jika tiga tetangga terdekat sebuah titik adalah dua “A” dan satu “B”, k-NN dengan k=3 cenderung memilih A.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

feature, label, training, testing, k-NN, distance, accuracy

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk masalah yang hasilnya berupa kategori dan memiliki contoh data berlabel.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan sumber, missing value, satuan, skala grafik, ukuran sampel, outlier, dan perbedaan antara korelasi dan sebab-akibat.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: langsung menghitung tanpa pertanyaan, grafik menyesatkan, mengabaikan data kosong, menyimpulkan terlalu jauh, dan memperlakukan data kecil sebagai gambaran seluruh populasi.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Rumus Evaluasi Akurasi

Akurasi (Accuracy) adalah metrik evaluasi paling umum dalam masalah klasifikasi untuk melihat seberapa sering tebakan model cocok dengan kenyataan aslinya.

Rumus:
Akurasi = (Jumlah Tebakan Benar / Total Data Uji) * 100%
Data Ke- Label Asli (Kunci) Prediksi Model Status
1 1 (Lulus) 1 (Lulus) Benar ✔
2 0 (Remedial) 1 (Lulus) Salah ❌
3 1 (Lulus) 1 (Lulus) Benar ✔
4 0 (Remedial) 0 (Remedial) Benar ✔

Dari 4 data uji di atas, terdapat 3 tebakan benar. Maka akurasinya adalah: (3 / 4) * 100% = 75%.

2. Contoh Kode Menghitung Akurasi

# Fungsi evaluasi akurasi def hitung_akurasi(label_asli, label_prediksi): if len(label_asli) == 0: return 0.0 benar = 0 for asli, tebakan in zip(label_asli, label_prediksi): if asli == tebakan: benar += 1 persentase = (benar / len(label_asli)) * 100 return persentase # Pengujian hasil model kunci_jawaban = [1, 0, 1, 1, 0] hasil_prediksi = [1, 0, 0, 1, 0] skor_akurasi = hitung_akurasi(kunci_jawaban, hasil_prediksi) print(f"Akurasi Model pada Data Uji: {skor_akurasi:.1f}%")

3. Eksplorasi Praktik

1

Jalankan model pada data uji

Masukkan fitur dari data uji ke dalam modelmu untuk mendapatkan list hasil tebakan (prediksi).

2

Bandingkan dengan fungsi zip()

Gunakan zip(label_asli, label_prediksi) untuk membandingkan pasangan data baris demi baris secara otomatis.

3

Hitung persentase keberhasilan

Bagi jumlah kecocokan benar dengan total panjang data uji lalu kalikan 100.

4

Analisis kesalahan

Cetak data mana saja yang salah tebak dan cari tahu penyebab kegagalannya.

4. Kesalahan yang Sering Terjadi

  • Menghitung akurasi hanya dari data latih dan langsung berpuas diri saat melihat angka 100%.
  • Jumlah elemen di list label asli dan list prediksi tidak sama (mengakibatkan pemotongan perbandingan).
  • Lupa mengalikan 100 sehingga nilai akurasi masih berupa desimal (0.8 bukan 80%).
Nilai akurasi data uji yang realistis biasanya berada di kisaran 75% – 95%. Akurasi sempurna 100% pada data nyata yang banyak justru patut dicurigai ada kebocoran data (*data leakage*).
