Data Latih dan Data Uji

Memisahkan data latihan dan ujian untuk mencegah jebakan model yang hanya menghafal (Overfitting)

Materi Lengkap: Klasifikasi Dan Evaluasi Model

Konsep dasar. Data adalah kumpulan fakta atau pengukuran yang dapat digunakan untuk menjawab pertanyaan. Analisis data dimulai dari pertanyaan yang jelas, kualitas data, pengolahan, lalu interpretasi hasil. Pada materi Data Latih dan Data Uji, fokus utama kita adalah klasifikasi dan evaluasi model. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Klasifikasi memberikan label pada data berdasarkan pola. Data latih digunakan untuk belajar aturan/pola, data uji untuk mengukur performa pada data yang belum digunakan saat belajar. k-NN membandingkan kedekatan data baru dengan contoh yang sudah berlabel.

Contoh Sederhana

Jika tiga tetangga terdekat sebuah titik adalah dua “A” dan satu “B”, k-NN dengan k=3 cenderung memilih A.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

feature, label, training, testing, k-NN, distance, accuracy

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk masalah yang hasilnya berupa kategori dan memiliki contoh data berlabel.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan sumber, missing value, satuan, skala grafik, ukuran sampel, outlier, dan perbedaan antara korelasi dan sebab-akibat.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: langsung menghitung tanpa pertanyaan, grafik menyesatkan, mengabaikan data kosong, menyimpulkan terlalu jauh, dan memperlakukan data kecil sebagai gambaran seluruh populasi.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Memahami Peran Data Latih vs Data Uji

Sama seperti siswa sekolah yang belajar dari buku paket lalu diuji dengan soal ujian baru, model Machine Learning harus dilatih dengan Data Latih (Training Data) dan dievaluasi dengan Data Uji (Testing Data) yang belum pernah dilihat sama sekali.

Kelompok Data Proporsi Umum Fungsi Utama
Data Latih (Train) 70% – 80% Bahan materi bagi model untuk mempelajari pola hubungan fitur dan label
Data Uji (Test) 20% – 30% Soal ujian rahasia untuk menilai apakah model benar-benar pintar atau cuma hafal
Bahaya Overfitting: Keadaan di mana model mendapatkan skor 100% sempurna saat latihan karena ia menghafal contoh, tetapi nilainya langsung anjlok saat diuji dengan data baru.

2. Contoh Kode Membagi Dataset (Slicing)

# Dataset 10 data siswa (jam_belajar, status_lulus) semua_data = [ (1, 0), (2, 0), (2.5, 0), (3, 0), (4, 1), (5, 1), (6, 1), (7, 1), (8, 1), (9, 1) ] # Tentukan batas pembagian 80% untuk data latih rasio_latih = 0.8 titik_pisah = int(len(semua_data) * rasio_latih) # Membagi list dengan teknik Slicing data_latih = semua_data[:titik_pisah] # 8 data pertama data_uji = semua_data[titik_pisah:] # 2 data terakhir print(f"Total data: {len(semua_data)}") print(f"Jumlah data latih: {len(data_latih)} data") print(f"Jumlah data uji : {len(data_uji)} data")

3. Eksplorasi Praktik

1

Kumpulkan minimal 10 baris data

Buat dataset list berisi minimal 10 pasang fitur dan label target.

2

Hitung indeks pemisah

Gunakan rumus int(len(data) * 0.7) atau 0.8 untuk menentukan jumlah baris latih.

3

Potong list menjadi dua bagian

Gunakan pemotongan list data[:titik] untuk data latih dan data[titik:] untuk data uji.

4

Kunci data uji

Pastikan proses penentuan model hanya membaca data_latih, simpan data_uji untuk penilaian akhir nanti.

4. Kesalahan yang Sering Terjadi

  • Data Leakage (Kebocoran Data): Sengaja atau tidak sengaja memasukkan data uji ke dalam proses latihan model.
  • Menguji model memakai data yang sama dengan data latihan (ini seperti memberi tahu kunci jawaban sebelum ujian dimulai).
  • Data uji terlalu sedikit (misal hanya 1 data), sehingga penilaian performa model menjadi tidak dapat dipercaya.
Kunci kejujuran Machine Learning: Model dinilai semata-mata dari kemampuannya menebak data uji baru yang belum pernah ia lihat sama sekali!
