Mode Gelap (Dark Mode)

Menyesuaikan tampilan web secara otomatis dengan mode tema yang dipilih pengguna di HP/laptop

Materi Lengkap: Tema Dan State Tampilan

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Mode Gelap (Dark Mode), fokus utama kita adalah tema dan state tampilan. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Tema halaman adalah keadaan tampilan yang dapat diubah dengan class atau atribut pada elemen root, lalu CSS menentukan gaya berdasarkan keadaan tersebut.

Contoh Sederhana

body.dark memakai aturan warna berbeda dari body biasa.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

theme, class, CSS variable, state, toggle

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan ketika pengguna perlu mengganti tampilan seperti mode terang/gelap.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Mendeteksi Tema dengan prefers-color-scheme

Banyak pengguna lebih nyaman membaca web dengan latar belakang gelap di malam hari agar mata tidak silau. CSS memiliki fitur untuk mendeteksi setelan tema bawaan perangkat pengguna secara langsung.

Fitur CSS Fungsi
prefers-color-scheme: dark Mendeteksi apakah sistem HP/laptop pengguna sedang mengaktifkan mode gelap
CSS Custom Properties (Variables) Menyimpan warna dalam variabel (misal: --bg-utama) agar mudah diganti sekaligus
Alih-alih menulis ulang seluruh kode CSS, cukup ganti nilai variabel warna di dalam blok media query mode gelap.

2. Contoh Kode CSS Mode Gelap Otomatis

/* 1. Warna Default: Mode Terang */ :root { --bg-halaman: #f8fafc; --bg-kartu: #ffffff; --teks-utama: #0f172a; --border-warna: #e2e8f0; } /* 2. Warna Otomatis saat HP/Laptop Mode Gelap */ @media (prefers-color-scheme: dark) { :root { --bg-halaman: #0b0f19; --bg-kartu: #1e293b; --teks-utama: #f8fafc; --border-warna: #334155; } } /* 3. Terapkan Variabel ke Elemen */ body { background-color: var(--bg-halaman); color: var(--teks-utama); } .kartu { background-color: var(--bg-kartu); border: 1px solid var(--border-warna); }

3. Eksplorasi Praktik

1

Tentukan variabel warna di :root

Deklarasikan nama variabel untuk latar belakang dan warna teks pada bagian atas file CSS.

2

Gunakan variabel pada elemen halaman

Ganti kode warna kaku pada body dan kartu menggunakan var(--nama-variabel).

3

Tambahkan media query prefers-color-scheme

Tulis aturan @media (prefers-color-scheme: dark) lalu ubah nilai variabel menjadi warna gelap.

4

Uji coba di browser

Ganti pengaturan tema laptopmu ke Dark Mode, dan perhatikan websitemu akan langsung berubah warna tanpa refresh.

4. Kesalahan yang Sering Terjadi

  • Memakai warna hitam pekat (#000000) murni yang kontrasnya terlalu tajam di mata; gunakan warna abu gelap seperti #0f172a.
  • Lupa mengubah warna teks sehingga tulisan hitam tidak terlihat di atas latar belakang yang berubah menjadi gelap.
  • Warna garis tepi (border) dibiarkan terang sehingga terlihat menyala aneh saat di mode gelap.
Pastikan kontras teks di mode gelap tetap memenuhi standar aksesibilitas agar teks tetap terbaca dengan jelas.
