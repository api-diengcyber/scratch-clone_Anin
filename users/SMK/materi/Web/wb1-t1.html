HTML Semantik & Layout CSS

Struktur halaman yang bermakna dan tata letak yang rapi

Materi Lengkap: Html Semantik

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi HTML Semantik & Layout CSS, fokus utama kita adalah HTML semantik. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Elemen semantik memberi makna pada bagian halaman, misalnya header, nav, main, section, article, dan footer. Browser, mesin pencari, dan teknologi bantu dapat memahami struktur ini lebih baik.

Contoh Sederhana

<main><article><h1>Berita</h1><p>Isi...</p></article></main> memisahkan konten utama secara bermakna.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, elemen, semantic, header, nav, main, section, article, footer

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan ketika membuat halaman yang terstruktur, mudah dipelihara, dan lebih aksesibel.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. HTML semantik

HTML semantik memakai tag yang menjelaskan fungsi bagian halaman, bukan hanya div. Manfaatnya: mudah dibaca, lebih baik untuk SEO, dan dibaca benar oleh pembaca layar.

TagFungsi
<header>Kepala halaman atau bagian: logo, judul
<nav>Kumpulan tautan navigasi
<main>Isi utama, satu per halaman
<section>Bagian bertema dengan judul
<article>Konten mandiri, mis. berita
<aside>Isi pendamping, mis. sidebar
<footer>Kaki halaman: hak cipta, kontak
<header><h1>Toko Buku</h1><nav><a href="#produk">Produk</a></nav></header> <main> <section id="produk"><h2>Produk</h2></section> </main> <footer>&copy; 2026</footer>

2. Box model

Setiap elemen adalah kotak berlapis: content, padding (ruang dalam), border, dan margin (ruang luar).

* { box-sizing: border-box; } /* lebar sudah termasuk padding dan border */ .kartu { padding: 16px; border: 1px solid #ddd; margin: 12px; }
Selalu pasang box-sizing: border-box. Tanpa itu, padding menambah lebar elemen dan sering merusak layout.

3. Flexbox: tata letak satu dimensi

nav { display: flex; gap: 16px; justify-content: space-between; align-items: center; }
PropertiFungsi
justify-contentMenata sepanjang sumbu utama
align-itemsMenata pada sumbu silang
flex-wrapBoleh turun baris
gapJarak antar item

4. Grid: tata letak dua dimensi

.galeri { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; }
GunakanKapan
FlexboxBaris atau kolom tunggal: menu, tombol, kartu sebaris
GridBaris dan kolom sekaligus: galeri, dashboard, layout halaman
Tiga kolom tetap terlalu sempit di HP. Materi berikutnya (responsif) memakai media query untuk menyesuaikannya.

5. Kesalahan yang sering terjadi

MasalahPerbaikan
Semua pakai divGanti dengan header, nav, main, section, footer
Lebih dari satu h1Gunakan satu h1, lalu h2 dan h3 berurutan
Elemen melebar keluar layarPasang box-sizing: border-box
Item flex tidak sejajarAtur align-items dan justify-content
