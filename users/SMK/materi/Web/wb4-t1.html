Daftar Tugas

Menambahkan dan mencoret daftar kegiatan secara dinamis dengan event listener

Materi Lengkap: Pengembangan Halaman Web

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Daftar Tugas, fokus utama kita adalah pengembangan halaman web. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Halaman web dibangun dari struktur HTML, aturan visual CSS, dan perilaku JavaScript bila diperlukan. Ketiganya bekerja bersama melalui browser.

Contoh Sederhana

Sebuah tombol memiliki elemen HTML, gaya CSS, dan event JavaScript untuk merespons klik.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

HTML, CSS, JavaScript, DOM, browser, event, responsive

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan pembagian tanggung jawab ini agar kode lebih mudah dipahami dan dipelihara.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Membuat Elemen Baru Saat Event Terjadi

Aplikasi daftar tugas (to-do list) bekerja dengan menangkap teks dari formulir, membuat elemen daftar baru menggunakan JavaScript, dan menambahkannya ke halaman secara langsung.

Metode DOM Fungsi
event.preventDefault() Mencegah formulir memuat ulang (refresh) halaman saat ditekan submit.
document.createElement("li") Membuat tag baris daftar baru di memori browser.
wadah.appendChild(elemenBaru) Memasukkan elemen baru ke dalam elemen pembungkus (misal ke dalam <ul>).
Setiap item daftar yang dibuat secara dinamis dapat langsung dipasangi event listener klik untuk mencoret teks tugas yang sudah selesai.

2. Contoh Kode Daftar Tugas

const formTugas = document.querySelector("#formTugas"); const inputTugas = document.querySelector("#inputTugas"); const listTugas = document.querySelector("#listTugas"); formTugas.addEventListener("submit", function(event) { event.preventDefault(); // 1. Cegah reload const teks = inputTugas.value.trim(); if (teks === "") return; // 2. Buat elemen <li> baru const liBaru = document.createElement("li"); liBaru.textContent = teks; // 3. Pasang aksi coret saat diklik liBaru.addEventListener("click", () => { liBaru.style.textDecoration = liBaru.style.textDecoration === "line-through" ? "none" : "line-through"; }); // 4. Masukkan ke dalam daftar <ul> listTugas.appendChild(liBaru); inputTugas.value = ""; // Kosongkan kolom input });

3. Eksplorasi Praktik

1

Siapkan form dan tag <ul>

Buat elemen form yang memuat satu input teks, satu tombol submit, dan satu wadah kosong <ul id="listTugas">.

2

Cegah reload halaman

Pasang event listener submit pada form dan panggil event.preventDefault().

3

Buat elemen <li> dinamis

Gunakan document.createElement("li") lalu isi properti textContent dengan nilai yang diketik pengguna.

4

Tambahkan fitur coret tugas

Beri event listener klik pada elemen li baru tersebut untuk mengubah gaya coret garis (line-through).

4. Kesalahan yang Sering Terjadi

  • Lupa menggunakan event.preventDefault() sehingga halaman seketika me-refresh dan item tugas yang baru dibuat langsung hilang.
  • Tidak membersihkan nilai input (inputTugas.value = "") sesudah item berhasil dimasukkan.
  • Memasang event listener klik hanya pada elemen yang sudah ada di HTML, bukan pada elemen yang baru dibuat lewat JavaScript.
Selalu pasang event listener pada elemen dinamis tepat setelah elemen tersebut dibuat lewat document.createElement().
