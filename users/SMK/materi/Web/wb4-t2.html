Kartu dari Data

Mengubah susunan array of objects menjadi kumpulan kartu HTML dinamis secara otomatis

Materi Lengkap: Logika Javascript Di Browser

Konsep dasar. Pengembangan web menggabungkan struktur halaman, tampilan, dan perilaku interaktif. HTML mendefinisikan makna dan struktur, CSS mengatur presentasi, sedangkan JavaScript mengatur logika di browser. Pada materi Kartu dari Data, fokus utama kita adalah logika JavaScript di browser. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. JavaScript membaca atau mengubah DOM, menangani event, mengolah data, dan memperbarui tampilan. Array methods seperti map dan filter membantu memproses kumpulan data.

Contoh Sederhana

data.filter(item => item.harga < 100000) memilih produk yang memenuhi kondisi.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

DOM, event, function, array, map, filter, callback, state

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk membuat halaman merespons tindakan pengguna dan mengolah data secara dinamis.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan struktur HTML, ukuran layar, aksesibilitas, validasi input, dan jangan mengandalkan tampilan sebagai satu-satunya sumber kebenaran.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: terlalu banyak inline style/script, struktur HTML tidak semantik, layout hanya cocok di satu ukuran layar, tidak memberi label input, dan tidak menguji keyboard/mobile.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Memisahkan Data dari Tampilan

Daripada menuliskan belasan kartu statis secara manual di HTML, data disimpan di JavaScript dalam bentuk Array of Objects. Program kemudian membaca array ini dan mencetak kartu secara teratur.

Struktur Contoh Penulisan Kegunaan
Objek { nama: "Lomba Web", kuota: 20 } Menyimpan informasi lengkap dari satu item data.
Array Objek [ { ... }, { ... }, { ... } ] Menampung kumpulan data dalam satu daftar terurut.
forEach() data.forEach(item => { ... }) Menjalankan fungsi cetak HTML untuk setiap item dalam daftar.
Gunakan Template Literals (tanda backtick ` ` dan ${variabel}) untuk menyisipkan data objek langsung ke dalam struktur tag HTML kartu.

2. Contoh Kode Render Kartu

// 1. Daftar Data (Array of Objects) const dataEvent = [ { judul: "Desain Web 2026", kategori: "Frontend", kuota: 25 }, { judul: "Kuis Logika Dasar", kategori: "Algoritma", kuota: 40 }, { judul: "Keamanan Jaringan", kategori: "Cyber", kuota: 15 } ]; // 2. Fungsi Cetak ke Halaman const wadahKartu = document.querySelector("#wadahKartu"); function tampilkanKartu(daftar) { wadahKartu.innerHTML = ""; // Bersihkan wadah terlebih dahulu daftar.forEach((item) => { wadahKartu.innerHTML += \` <div class="kartu"> <span class="badge">\${item.kategori}</span> <h3>\${item.judul}</h3> <p>Tersedia \${item.kuota} kursi peserta</p> </div> \`; }); } tampilkanKartu(dataEvent);

3. Eksplorasi Praktik

1

Siapkan wadah penampung di HTML

Buat elemen pembungkus kosong di file HTML, misalnya: <div id="wadahKartu"></div>.

2

Buat array of objects di JavaScript

Susun array bernama dataEvent yang memuat minimal 3 objek dengan properti yang seragam (misal: judul, kategori, kuota).

3

Looping data dengan forEach()

Buat fungsi render yang membaca setiap objek di dalam array dan merangkai tag HTML kartu menggunakan template literals.

4

Panggil fungsi saat halaman terbuka

Jalankan fungsi render tersebut agar semua kartu muncul rapi secara otomatis saat web pertama kali dimuat.

4. Kesalahan yang Sering Terjadi

  • Lupa mengosongkan wadahKartu.innerHTML = "" sebelum loop, sehingga kartu bertambah ganda saat fungsi dipanggil ulang.
  • Salah menuliskan nama properti objek (misal di array tertulis judul, tetapi saat dicetak memanggil ${item.Judul}).
  • Menggunakan tanda petik biasa (' atau ") bukan tanda backtick (`), sehingga sintaks ${...} terbaca sebagai teks biasa.
Perhatikan penulisan huruf besar dan kecil (case-sensitive) pada properti objek JavaScript.
