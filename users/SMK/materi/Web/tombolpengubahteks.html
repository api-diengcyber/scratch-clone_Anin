Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Memahami Elemen dan Event Listener

Halaman web dibangun dari susunan elemen HTML yang tersusun seperti pohon (DOM). Supaya elemen bisa merespons tindakan pengguna, JavaScript menggunakan Event Listener.

Metode DOM Kegunaan
document.querySelector() Memilih elemen HTML berdasarkan class atau id.
addEventListener() Mendeteksi aksi pengguna seperti klik atau ketikan.
textContent Membaca atau mengganti isi teks di dalam elemen.
Dengan menggabungkan seleksi elemen dan event listener, kamu bisa membuat halaman web berinteraksi saat pengguna menekan tombol.

2. Contoh Kode

<!-- Struktur HTML --> <h2 id="judul">Halo Dunia!</h2> <button id="btnUbah">Ubah Pesan</button> // Logika JavaScript const judul = document.querySelector("#judul"); const tombol = document.querySelector("#btnUbah"); tombol.addEventListener("click", function() { judul.textContent = "Teks berhasil diubah lewat JavaScript!"; });

3. Eksplorasi Praktik

1

Siapkan struktur HTML

Buat elemen teks dengan tag <h1> atau <p> dan sebuah <button> dengan atribut id yang jelas.

2

Seleksi elemen di file JavaScript

Simpan referensi kedua elemen tersebut ke dalam variabel const menggunakan document.querySelector('#nama-id').

3

Pasang event listener klik

Gunakan method addEventListener('click', ...) pada elemen tombol yang sudah kamu simpan.

4

Ubah properti textContent

Di dalam blok fungsi event, tentukan kalimat baru yang akan menggantikan teks lama.

4. Kesalahan yang Sering Terjadi

  • Lupa menuliskan tanda pagar (#) saat memilih elemen id dengan querySelector.
  • Salah penulisan huruf besar-kecil pada textContent atau addEventListener.
  • File script JavaScript dipanggil sebelum elemen HTML selesai dimuat oleh browser.
Pastikan file JavaScript dimuat di akhir tag <body> atau gunakan atribut defer agar elemen HTML terbaca sempurna.
