Fisika & Raycast

Gravitasi, tabrakan, dan sinar pendeteksi benda

1. Gravitasi

vy += gravitasi * dt; // gravitasi negatif, menarik ke bawah benda.y += vy * dt; if (benda.y <= tanah) { benda.y = tanah; vy = 0; }

Gravitasi menambah kecepatan jatuh sedikit demi sedikit, jadi benda jatuh makin cepat. Waktu jatuh dari ketinggian h kira-kira √(2h ÷ g).

Tinggi awalWaktu jatuh (g = 9,8)
5 satuansekitar 1,0 detik
20 satuansekitar 2,0 detik
Tinggi empat kali lipat hanya membuat waktu jatuh dua kali lipat. Coba buktikan lewat percobaan task Gravitasi.

2. Bounding box dan tabrakan

Menghitung tabrakan bentuk rumit itu berat. Sebagai gantinya tiap benda diberi bounding box: kotak lurus yang membungkusnya.

function bertabrakan(a, b) { return a.minX <= b.maxX && a.maxX >= b.minX && a.minY <= b.maxY && a.maxY >= b.minY && a.minZ <= b.maxZ && a.maxZ >= b.minZ; } if (bertabrakan(pemain.kotak, dinding.kotak)) { pemain.x = pemain.xSebelumnya; // batalkan gerakan pesan = "Menabrak dinding!"; }
Dua kotak bertabrakan bila mereka tumpang tindih di sumbu X, Y, dan Z sekaligus.

3. Raycast: sinar pendeteksi

Raycast menembakkan sinar tak terlihat dari satu titik ke satu arah, lalu menanyakan: benda pertama apa yang terkena?

BagianArti
AsalTitik awal sinar (mata atau karakter)
ArahKe mana sinar menuju
Jarak maksimumSinar berhenti setelah sejauh ini
HasilBenda pertama yang terkena, atau tidak ada
const sinar = { asal: karakter.posisi, arah: arahDepan, jarakMaks: 10 }; const kena = dunia.raycast(sinar); if (kena) { kena.benda.warna = "merah"; }

4. Memilih benda dengan klik

Saat kamu mengklik layar, game membuat sinar dari kamera menembus posisi kursor ke dalam dunia. Benda pertama yang terkena sinar itulah yang terpilih.

Kalau semua benda ikut berubah warna, kemungkinan benda-benda berbagi satu material yang sama. Beri tiap benda material sendiri sebelum mengubah warnanya.
