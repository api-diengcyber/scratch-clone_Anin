Fisika & Raycast

Gravitasi, tabrakan, dan sinar pendeteksi benda

Materi Lengkap: Fisika Dan Deteksi Interaksi

Konsep dasar. Pengembangan 3D mengatur objek dalam ruang tiga dimensi. Setiap objek memiliki posisi, rotasi, skala, dan dapat berinteraksi dengan kamera, cahaya, fisika, audio, serta logika permainan. Pada materi Fisika & Raycast, fokus utama kita adalah fisika dan deteksi interaksi. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Fisika mensimulasikan gerak berdasarkan kecepatan, gravitasi, dan benturan. Collision mendeteksi kontak antar collider, sedangkan raycast mengirim garis/ray untuk mencari objek yang terkena.

Contoh Sederhana

Raycast dari posisi karakter ke bawah dapat mengetahui apakah ada lantai di bawahnya.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

gravity, velocity, collider, collision, raycast, rigidbody

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk lompatan, lantai, proyektil, interaksi, dan deteksi objek.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan koordinat, parent-child transform, collider, frame rate, jarak kamera, dan perbedaan update per frame dengan waktu nyata.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: salah memahami sumbu, gerak bergantung frame rate, collider tidak sesuai bentuk, terlalu banyak objek/efek, dan tidak menguji scene pada kondisi performa berbeda.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.
  4. Ubah satu bagian dan amati dampaknya.
  5. Catat alasan solusi yang kamu pilih.

1. Gravitasi

vy += gravitasi * dt; // gravitasi negatif, menarik ke bawah benda.y += vy * dt; if (benda.y <= tanah) { benda.y = tanah; vy = 0; }

Gravitasi menambah kecepatan jatuh sedikit demi sedikit, jadi benda jatuh makin cepat. Waktu jatuh dari ketinggian h kira-kira √(2h ÷ g).

Tinggi awalWaktu jatuh (g = 9,8)
5 satuansekitar 1,0 detik
20 satuansekitar 2,0 detik
Tinggi empat kali lipat hanya membuat waktu jatuh dua kali lipat. Coba buktikan lewat percobaan task Gravitasi.

2. Bounding box dan tabrakan

Menghitung tabrakan bentuk rumit itu berat. Sebagai gantinya tiap benda diberi bounding box: kotak lurus yang membungkusnya.

function bertabrakan(a, b) { return a.minX <= b.maxX && a.maxX >= b.minX && a.minY <= b.maxY && a.maxY >= b.minY && a.minZ <= b.maxZ && a.maxZ >= b.minZ; } if (bertabrakan(pemain.kotak, dinding.kotak)) { pemain.x = pemain.xSebelumnya; // batalkan gerakan pesan = "Menabrak dinding!"; }
Dua kotak bertabrakan bila mereka tumpang tindih di sumbu X, Y, dan Z sekaligus.

3. Raycast: sinar pendeteksi

Raycast menembakkan sinar tak terlihat dari satu titik ke satu arah, lalu menanyakan: benda pertama apa yang terkena?

BagianArti
AsalTitik awal sinar (mata atau karakter)
ArahKe mana sinar menuju
Jarak maksimumSinar berhenti setelah sejauh ini
HasilBenda pertama yang terkena, atau tidak ada
const sinar = { asal: karakter.posisi, arah: arahDepan, jarakMaks: 10 }; const kena = dunia.raycast(sinar); if (kena) { kena.benda.warna = "merah"; }

4. Memilih benda dengan klik

Saat kamu mengklik layar, game membuat sinar dari kamera menembus posisi kursor ke dalam dunia. Benda pertama yang terkena sinar itulah yang terpilih.

Kalau semua benda ikut berubah warna, kemungkinan benda-benda berbagi satu material yang sama. Beri tiap benda material sendiri sebelum mengubah warnanya.
