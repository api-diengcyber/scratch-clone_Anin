Tipe Data Python

Mengenal identitas dan jenis-jenis data di dalam memori komputer

Materi Lengkap: Dasar Pemrograman

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Tipe Data Python, fokus utama kita adalah dasar pemrograman. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Program menerima data, memprosesnya berdasarkan aturan, lalu menghasilkan keluaran. Variabel menyimpan nilai, tipe data menentukan jenis nilai, operator melakukan operasi, dan fungsi membantu membagi program menjadi bagian yang dapat digunakan kembali.

Contoh Sederhana

nama = input("Nama: ") lalu print("Halo", nama) menunjukkan alur input → proses sederhana → output.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

variabel, tipe data, input, output, operator, fungsi, algoritma

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan konsep dasar ini sebagai fondasi hampir semua program Python.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

Cara Belajar Sebelum Task

  1. Jelaskan konsep dengan kata-katamu sendiri.
  2. Perhatikan contoh dan prediksi hasilnya sebelum dijalankan.
  3. Kerjakan task tanpa menyalin jawaban langkah demi langkah.

1. Empat Tipe Data Inti

Setiap informasi di Python memiliki identitas tipe data agar komputer mengerti cara memprosesnya:

Tipe Nama Lengkap Penjelasan Singkat Contoh
str String Teks / Kata (wajib diapit tanda petik) "Garuda", 'SMP 1'
int Integer Bilangan bulat tanpa desimal 14, 2026, -3
float Float Bilangan pecahan / desimal (titik) 3.14, 75.5
bool Boolean Kebenaran logika (hanya Benar / Salah) True, False

2. Eksplorasi Praktik

1

Contoh 1: Deklarasikan Berbagai Tipe Data

Buat variabel untuk nama game, level, dan status aktif.

game = "Roblox" # str level = 25 # int menang = True # bool
2

Contoh 2: Cek Tipe Data Menggunakan type()

Gunakan perintah type() untuk meminta Python memeriksa tipe variabel.

print(type(game)) print(type(level)) print(type(menang))
3

Contoh 3: Lakukan Konversi Tipe Data (Casting)

Ubah angka bulat menjadi desimal (float) atau ubah angka ke teks (str).

desimal = float(level) # 25 berubah menjadi 25.0 print(desimal)
