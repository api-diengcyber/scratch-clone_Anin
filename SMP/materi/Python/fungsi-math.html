Membungkus langkah jadi fungsi yang bisa dipakai berulang

Materi Inti: Konsep inti materi

Gagasan utama. Materi sebaiknya dipahami sebagai konsep, bukan sekadar urutan klik. Pahami istilah, hubungan sebab-akibat, dan alasan sebuah teknik digunakan sebelum mencoba task.

Cara berpikir sebelum mengerjakan task. Sebelum membuka task, jelaskan dengan kata-katamu sendiri masalah, data yang tersedia, dan hasil yang diharapkan.

Istilah yang perlu dipahami: konsep, model mental, sebab-akibat, eksperimen, evaluasi.

Hubungkan Konsep dengan Masalah

Jangan langsung mencari urutan klik atau menyalin jawaban. Gunakan task sebagai tempat menguji pemahaman. Buat prediksi, jalankan percobaan, amati hasilnya, lalu revisi dugaan jika hasilnya berbeda.

  • Apa masalah yang sebenarnya ingin diselesaikan?
  • Informasi atau data apa yang tersedia, dan apa yang belum diketahui?
  • Konsep mana yang paling relevan? Mengapa?
  • Kasus apa yang mungkin membuat solusi pertamamu gagal?
  • Bagaimana kamu membuktikan bahwa hasil task benar?

Eksplorasi Mandiri

Gunakan contoh yang tersedia sebagai bahan pengamatan, bukan sebagai jawaban task. Ubah satu variabel atau kondisi, buat prediksi, lalu bandingkan hasilnya. Catat temuan yang membuatmu lebih memahami konsep.

1. Apa itu fungsi dan kenapa perlu?

Fungsi adalah potongan kode bernama yang melakukan satu tugas. Kamu menulisnya sekali, lalu memanggilnya sebanyak yang kamu mau. Tanpa fungsi, kode yang sama harus disalin berkali-kali: panjang, mudah salah, dan sulit diperbaiki.

def sapa(nama): print("Halo,", nama) sapa("Rani") # Halo, Rani sapa("Budi") # Halo, Budi
Urutan penting: fungsi harus didefinisikan dulu (def), baru dipanggil. Mendefinisikan tidak menjalankan isinya; isinya baru jalan saat dipanggil.

2. Anatomi fungsi: def, parameter, return

BagianFungsiContoh
defKata kunci untuk membuat fungsidef luas(p, l):
ParameterNama kotak penerima nilai (di definisi)p, l
ArgumenNilai yang dikirim saat memanggilluas(4, 5)
Isi (indentasi)Baris yang ikut fungsi, menjorok 4 spasi return p * l
returnMengirim hasil keluar dari fungsireturn p * l
def luas(p, l): return p * l hasil = luas(4, 5) print(hasil) # 20
print vs return: print hanya menampilkan ke layar, hasilnya hilang. return mengirim nilai agar bisa disimpan di variabel atau dipakai lagi. Fungsi tanpa return menghasilkan None.

3. Parameter default dan banyak parameter

Parameter boleh punya nilai bawaan. Kalau argumen tidak diberikan, nilai bawaan dipakai.

def diskon(harga, persen=10): return harga - harga * persen / 100 print(diskon(50000)) # 45000.0 print(diskon(50000, 25)) # 37500.0

4. Modul math: rumus siap pakai

Modul adalah kumpulan fungsi buatan orang lain. Ambil dengan import math, lalu panggil dengan awalan math..

import math def luas_lingkaran(r): return math.pi * r ** 2 print(round(luas_lingkaran(7), 2)) # 153.94
