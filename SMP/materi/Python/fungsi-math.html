Materi Lengkap: Fungsi Dan Modularisasi

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Fungsi & Modul math, fokus utama kita adalah fungsi dan modularisasi. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Fungsi membungkus langkah yang memiliki tujuan tertentu. Parameter menerima input, return mengembalikan hasil, dan modul memungkinkan fungsi dipakai ulang di file atau pustaka lain.

Contoh Sederhana

def luas(panjang, lebar): return panjang * lebar menghasilkan fungsi yang dapat dipakai untuk banyak pasangan ukuran.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

Istilah Penting

fungsi, parameter, argumen, return, scope, module, import, *args, **kwargs

Pahami istilah tersebut sebagai konsep yang saling berhubungan, bukan daftar hafalan. Saat membaca task, coba tunjukkan istilah mana yang sedang digunakan dan apa buktinya dari hasil program/scene.

Kapan Konsep Ini Digunakan?

Gunakan untuk menghindari kode berulang, memperjelas tanggung jawab, dan membuat program lebih mudah diuji.

Pemilihan teknik selalu bergantung pada masalah. Tidak ada satu metode yang paling benar untuk semua situasi; bandingkan kebutuhan, batasan, data, dan hasil yang diinginkan.

Hal yang Perlu Diperhatikan

  • Perhatikan tipe data, nilai batas, urutan operasi, nama variabel yang jelas, dan hasil yang benar untuk input berbeda.
  • Uji lebih dari satu kondisi, termasuk kasus normal dan kasus batas.
  • Amati hasil sebelum mengubah kode/scene agar perubahanmu memiliki alasan.
  • Bedakan masalah pada konsep, data/input, dan implementasi.

Kesalahan Umum

Kesalahan umum: menyalin kode tanpa memahami alurnya, salah indentasi, salah tipe data, kondisi tidak lengkap, indeks di luar batas, atau menganggap satu contoh selalu mewakili semua kasus.

Jika hasil task berbeda dari prediksi, jangan langsung mengganti kode secara acak. Cari langkah pertama ketika perilaku mulai berbeda, lalu jelaskan penyebabnya.

1. Apa itu fungsi dan kenapa perlu?

Fungsi adalah potongan kode bernama yang melakukan satu tugas. Kamu menulisnya sekali, lalu memanggilnya sebanyak yang kamu mau. Tanpa fungsi, kode yang sama harus disalin berkali-kali: panjang, mudah salah, dan sulit diperbaiki.

def sapa(nama): print("Halo,", nama) sapa("Rani") # Halo, Rani sapa("Budi") # Halo, Budi
Urutan penting: fungsi harus didefinisikan dulu (def), baru dipanggil. Mendefinisikan tidak menjalankan isinya; isinya baru jalan saat dipanggil.

2. Anatomi fungsi: def, parameter, return

BagianFungsiContoh
defKata kunci untuk membuat fungsidef luas(p, l):
ParameterNama kotak penerima nilai (di definisi)p, l
ArgumenNilai yang dikirim saat memanggilluas(4, 5)
Isi (indentasi)Baris yang ikut fungsi, menjorok 4 spasi return p * l
returnMengirim hasil keluar dari fungsireturn p * l
def luas(p, l): return p * l hasil = luas(4, 5) print(hasil) # 20
print vs return: print hanya menampilkan ke layar, hasilnya hilang. return mengirim nilai agar bisa disimpan di variabel atau dipakai lagi. Fungsi tanpa return menghasilkan None.

3. Parameter default dan banyak parameter

Parameter boleh punya nilai bawaan. Kalau argumen tidak diberikan, nilai bawaan dipakai.

def diskon(harga, persen=10): return harga - harga * persen / 100 print(diskon(50000)) # 45000.0 print(diskon(50000, 25)) # 37500.0

4. Modul math: rumus siap pakai

Modul adalah kumpulan fungsi buatan orang lain. Ambil dengan import math, lalu panggil dengan awalan math..

PemakaianHasilKegunaan

math.pi3.14159…Nilai pi
math.floor(3.7)3Bulatkan ke bawah

import math def luas_lingkaran(r): return math.pi * r ** 2 print(round(luas_lingkaran(7), 2)) # 153.94
