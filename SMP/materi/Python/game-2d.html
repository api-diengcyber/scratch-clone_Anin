Game 2D: Loop, Gerak, Tabrakan & Skor

Membangun game dari satu loop yang berjalan terus

Materi Lengkap: Pemrograman Berorientasi Objek

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Game 2D: Loop, Gerak, Tabrakan & Skor, fokus utama kita adalah pemrograman berorientasi objek. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. OOP mengelompokkan data dan perilaku ke dalam object. Class menjadi cetak biru, object adalah instance, inheritance mewariskan perilaku, polymorphism memungkinkan antarmuka yang sama memiliki perilaku berbeda, encapsulation membatasi cara data diakses, dan composition menyusun object dari object lain.

1. Game loop

Semua game berjalan dengan siklus yang diulang puluhan kali per detik: 1) baca input → 2) ubah keadaan (update) → 3) tampilkan (draw).

TahapPertanyaannyaContoh
InputPemain menekan apa?Tombol kiri atau kanan
UpdateApa yang berubah?Posisi pemain, skor, rintangan
DrawBagaimana tampilannya?Gambar ulang semuanya
posisi, lebar = 5, 10 while True: garis = ["."] * lebar garis[posisi] = "P" print("".join(garis)) perintah = input("a=kiri d=kanan q=keluar: ") if perintah == "a": posisi -= 1 elif perintah == "d": posisi += 1 elif perintah == "q": break posisi = max(0, min(lebar - 1, posisi)) # batasi di layar
Contoh ini memakai teks supaya jalan di Python biasa. Di library game (misalnya pygame atau turtle) konsepnya sama; hanya cara membaca tombol dan menggambar yang berbeda. Ikuti library yang dipakai kelasmu.

2. Koordinat dan batas layar

SumbuArahPerubahan
xKiri ke kananx bertambah = ke kanan
yAtas ke bawah (pada kebanyakan library game)y bertambah = turun

Untuk membatasi pemain, pakai pola clamp: x = max(0, min(lebar - 1, x)). Nilai x tidak pernah di bawah 0 atau melewati lebar layar.

3. Posisi acak dan tabrakan

import random koin_x = random.randint(0, lebar - 1) # posisi acak # tabrakan 1 dimensi if posisi == koin_x: skor += 1 koin_x = random.randint(0, lebar - 1) # koin baru # tabrakan kotak 2 dimensi (AABB) def bertabrakan(a, b): return (a["x"] < b["x"] + b["w"] and a["x"] + a["w"] > b["x"] and a["y"] < b["y"] + b["h"] and a["y"] + a["h"] > b["y"])
Dua kotak bertabrakan bila mereka tumpang tindih di sumbu x DAN sumbu y sekaligus.

4. Skor dan nyawa

VariabelAwalBerubah saat
skor0Mengambil koin: skor += 1
nyawa3Menabrak rintangan: nyawa -= 1
Buat skor dan nyawa di luar loop. Kalau dibuat di dalam, nilainya kembali awal tiap putaran.

5. Rintangan bergerak

rintangan_x = lebar - 1 kecepatan = 1 # di dalam loop: rintangan_x -= kecepatan # bergerak tiap putaran if rintangan_x < 0: rintangan_x = lebar - 1 # kembali ke sisi awal

Kecepatan adalah perubahan posisi per putaran. Makin besar angkanya, makin cepat rintangannya.

6. Game over dan main lagi

def mulai_ulang(): return {"skor": 0, "nyawa": 3, "posisi": 5} keadaan = mulai_ulang() while True: # ... update dan tampilkan ... if keadaan["nyawa"] <= 0: print("GAME OVER. Skor:", keadaan["skor"]) if input("Main lagi? (y/n) ") == "y": keadaan = mulai_ulang() else: break

Membungkus keadaan awal dalam satu fungsi membuat mengulang permainan cukup satu baris.

7. Kesalahan yang sering terjadi

MasalahPenyebabPerbaikan
Game tidak pernah berhentiTidak ada break atau kondisi keluarTambah jalan keluar saat game over atau q
Pemain keluar layarBelum ada clampPakai max dan min
Tabrakan tidak terdeteksiPosisi dibandingkan sebelum diperbaruiUpdate posisi dulu, baru cek tabrakan
Skor kembali 0 terusVariabel dibuat dalam loopPindahkan ke sebelum loop
Rintangan hilang selamanyaTidak di-resetKembalikan ke sisi awal saat keluar

8. Peta ke task

  • Gerakkan pemain: loop utama, input, clamp.
  • Kumpulkan koin: posisi acak, tabrakan, skor.
  • Skor dan nyawa: dua variabel keadaan dan tampilannya.
  • Rintangan bergerak: kecepatan tetap dan reset posisi.
  • Game over dan ulang: kondisi nyawa, pesan, dan mulai_ulang().

9. Proyek: Game Hindari Rintangan

1

Gabungkan

Pemain, koin, dan rintangan dalam satu loop; urutan per putaran: input, update, cek tabrakan, tampilkan.

2

Lengkapi

Pastikan ada skor, nyawa, layar Game Over, dan opsi main lagi.

3

Uji dengan teman

Minta satu orang bermain, catat satu hal yang membingungkan, lalu perbaiki.
