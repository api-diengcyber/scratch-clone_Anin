TASK 1 • LOGIKA PERCABANGAN

Cek Nilai (if - else)

Mengajarkan komputer mengambil keputusan berdasarkan kondisi benar atau salah

Materi Lengkap: Percabangan

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi Cek Nilai (if - else), fokus utama kita adalah percabangan. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. Percabangan mengevaluasi kondisi Boolean lalu memilih jalur program. if menangani kondisi utama, elif alternatif, dan else kondisi yang tersisa.

Contoh Sederhana

Jika nilai >= 75 maka lulus, selain itu belum lulus. Kondisi harus ditulis sehingga semua kemungkinan penting tertangani.

Coba pikirkan: jika input, ukuran data, kondisi, atau lingkungan diubah, bagian mana dari proses yang ikut berubah? Sebelum menjalankan task, buat prediksi terlebih dahulu.

1. Apa itu Percabangan (if - else)?

Dalam kehidupan sehari-hari, kita sering membuat keputusan: "Jika hari hujan, bawa payung. Jika tidak, pakai topi."

Di Python, kata jika ditulis sebagai if, dan jika tidak ditulis sebagai else.

Aturan Wajib (Indentasi): Baris kode setelah tanda titik dua (:) harus diberi spasi tab / 4 spasi agar Python tahu kode itu berada di dalam blok kondisi!

2. Eksplorasi Praktik

1

Contoh 1: Ambil Nilai Siswa

Minta input nilai ujian dan konversi ke bilangan bulat (int).

nilai = int(input("Masukkan nilai ujianmu: "))
2

Contoh 2: Tentukan Batas Kelulusan (if)

Gunakan operator >= (lebih besar atau sama dengan 75) untuk mengecek status lulus.

if nilai >= 75: print("Selamat! Kamu dinyatakan LULUS 🎉")
3

Contoh 3: Beri Pesan Jika Belum Lulus (else)

Tambahkan bagian else: sebagai jalur alternatif jika nilainya di bawah 75.

else: print("Semangat, kamu harus ikut remedial ya! 💪")
