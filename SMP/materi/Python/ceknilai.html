TASK 1 • LOGIKA PERCABANGAN

Cek Nilai (if - else)

Mengajarkan komputer mengambil keputusan berdasarkan kondisi benar atau salah

1. Apa itu Percabangan (if - else)?

Dalam kehidupan sehari-hari, kita sering membuat keputusan: "Jika hari hujan, bawa payung. Jika tidak, pakai topi."

Di Python, kata jika ditulis sebagai if, dan jika tidak ditulis sebagai else.

Aturan Wajib (Indentasi): Baris kode setelah tanda titik dua (:) harus diberi spasi tab / 4 spasi agar Python tahu kode itu berada di dalam blok kondisi!

2. Instruksi 3 Langkah Praktik

1

Langkah 1: Ambil Nilai Siswa

Minta input nilai ujian dan konversi ke bilangan bulat (int).

nilai = int(input("Masukkan nilai ujianmu: "))
2

Langkah 2: Tentukan Batas Kelulusan (if)

Gunakan operator >= (lebih besar atau sama dengan 75) untuk mengecek status lulus.

if nilai >= 75: print("Selamat! Kamu dinyatakan LULUS 🎉")
3

Langkah 3: Beri Pesan Jika Belum Lulus (else)

Tambahkan bagian else: sebagai jalur alternatif jika nilainya di bawah 75.

else: print("Semangat, kamu harus ikut remedial ya! 💪")
