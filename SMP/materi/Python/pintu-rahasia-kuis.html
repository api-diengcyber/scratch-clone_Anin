Pintu Rahasia & Proyek Kuis

Perulangan while, batas percobaan, dan merangkai program kuis

1. Kapan memakai while?

for dipakai saat jumlah pengulangan sudah diketahui. while dipakai saat kita mengulang sampai suatu kondisi terpenuhi, misalnya sampai sandi benar.

PerulanganBerhenti ketikaContoh
forDaftar atau rentang habisCek 5 soal satu per satu
whileKondisi menjadi FalseMinta sandi sampai benar
Setiap while butuh jalan keluar: sesuatu di dalam loop yang pada akhirnya membuat kondisi False, atau perintah break. Tanpa itu loop berjalan selamanya (infinite loop).

2. Pola pintu rahasia

sandi = "lumbung" coba = 0 while coba < 3: tebakan = input("Sandi: ") if tebakan == sandi: print("Pintu terbuka!") break coba += 1 print("Salah. Sisa percobaan:", 3 - coba) else: print("Pintu terkunci.")

Blok else pada while hanya jalan bila loop selesai tanpa break, yaitu saat percobaan habis. Variabel coba adalah penghitung: dibuat di luar loop, bertambah di dalam loop.

3. Versi dengan operator and

tebakan = "" coba = 0 while tebakan != sandi and coba < 3: tebakan = input("Sandi: ") coba += 1 if tebakan == sandi: print("Pintu terbuka!") else: print("Pintu terkunci.")
OperatorArtinyaLoop lanjut jika
andKeduanya benarSandi belum benar DAN percobaan belum habis
orSalah satu benarSalah satu syarat masih terpenuhi
notMembalikKebalikan dari kondisi
Kondisi harus bisa dievaluasi sebelum loop pertama. Karena itu tebakan diberi nilai awal "".

4. Proyek: Kuis Pengetahuan Umum

Rangkai semua yang sudah kamu pelajari: variabel, input, perbandingan, perulangan, dan percabangan.

soal = [("Ibu kota Indonesia?", "jakarta"), ("Hasil 7 x 8?", "56")] skor = 0 for pertanyaan, kunci in soal: jawab = input(pertanyaan + " ").strip().lower() if jawab == kunci: print("Benar!") skor += 1 else: print("Salah. Jawabannya:", kunci) nilai = skor / len(soal) * 100 print("Nilai akhir:", nilai)
  • .strip().lower() membuat jawaban " Jakarta " tetap dianggap benar.
  • Menyimpan soal sebagai daftar membuat menambah soal cukup dengan satu baris.

5. Predikat dari nilai

if nilai >= 80: predikat = "Sangat baik" elif nilai >= 60: predikat = "Baik" else: predikat = "Perlu belajar lagi" print(predikat)

Urutan elif penting: Python memakai cabang pertama yang benar, jadi mulai dari syarat tertinggi.
