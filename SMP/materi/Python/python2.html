1. Masalah Utama pada input()

Di modul sebelumnya, kita sudah tahu bahwa fungsi input() selalu menghasilkan teks (string).

Jika kita menjumlahkan dua teks tanpa diubah terlebih dahulu, Python tidak menghitungnya, melainkan menggabungkan teksnya:

a = "10" b = "5" print(a + b) # Hasilnya "105", BUKAN 15!
Solusi Konversi (Type Casting):
Gunakan int() untuk mengubah teks angka menjadi bilangan bulat murni agar simbol + berfungsi sebagai operasi matematika.

2. Eksplorasi Praktik

1

Contoh 1: Ambil Angka Pertama

Minta input angka dari pengguna dan bungkus langsung dengan int().

angka1 = int(input("Masukkan angka pertama: "))
2

Contoh 2: Ambil Angka Kedua

Gunakan cara yang sama untuk menyimpan angka kedua di variabel baru.

angka2 = int(input("Masukkan angka kedua: "))
3

Contoh 3: Hitung dan Cetak Hasil

Jumlahkan kedua variabel lalu tampilkan ke layar dengan fungsi print().

hasil = angka1 + angka2 print("Hasil penjumlahan:", hasil)
