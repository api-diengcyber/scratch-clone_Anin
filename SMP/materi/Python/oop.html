OOP: Kelas, Object & Inheritance

Membuat cetakan, membuat banyak objek, dan membuat class turunan

Materi Lengkap: Pemrograman Berorientasi Objek

Konsep dasar. Python adalah bahasa pemrograman yang digunakan untuk memberi komputer instruksi secara terstruktur dan mudah dibaca. Pada materi OOP: Kelas, Object & Inheritance, fokus utama kita adalah pemrograman berorientasi objek. Tujuannya bukan menghafal langkah, tetapi memahami alasan di balik setiap keputusan sehingga kamu dapat menerapkannya pada masalah yang berbeda.

Cara kerja. OOP mengelompokkan data dan perilaku ke dalam object. Class menjadi cetak biru, object adalah instance, inheritance mewariskan perilaku, polymorphism memungkinkan antarmuka yang sama memiliki perilaku berbeda, encapsulation membatasi cara data diakses, dan composition menyusun object dari object lain.

1. Mengapa perlu class?

Bayangkan game dengan 3 karakter. Tanpa class, kamu butuh nama1, hp1, nama2, hp2, ...: panjang dan mudah tertukar. OOP (Object-Oriented Programming) mengelompokkan data dan aksinya dalam satu paket bernama object.

Class = cetakan. Object = hasil cetakan. Satu class bisa menghasilkan banyak object.

class Hewan: def __init__(self, nama, suara): self.nama = nama self.suara = suara def bersuara(self): print(self.nama, "berkata", self.suara) kucing = Hewan("Mimi", "meong") anjing = Hewan("Doli", "guk") kucing.bersuara() # Mimi berkata meong anjing.bersuara() # Doli berkata guk
Setiap method wajib punya self sebagai parameter pertama, tetapi saat memanggil kamu tidak menuliskannya.

3. Method yang mengubah data dan berinteraksi dengan object lain

Method bisa mengubah atribut milik object, dan bisa menerima object lain sebagai argumen. Contoh dengan rekening bank (bukan karakter game, supaya kamu menerapkannya sendiri):

class Rekening: def __init__(self, pemilik, saldo): self.pemilik = pemilik self.saldo = saldo def tarik(self, jumlah): self.saldo -= jumlah def kirim(self, tujuan, jumlah): # tujuan = object Rekening lain self.saldo -= jumlah tujuan.saldo += jumlah a = Rekening("Ani", 100) b = Rekening("Budi", 50) a.kirim(b, 30) print(a.saldo, b.saldo) # 70 80

4. Inheritance: class turunan

Class anak mewarisi atribut dan method class induk, lalu boleh menambah atau mengganti (override).

class Kendaraan: def __init__(self, nama, roda): self.nama = nama self.roda = roda def info(self): print(self.nama, "beroda", self.roda) class Motor(Kendaraan): def __init__(self, nama): super().__init__(nama, 2) # panggil __init__ induk def wheelie(self): print(self.nama, "angkat roda depan") m = Motor("Vespa") m.info() # diwarisi dari Kendaraan m.wheelie() # milik Motor
super() memanggil bagian induk, sehingga kamu tidak menulis ulang kode yang sama.

5. Banyak object dalam list dan kartu info

class Siswa: def __init__(self, nama, nilai): self.nama = nama self.nilai = nilai def __str__(self): return f"{self.nama} - nilai {self.nilai}" kelas = [Siswa("Ani", 90), Siswa("Budi", 75), Siswa("Citra", 85)] for s in kelas: print(s) # memanggil __str__ otomatis
